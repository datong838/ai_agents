## 1. 基础公式（Core Formula）

```text
[画质前缀] + [主体描述] + [环境/背景] + [光影/氛围] + [构图/镜头] + [负向提示词]
```

**输出语言**：面向 **豆包 / MJ / SD** 的 **英文主提示词** + **中文备注**（供美术 Tab 展示）；负向提示词 **单独字段** `negative_prompt`。

## 2. 模块化规则

### 2.1 画质前缀（Quality Prefix）

**目的**：抬高美学上限，避免塑料感、AI 廉价感。

**推荐词块**（任选 4–6 个，勿堆砌矛盾风格）：

```text
masterpiece, best quality, ultra-detailed, photorealistic, cinematic lighting, 8k resolution, sharp focus
```

**美妆种草补充**（与 [风格 v1.2](风格-美妆种草60s-v1.md) 对齐——像 vlog 而非棚拍广告）：

```text
natural skin texture, subtle imperfections, handheld phone camera feel, soft grain, authentic lifestyle
```

### 2.2 主体描述（Subject）

**目的**：锁定人物长相、妆造、表情、手持物。

**结构**：`年龄 + 族裔/肤质 + 妆容 + 服饰 + 动作/表情 + 手持物`

| 字段 | 规则 | 示例 |
|------|------|------|
| 年龄 | 与剧本受众一致 | 25-year-old Asian woman |
| 肤质 | Hook 可微瑕；展示后段透亮 | visible dark spots on left cheek, dull skin tone |
| 妆容 | 淡妆/素颜，禁浓妆模特感 | light natural makeup, no heavy contour |
| 服饰 | 简约通勤 / 家居 | simple home wear, casual white T-shirt |
| 动作 | 与 Beat 画面一致 | holding Shangyaxiu Diamond Radiance set silver box with gold-lid jar, applying essence with pump dispenser |
| 表情 | 情绪与 Beat 匹配 | slightly worried / tired / confident smile |

**禁止**：虚构剧本与 fact_sheet 未出现的产品名、成分、品牌 Logo 文字（画面内 readable text 尽量规避）。

**禁止笼统手持物（v1.2 硬性）**：不得仅写「护肤礼盒 / 礼盒 / 护肤品 / skincare set / gift box / product box / generic serum bottle」——须从 **创作素材包 media_refs** 摘 **品牌 + 系列 + 品名 + 包装形态 + 颜色材质**（见 §2.7）。

### 2.7 素材包手持物绑定（Mandatory · v1.2）

**目的**：主角/道具/Beat 镜头中的 **手持物、特写主体、CTA 展示物** 必须与 `creation_material_bundle.media_refs` 中 **已有商品图** 一致，避免笼统「礼盒/护肤品」导致出图跑偏。

**输入字段**（每条 media_ref）：

| 字段 | 用途 |
|------|------|
| `vlm_description` | 包装形态、颜色、瓶型、容量——**写入 prompt_en Subject / prop 段** |
| `use_cases` | 适用场景——**决定该 Beat 应选哪条 SKU** |
| `role_hint` | `cover`=套装/外包装 · `texture`=质地/精华液 · `scene`=场景参考 |

**选型规则**：

1. 剧本/Beat 含「体验套 / 钻光套 / 套装」→ 选用 `role_hint=cover` 的 catalog 条目；prompt **必须写完整品名**（如「尚雅绣钻石光感套…外盒」），**禁止**用「护肤礼盒 / 礼盒 / gift box」代替品名  
2. 剧本/Beat 含「精华液 / 涂抹 / 泵头 / 质地 / 提亮」→ 选用 `role_hint=texture` 的 catalog 条目；须写「尚雅绣臻宠晶透精华液」等 **全称 + 瓶型/容量**  
3. **CTA 对镜微笑 + 手持**：须写 **catalog 完整品名 + 手持方式**；禁止「手持护肤礼盒 / 银色金属护肤礼盒」（修饰词 + 礼盒 **仍算违规**）  
4. **背景杂物**：须写 catalog 中具体包装形态；禁止仅写 `scattered skincare bottles`  

**禁止词块**（出现即视为违规；「银色金属 + 下列词」同样违规）：

```text
护肤礼盒, 礼品盒, skincare gift box, skincare set, gift box, product box, generic serum bottle
```

**「礼盒」二字**：仅当同条 prompt **已出现 catalog 完整品名**（含「尚雅绣…套/液/水」）时，才允许在品名后出现「盒/外包装」等形态描述；**禁止**单独用「礼盒」指代产品。

**合规写法示例**（以尚雅绣为例，实际项目替换为 catalog 全文）：

```text
[Subject]: ... holding Shangyaxiu Diamond Radiance set — silver metallic rectangular outer box
with gold-lid round glass jar on top, pressed gently against cheek ...

[Subject]: ... holding Shangyaxiu Precious Crystal Clear essence bottle — rose-gold cylindrical
pump dispenser, 40ML, diamond radiance series ...
```

### 2.3 环境/背景（Environment）

**目的**：还原剧本场景（梳妆台、浴室等）。

**结构**：`空间类型 + 材质 + 关键杂物 + 整洁度`

```text
modern minimalist bedroom dressing table, warm wooden surface, same-brand skincare items from catalog (silver box and rose-gold pump bottle shapes), soft clutter, clean wall background
```

**占比参考**（美妆 60s 竖屏）：梳妆台/卧室 ~70% · 浴室 ~15% · 纯色产品背景 ~15%。

### 2.4 光影/氛围（Lighting & Atmosphere）

**目的**：烘托产品情绪（晨间治愈、钻光通透）。

| Beat 类型 | 光影倾向 | 氛围词 |
|-----------|----------|--------|
| Hook / 痛点 | 侧光、阴影略重、强调瑕疵纹理 | moody, contrast, realistic skin texture |
| 共鸣 | 暖黄台灯光、略凌乱 | warm, tired, intimate, late night |
| 展示/信任 | 柔光、 rim light、产品高光 | glowing, translucent skin, premium, diamond-like reflection |
| CTA | 明亮均匀、干净背景虚化 | bright, hopeful, clean, eye contact |

```text
soft side backlight through sheer curtain, gentle rim light, warm and healing atmosphere
```

### 2.5 构图/镜头（Composition）

**目的**：为 Vidu / 摄影提供景别与视角基础。

**竖屏 9:16 默认**：

| 参数 | 可选值 | 说明 |
|------|--------|------|
| 景别 | extreme close-up, close-up, medium shot, medium close-up | Hook 斑点多用 close-up |
| 视角 | eye-level, slight high angle, slight low angle | 手持 vlog 略俯常见 |
| 景深 | shallow depth of field, bokeh background | 产品/脸部特写必用 |
| 画幅 | vertical 9:16, portrait orientation | 写入 `aspect_ratio: "9:16"` |
| 主体位置 | subject on left third / centered / right third | 优秀特写常交代主体在画面左/中/右 |

```text
close-up shot, eye-level, shallow depth of field, focus on cheek spots, vertical 9:16
```

### 2.6 优秀特写结构（v2.7 · 参考 `docs/优秀镜头特写提示词实例.docx`）

内部样例共性（**学结构，禁止照抄原句**）：

| 维度 | 写法要点 |
|------|----------|
| 主体 | 谁 · 什么表情 · **一个**姿态/动作（或明确 zero hands） |
| 环境 | 具体场景元素 + 氛围（非「plain gray」敷衍，除非 Beat 刻意极简） |
| 光影 | 主光方向、色温、面部/产品高光、阴影层次 |
| 构图 | 景别 + 机位 + 主体位置 + 景深/虚化 |
| 瞬间 | 冻结 **单一** 叙事瞬间，不写「又…又…又…」 |

**YAML 输出必须带小节标题**（与 §4 模板一致）：

```text
[Subject]: ...
[Environment]: ...
[Lighting]: ...
[Composition]: ...
```

### 2.8 负向提示词（Negative Prompt）

**目的**：商业合规 + 解剖正确 + 无水印。

**通用块**（每条 prompt 必带）：

```text
worst quality, low quality, deformed, ugly, bad anatomy, extra limbs, extra fingers, fused fingers, malformed hands, watermark, logo, text, blurry, oversaturated, cartoon, anime, plastic skin, over-smoothed face
```

**美妆专项避坑**：

```text
heavy makeup, studio advertising pose, perfect porcelain skin, before-after split screen text, price tag, QR code, competitor brand
```

## 3. Vidu / 视频一致性约束

### 3.1 跨镜头身份一致

同项目 **主讲述者** 生成多角度图时：

| 引擎 | 做法 |
|------|------|
| Midjourney | `--cref [URL] --cw 80`（或项目内 `consistency_ref_url`） |
| SD / Flux | ControlNet OpenPose / IP-Adapter / 参考图 img2img |
| 人工 | 第一张「定稿肖像」锁定为 `character.reference_locked` |

**规则**：女主 **基设定批次** 须产出 ≥1 张 **approved** 参考图后，再批量生成场景/产品手持图。

### 3.2 动作与手部 · 一镜一动作（v2.6 · tier 隔离 v2.8）

**硬规则**：每条 Beat / composite Prompt **只允许一个手部或交互动作**。

**tier 隔离**（出图 Anchor / ref / Guardrails 按层分流）：

| tier | Prompt 写法 | 出图系统行为 |
|------|-------------|--------------|
| prop | 产品静物，无 `[Subject]` 人物 | 禁止人手/POV；不注入角色 ref |
| scene | 空镜；镜中写 `empty reflection, no person` | 禁止镜中脸/手；不注入角色 ref |
| character_base | 定脸肖像 | 无复杂手部 |
| composite | Beat 合成 | Beat 感知 Anchor + 过滤 ref + Guardrails |

**Beat1 瑕疵（防「受伤脸」）**：用 `2-3 small soft brown hyperpigmentation spots`；禁止叠加 `cluster + harsh shadow + moody contrast`。

| Beat 类型 | 建议 |
| --------- | ---- |
| Beat1 HOOK | **无手近景斑** 或 **单指触斑** 二选一；禁止同帧出现滴管/手背试质地 |
| Beat4 展示 | 滴管/手背试质地；禁止同帧出现「点斑指」 |
| 任意 Beat | 正提示追加：`exactly one hand action` / `maximum two hands visible` |

Beat 含 **拧瓶盖、涂抹、按压泵头** 等动作时，正提示词追加：

```text
clear hand anatomy, natural grip, five fingers, realistic hand pose, exactly one visible hand action
```

负向提示词已含 `extra fingers`；**Agnes 对 Negative 弱**，仍失败则：

1. **降景别**（只拍产品+部分手部，或 Hook 改无手版）
2. 相册 **删图** → 改 Prompt → 单条重跑
3. 系统已自动：Beat 感知 Anchor · ref 过滤 · `[Shot Guardrails]`

### 3.3 与剧本「随手拍」对齐

[风格 v1.2](风格-美妆种草60s-v1.md) 要求去摆拍感——提示词 **优先**：

```text
handheld camera slight motion blur, phone selfie angle, casual framing, not studio commercial
```

**减少**：`professional studio lighting, model pose, cinematic dolly shot`

## 5. 示例 Prompt（可复制）

### 5.1 Hook · 镜中斑（痛点展示）

```text
masterpiece, best quality, photorealistic, cinematic lighting, 8k, natural skin texture, vertical 9:16.

[Subject]: 25-year-old Asian woman, facing mirror, left cheek has visible dark spots and dull skin, right cheek slightly better, wearing simple home wear, expression slightly worried, light natural makeup.

[Environment]: Modern bedroom dressing table, warm desk lamp on wooden surface, messy skincare bottles in background, authentic lifestyle clutter.

[Lighting]: Soft side lighting, strong contrast between shadow and highlight, emphasizing skin texture and spots, moody but realistic.

[Composition]: Close-up shot, eye-level, shallow depth of field, focus on cheek spots, mirror reflection visible, handheld phone camera feel.
```

**Negative**: `worst quality, low quality, deformed, ugly, bad anatomy, extra limbs, extra fingers, watermark, logo, text, blurry, plastic skin, heavy makeup, studio advertising pose`

### 5.2 展示 · 产品钻光（信任建立）

```text
masterpiece, best quality, photorealistic, commercial product photography, 8k, vertical 9:16.

[Subject]: Shangyaxiu Diamond Radiance set — silver metallic rectangular outer packaging box,
round glass jar with reflective gold lid on smaller silver base, brand area blurred, no readable text.

[Environment]: Pure black background, minimalist style.

[Lighting]: Dramatic rim light, diamond-like reflection on silver box and gold lid, glowing premium feel.

[Composition]: Macro shot, shallow depth of field, focus on box shape and jar lid texture, bokeh background.
```

**Negative**: `worst quality, low quality, deformed, ugly, bad anatomy, extra limbs, watermark, logo, readable text, blurry, oversaturated, cartoon`

### 5.3 CTA · 手持产品对镜微笑

```text
masterpiece, best quality, photorealistic, soft natural light, 8k, vertical 9:16, handheld vlog style.

[Subject]: 28-year-old Asian woman, confident warm smile, looking directly at camera,
holding Shangyaxiu Precious Crystal Clear essence bottle (rose-gold cylindrical pump dispenser, 40ML)
gently against cheek, clear translucent skin, casual home wear.

[Environment]: Bright clean bedroom, heavily blurred background bokeh.

[Lighting]: Bright even front light, hopeful and clean atmosphere.

[Composition]: Medium close-up, eye-level, subject centered, specific product bottle visible in lower frame, shallow depth of field.
```
