# 剧本风格方向 · 美妆种草（30–60 秒推荐 · v1.2）

> **用途**：编剧 Skill 任务书引用；与 [评估 Rubric](评估-电商短视频Rubric-v1.md) 配套  
> **体裁**：竖屏 9:16 · **30–60 秒推荐**（允许至 75 秒）· 电商软性种草  
> **v1.2**：默认 **真人自述 / 随手拍**——去表演感、去广告腔；Beat 结构、产品镜头与 Rubric 硬性规则不变。

---

## 1. 定位

| 项 | 要求 |
|----|------|
| 性质 | **商业引流资产**——内容为人服务，人为货服务 |
| 受众 | 25–45 岁女性；黄黑皮、斑、敏肌、忙妈/上班族 |
| 人设 | **像熟人唠嗑**，不是代言人念稿、不是品牌广告片 |
| 语气 | 闺蜜分享，非柜姐推销；**第一人称「我」** 讲自己的经历 |
| **商业锚点** | **必达三要素**：fact_sheet 品名 + 1 主卖点 + 合规 CTA |
| **叙事呈现** | **vidu_audio**：Beat 写 **画面 + 旁白**；旁白由 Vidu 配音；禁止「画外音/OS」等元标签 |

### 1.1 口吻（去广告腔）

- 全部旁白用 **「我」** 讲体验：「我最大的感受是…」「对我来说完全不刺激」「我一般会…」
- **禁止**：指令/承诺腔——「你应该」「必买」「本产品能」「用了就…」「效果绝了」「一秒变白」
- **禁止**：文艺/端着腔——「光影流转」「肌肤苏醒」「邂逅」「焕新之旅」等书面广告词
- **推荐**：口语、短句、可带自然停顿（「嗯…」「说实话」「反正我…」）；像**边洗脸边聊**，不是背稿

### 1.2 画面（去摆拍感）

- **优先**：手持略晃、对镜自拍、随手拿起/放下产品、边洗脸边拍、手机支架视角
- **减少**：固定机位大全景、精心打光的「广告构图」、模特摆 pose、慢动作唯美空镜
- 产品展示仍须 **实体镜头**（手持/特写/质地）——拍法要像**自己录 vlog**，不是棚拍

### 1.3 信任（去夸张）

- 用 **真实个人感受** 代替夸张结论：「我摸着不黏」「我这边没泛红」优于「效果惊人」「立竿见影」
- 可承认个体差异：「我这支用着还行」「因人而异吧」——**不**做功效硬承诺（Rubric 仍禁止）

### 1.4 节奏（去赶场）

- Beat 之间允许 **自然停顿**；旁白不必句句填满秒数
- 单句宜短，宁可多停半拍，也不要连珠炮 Slogan

## 2. 禁止 vs 鼓励

**禁止（口播/字幕红线）**：具体价格、促销档位、**小程序名/搜索路径**、私信导流；功效硬承诺

**必须（商业锚点）**：展示 Beat **实体产品镜头** + 品名口播/字幕 + 合规 CTA

**可选（知识画面）**：栖月汇小程序 UI 屏录/截图 **≤3 秒**（公域），作肤质测试等过程展示；**口播仍不讲「打开小程序」**

**禁止（风格反模式）**：

| 反模式 | 说明 |
|--------|------|
| 广告/文艺腔 | 「你应该」「本产品能」；「光影」「邂逅」「焕新之旅」；固定机位摆拍描述 |
| 夸张种草 | 「效果绝了」「必入」「一秒变白」—— 改「我这边的感受是…」 |
| 元叙事标签 | 「画外音：」「OS：」—— 用 Beat「旁白」字段即可 |

## 3. 推荐节拍

见评估标准 §四（含 **60 秒五节拍** 与 **30 秒精剪四段**；展示 Beat 锚点必出现）。

## 3.1 同一母稿 · 三篇叙事（事前 / 事中 / 事后）

**一篇文库母稿 + 一份创作素材包**，可拆成 **三条独立短视频项目**（三份剧本），共用 fact_sheet / media_refs，**时间立场不可混用**。

| 篇章 | 核心立场 | 可选 Beat「购买/选品」 | 禁止 |
|------|----------|------------------------|------|
| **事前篇** | 有困扰 → 做功课 → **期待尝试** | **必备·因需寻品**：手机微信搜索「栖月汇」**画面**（≤3s）+ 肤质摸底；旁白讲功课 | 「打卡 N 天已白」「已经淡斑成功」 |
| **事中篇** | **已到手** → 开箱 → 在家使用 **全过程分享** | **分享导向**：展示「我怎么买/怎么选到的」；小程序 UI **≤3s 仅画面**，旁白/字幕不写路径 | 周期功效结论 |
| **事后篇** | **用了一阵** → 聊真实感受 | 通常**省略**；若提购买则一笔带过 | 60s 内从「刚买」跳到「一周必白」 |

**购买/选品——事前 vs 事中（关键区别）**：

| | 事前篇 | 事中篇 |
|---|--------|--------|
| **是否必备** | **必备 Beat**（共鸣与展示之间） | 可选 |
| **动机** | **因为有需要**而在找方向 | **分享**自己怎么买、怎么选 |
| **语气** | 「脸太黄了，想找个温和的…」「先做肤质摸底」 | 「我是在小程序里选到这套的，给你们看下过程」 |
| **小程序镜头** | 微信搜索框输入「栖月汇」+ 肤质测试 **≤3s 知识画面** | 同上，但叙事是**经验分享**，不是「四处寻医问药」 |
| **口播/字幕** | 仍 **禁止** 小程序名、搜索路径（Rubric §〇） | 同左 |

**栖月汇小程序**：公域仅 **≤3 秒** UI 一闪；口播/字幕 **不讲「打开栖月汇/搜小程序」**（见 Rubric「画面 vs 口播」）。

**运营指定方式**：编剧 Tab「叙事方向」下拉，或项目字段 `script_narrative_phase`（`before` / `during` / `after`）。

## 4. 口播风格

- 短句，每句 ≤ 20 字为宜
- **只用「我」** 讲经历；少用「咱们」推销感；禁止「本品」「该产品」
- 功效用「我用着…」「我这支…」「用了一阵我这边的感受是…」
- 允许自然停顿、口语填充词；**不要**广告 Slogan 或文艺文案腔

## 5. 镜头偏好

- **必拍**：展示 Beat 产品特写、质地涂抹、手持礼盒（来自 fact_sheet / media_refs）——**手机近拍、可略晃**，像随手录
- **优先**：对镜自拍、从台面随手拿起/放下、真实洗手台/梳妆台（生活杂物可入画）
- **减少**：固定机位大全景、电影感推拉、唯美慢镜空镜
- **可选**：栖月汇小程序界面 **知识性一闪**（≤3s），配合「先做肤质摸底」类叙事，非导流主视觉
- 单场景为主：梳妆台 / 洗手台
- 禁止：二维码特写、画面大字价格、小程序页占镜 >5s 且无产品上下文

## 6. 与 Rubric 的关系

- 本风格文档管 **怎么写**（人设、口吻、镜头、CTA 语气）
- Rubric 管 **能不能过**（禁词、产品镜头、CTA 形态、Beat 完整性）
- **v1.2 口径**：风格偏「真人唠嗑 / 随手拍」，Rubric 硬性规则（5 Beat、禁价禁路径、产品镜头等）**不变**
