## 3. L2 双引擎：补充定位焊死

```text
              流量入口
                 │
         ┌───────┴───────┐
         │   智能路由      │
         └───────┬───────┘
                 │
    ┌────────────┴────────────┐
    ▼                         ▼
┌─────────────┐       ┌─────────────────┐
│ L2 左引擎    │       │ L2 右引擎        │
│ Palantir AIP │       │ PPR+ANN+EGB     │
│ 检索 → 生成  │       │ 过滤→提纯→快决策 │
│ 【主路】     │       │ 【应急车道】     │
│ 环科院政策   │       │ 马帮直播弹幕     │
└──────┬──────┘       └────────┬────────┘
       └───────────┬───────────┘
                   ▼
            L1 OKF 本体（共享）
                   ▼
            L3 交互界面（统一展示）
```

| 维度 | 左引擎 AIP | 右引擎 自研 |
|------|-----------|------------|
| 关系 | **不是替代** | **是补充** |
| 链路 | 检索 → 生成 | 过滤 → 提纯 → 快决策 |
| 平时 | 主力 | 待命 |
| 洪峰 | 可降级 | 自动补位 |
| 话术 | 「我们拥抱 Palantir 最佳实践」 | 「我们解决国内电商实际痛点」 |

### 3.1 左右引擎切换阈值（补强 · 给技术方案用）

| 条件（满足任一可切右 / 快路径） | 动作 |
| --- | --- |
| **QPS > 10 万**（滑动窗口） | 洪峰流量优先右引擎过滤/提纯，左引擎保关键路径 |
| **端到端延迟目标 < 100ms** | 走右引擎快决策；左引擎异步补理由/溯源 |
| 左引擎错误率或超时上升 | RT-004 类路由降级到右引擎待命池 |
| 平时低并发 · 强推理 | **默认左引擎 AIP** |

> 目标态对外产品主叙事可以是「AIP 人工智能平台」；右引擎作为**性能与洪峰补位**保留在武器谱 / M7-6，技术方案分期落地（见 20）。
