# v0.1 开工编码规格（AOS 本地工作站）

> **文档性质**：可直接排 Sprint / 写代码的工程规格  
> **版本**：v2.5 · 2026-07-15（试用版 · **UI 与 foundry/html 目标版视觉强制对齐**）  
> **承接**：[10 · v0.1 技术方案](10-v0.1技术方案.md)（含 §0.3 UI 视觉规范）  
> **原则**：自有目录开发；三端可装；**页面风格与目标版 HTML 一致**  
> **工具**：[§12 Claudeskills](#12-claudeskills-可参考--直接用本机仓库内)

## 0. 技术栈（写死）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| UI Shell | **Tauri 2 + React（或 Vue）** | **三端打包**：Win / macOS / Linux；三栏布局 |
| Agent | **OpenOcta 本机二进制** | Skill `SearchKnowledgeDoc` → Dify；取各 OS 可用构建 |
| 知识 / RAG | **Dify 官方 Docker（本机）** | Compose 三端均可起；锁稳定 tag |
| 契约（对内） | `POST /v1/buddy/ask` | 可由 OpenOcta Skill 实现，或 `adapter/` 薄层；换脑不换 UI |
| IM | **不做** | 钉钉/企微/飞书 = Out of Scope |

产品名：**AOS 本地工作站** · 工程目录：`mybuddy-v01/`

### 0.1 开发组织方式（强制 · 与 10 对齐）

```text
日常写代码 → desktop / openocta-overlay / adapter / docs
上游引擎   → dify / openocta（配置与 API，不进主开发）
工具箱     → ../../claudeskills（捞脚本与方法，不进交付）
```

| 做 | 不做 |
| --- | --- |
| 在 `desktop/` 做 UI 与交互 | 把功能需求实现进 `dify/api`、`dify/web` 源码大改 |
| 在 `openocta-overlay/` 提交 Skill/配置模板 | 只在上游 `openocta/` 工作区改完不回灌 overlay |
| 控制台配 Dify 知识库/Prompt，DSL 导出到 `docs/dify-export/` | Fork Dify 当「我们的 AOS 本体层」长期分叉 |
| 需要时打开 claudeskills 跑 rag-architect 等 | 把 claudeskills 整仓打进安装包冒充产品能力 |
| **桌面逻辑跨平台**（无 Win-only 硬编码） | 只交付 Windows 安装包 |

**极小 patch 例外：** 上游仅允许为起服/私有化所必需的最小 diff，且必须书面记录；默认回归「配置 + 自有目录」。

### 0.2 跨平台安装要求（强制 · 与 10 §0.2 对齐）

| 平台 | 最低交付形态 | 验收 |
| --- | --- | --- |
| Windows | `.msi`/`.exe` 或便携 zip | 双击/解压可开 UI；Compose+Octa 可按文档起 |
| macOS | `.dmg` 或 `.app` | 同上（架构：arm64/x64 在交付说明中写清） |
| Linux | AppImage 或 deb/解压包（择一主推） | 同上 |

- 构建：`desktop/` 使用 Tauri 多目标；CI 矩阵产出三端产物。  
- 脚本：`scripts/win` · `scripts/mac` · `scripts/linux`（健康检查、提示起 Docker）。  
- **禁止**将「仅 Windows」写进验收；某一端暂缓须产品书面豁免，默认三端都要。

## 2. UI 规格（三栏 · 视觉强制对齐目标版）

> **设计源：** `docs/palantier/foundry/html/`（`index.html` · `workshop-aip-chat.html` · `assets/demo.css`）。  
> **原则：** 能力可为试用切片，**风格必须与目标版 AOS 深色壳一致**（详见 [10 §0.3](10-v0.1技术方案.md)）。

| 区域 | 内容 | 0.1 实现深度 |
| --- | --- | --- |
| **左** | 业务对象列表 | 静态 JSON / mock；点选 → Chat context 芯片；选中态左边框 cyan（对齐 `.agent-item.active`） |
| **中** | Chat 对话流 | 输入 → ask → answer；气泡/输入区用 slate 卡片边框 |
| **右** | Traceability | `citations[]` 卡片列表；无命中空态文案灰色 |

顶栏：产品名「AOS 本地工作站」· 健康状态（Dify / OpenOcta）· 高度与底边框对齐目标版 `h-14`。

### 2.1 设计 Token（从目标版抽取 · 写入 desktop）

| Token | 值（与 foundry/html 一致） |
| --- | --- |
| `--bg-app` | `rgb(2 6 23)` ≈ slate-950 |
| `--bg-panel` | slate-900 / `slate-900/80` |
| `--border` | `rgba(255,255,255,0.08)` |
| `--text-title` | gray-100 |
| `--text-body` | gray-400 |
| `--text-muted` | gray-500 |
| `--accent` | cyan-400 `rgb(34 211 238)`（见 `demo.css` `:root --accent`） |
| `--accent-buddy` | amber-300（AIP/Buddy 提示） |
| `--accent-onto` | violet（若展示本体相关标签） |
| 圆角 | `rounded-lg` / `rounded-xl` |
| 字体 | 系统栈与目标版一致（`-apple-system, Segoe UI, …`） |

**禁止：** 白底 Ant Design 默认皮、另套紫色霓虹主题、与目标版并排一眼可辨的两套产品。

**验收：** 截图对比 `workshop-aip-chat.html` vs `desktop` 三栏；评审人一眼应认为「同一 AOS 产品族」。

## 4. API 契约（冻结）

### 4.1 `POST /v1/buddy/ask`

```json
{
  "question": "OBJ-1001 的关键运行参数是什么？",
  "channel": "desktop",
  "user": { "id": "local", "display_name": "业务用户" },
  "session_id": "可选",
  "meta": { "object_id": "可选·左栏选中" }
}
```

```json
{
  "trace_id": "01Jxxxxx",
  "answer": "……",
  "citations": [
    { "doc_name": "….pdf", "page": 5, "snippet": "…", "score": 0.82 }
  ],
  "status": "ok|no_hit|error",
  "refuse_reason": null
}
```

| status | UI 行为 |
| --- | --- |
| ok | 中栏答案 + 右栏引用 |
| no_hit | 固定拒答文案；右栏空态说明 |
| error | 温和失败 + 提示检查 Docker/模型 |

### 4.2 OpenOcta Skill `SearchKnowledgeDoc`

- 输入：用户问题（+ 可选 object context）  
- 动作：HTTP 调 Dify `chat-messages`（或调本机 `adapter`）  
- 输出：映射为上述契约，供 Tauri 右侧面板消费  

### 4.3 健康检查

- Desktop 启动时探测：`DIFY` · `OPENOCTA`（或 adapter `/healthz`）  
- 任一 down → 顶栏红灯 + 一键「打开修复说明」

## 8. 非功能与安全

| 项 | 要求 |
| --- | --- |
| 监听 | 默认仅 `127.0.0.1` |

## 10. 建议开工顺序

```text
1. 起 Dify → 3 份文档 → 1 条金牌（Web）
```

## 12. Claudeskills 可参考 / 直接用（本机仓库内）

> 根路径：`claudeskills/`（与 `mybuddy-v01/` 平级）。  
> **没有** Dify / OpenOcta / Tauri 专用一键包；下列用于 RAG 调参、Prompt、安全与契约。

### 12.1 0.1 强烈建议用

| Skill | 路径 | 用法 |
| --- | --- | --- |
| **rag-architect** | `claudeskills/engineering/skills/rag-architect/` | chunking + retrieval 评测 → 回填 Dify |
| **senior-prompt-engineer** | `claudeskills/engineering-team/skills/senior-prompt-engineer/` | 拒答 / 引用 Prompt |
| **prompt-governance** | `claudeskills/engineering/prompt-governance/` | Prompt 版本化 + 金牌门禁 |
| **ai-security** | `claudeskills/engineering-team/skills/ai-security/` | 恶意 PDF 间接注入扫描 |
| **api-design-reviewer** / **api-test-suite-builder** | `claudeskills/engineering/skills/…` | 冻结并测试 `/v1/buddy/ask` |
