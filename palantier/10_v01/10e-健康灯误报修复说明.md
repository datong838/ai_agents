# v0.1 健康灯误报修复（桌面）

> 日期：2026-07-16  
> 现象：`start-all` / healthcheck PASS，桌面仍 **Dify down · 总览 red**；「刷新健康」看似无效。

## 根因

1. 桌面曾对 `http://127.0.0.1/` 做 `fetch(mode:cors)`。Dify nginx **无 CORS**，WebView 抛错 → 记为 down（假阴性）。Adapter `:8090/healthz` 有 CORS → 显示 up。  
2. `aggregateHealth` 把任一 `down` 记为 red；`openocta=unknown` 也会妨碍全绿。v0.1 以 **Dify + Adapter** 为关键依赖。  
3. 「Dify / Adapter」是状态文案不是按钮；仅「刷新健康」可点。

## 修复

- 健康只读 Adapter `GET /healthz`，用返回的 `dify_reachable`。  
- 总览仅看 dify + adapter；文案改为 正常/异常。  
- `start-dify.ps1` 的 volume chown 改为独立 `.sh`，避免 PowerShell 引号把 bash 弄断。
