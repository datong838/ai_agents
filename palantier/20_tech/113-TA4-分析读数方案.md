## 1. 目标 / 非目标

**目标（DoD）**

- `/analytics` 可 **试跑读数**：Object Type 列表抽样、单对象 get、Dataset Preview（经 `objectTypeHint` 落 PG）。
- 返回 **表格形** `{ columns, rows, total, source }`（pandas/Arrow 友好；Host JSON，不嵌内核）。
- `POST /v1/analytics/sql/preview`：**不再 501 stub**；支持 `select 1` 与「基于已加载抽样的 `select *`」；其它 SQL 诚实 **400**。
- 只读；写回仍仅 Draft（TA.5）。

**非目标**

- 真 Jupyter 单元格执行 / 客户机 pandas 进程。
- 任意 DuckDB SQL 方言全集（可选后置依赖；本刀零新包）。
- Draft 写回、Marking 导出治理加深（TA.5/6）。

## 2. 架构

```
/analytics UI
   │ 试跑读数 / 试 SQL
   ▼
aos-api Analytics Facade（只读）
   ├─ objects/list|get  → PG ObjectSet + Marking 脱敏
   ├─ datasets/preview  → dataset 元数据 + objectTypeHint → 同 list
   └─ sql/preview       → 白名单 SQL · 可绑 datasetRid/objectType 抽样
```

左栏片段（TA.3）中的 `aos.objects.*` / `aos.datasets.*` **由 Host 上述 API 兑现**（非边车内核）。

## 3. 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/analytics/objects/list` | `{ objectType, limit?, filters? }` → 表格 |
| `POST` | `/v1/analytics/objects/get` | `{ objectType, objectId }` → 单行 |
| `POST` | `/v1/analytics/datasets/preview` | `{ datasetRid, limit? }` → 表格 |
| `POST` | `/v1/analytics/sql/preview` | `{ sql, datasetRid?, objectType?, limit? }` |

**表格响应（统一）：**

```json
{
  "mode": "ta4-read",
  "kind": "objectType|object|dataset|sql",
  "columns": ["id", "type", "..."],
  "rows": [{ "...": "..." }],
  "total": 3,
  "source": "pg|dataset-hint|sql-literal",
  "objectType": "WorkOrder",
  "datasetRid": null
}
```

**SQL 白名单：**

| SQL（归一化） | 行为 |
|--------------|------|
| `select 1` | 一行 `{"v": 1}` |
| `select *`（需 `objectType` 或 `datasetRid`） | 返回对应抽样表 |
| 其它 | **400** `ANALYTICS_SQL_UNSUPPORTED`（提示用 objects/list 或收窄 SQL） |

禁止：DDL/DML 关键字（`insert`/`update`/`delete`/`drop`/`alter`/`attach` 等）→ 400。

## 4. Dataset Preview 策略

Dev Dataset 多为元数据（无 Parquet 湖文件）：

1. 查 `/v1/datasets` 同源目录得 `objectTypeHint`。
2. 有 hint → 按 OT `objects/list` 抽样，`source=dataset-hint`。
3. 无 hint → **200** 空表 + `detail=no objectTypeHint`（诚实，不造假行）。

## 5. UI

- 「试跑读数」：优先选中 Dataset → `datasets/preview`；否则选中 OT → `objects/list`。
- 「试 SQL Preview」：默认 `select 1`；若有上下文可跑 `select *`。
- 结果区展示 columns/rows（JsonBlock）；标明只读。

## 8. 风险

| 风险 | 缓解 |
|------|------|
| Dataset 无物理文件 | hint 抽样；无 hint 空表诚实 |
| SQL 能力窄 | 文档标明白名单；后续可加 duckdb extra |
| 与 object-sets 重复 | 复用 `_query_pg` + Marking；薄 Facade |
