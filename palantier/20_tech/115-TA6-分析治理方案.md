## 1. 目标 / 非目标

**目标（DoD）**

- 分析读数输出继续 **字段级脱敏**（复用 `apply_field_redaction`）；响应带 `governance.redactionApplied`。
- **导出**：`POST /v1/analytics/export` — 若结果含被脱敏字段 → **403** `ANALYTICS_EXPORT_FORBIDDEN`（拒绝把「残缺/涉密」表当完整导出）；全量可见时才允许 JSON 导出。
- **谱系可指**：`GET /v1/analytics/lineage?objectType=&objectId=` 列出该对象近期 `decision_lineage`；UI 链到 `/aip/lineage`。

**非目标**

- 新 Marking 引擎 / OpenFGA 模型扩展（沿用 TX.4）。
- 客户侧文件下载代理 / Excel 生成器。
- TA.7 演示故事编排。

## 2. 架构

```
读数 list/get/preview
   └─ apply_field_redaction → rows + _redactedFields
         │
         ├─ UI 展示（可含脱敏提示）
         │
         └─ POST /export
               ├─ 有 redacted → 403 ANALYTICS_EXPORT_FORBIDDEN
               └─ 无 redacted → 200 JSON 表

写回 approve（既有）
   └─ decision_lineage
         └─ GET /v1/analytics/lineage?objectType&objectId
```

## 3. 契约

### 读数响应增量（list/get/preview/sql 表格）

```json
{
  "governance": {
    "redactionApplied": true,
    "exportPolicy": "deny-if-redacted",
    "redactedFieldUnion": ["internalCost"]
  }
}
```

### `POST /v1/analytics/export`

| 字段 | 说明 |
|------|------|
| `objectType` | 与 list 同源抽样 |
| `datasetRid` | 可选；优先 dataset preview |
| `limit` | 默认 100 |
| `format` | 仅 `json`（本刀） |

- 403：存在 `_redactedFields` 非空  
- 200：`{ mode, format, columns, rows, total, governance }`

### `GET /v1/analytics/lineage`

| Query | 说明 |
|-------|------|
| `objectType` | 必填 |
| `objectId` | 必填 |
| `limit` | 默认 5，最大 20 |

返回 `{ mode: ta6-lineage, items: [{ id, draftId, actionTypeId, steps, ... }] }`。
