## 方案（最小改动）

| 项 | 落点 |
| --- | --- |
| 目录 API | `GET /v1/workspaces` → 含 **测试工作区**（`dev-project`，`deletable`）+ 生产运营工作区 |
| UI | `apps/web/src/components/WorkspaceSwitcher.tsx` 接入 `AppShell` topbar |
| 切区 | `setTenant` + `aos-workspace-changed`；`Outlet key=org:project` 强制刷新主列表 |
| 样式 | `styles.css` `.aos-workspace*`（对齐外观菜单模式，非卡片堆叠） |
