## 1. 目标（DoD）

| 项 | 验收 |
| --- | --- |
| 断网/API 不可达 | 主壳顶出现 **离线横幅**（UI-09） |
| 读 | 优先用本工作区 **只读快照**；无快照则可读失败提示，不伪造数据 |
| 写 | **禁止**直写生产；`POST/PUT/PATCH/DELETE` → **待同步队列** |
| 切区 | 队列/快照按 `orgId:projectId` 隔离；切区清他区缓存走 TWC.6 扩展 |
| 上线 | 「重试连接」探针；队列可 **手动冲刷**（成功一项删一项），禁静默全自动直写 |

## 2. 非目标（本刀不做）

- Tauri 侧 SQLite 落库（20c 目标态；本刀 Web/桌面同构用 **localStorage**，键带工作区前缀，后续可迁 SQLite 而不改 UI）
- 全站 Action Form / ACT-07 业务编排（仅提供队列与冲刷钩子）
- 托盘图标离线态细化（可复用 TWC.4 灯；本刀以横幅为准）

## 3. 架构

```
probeApiHealth + navigator.onLine
        ↓
  offlineStore（online | offline）
        ↓
┌───────┴────────┐
│ GET 成功 → 快照 │  写动词 + offline → enqueue（禁 fetch）
│ GET 离线 → 快照命中则返回 │
└────────────────┘
        ↓
 OfflineBanner：计数 · 查看队列抽屉 · 重试连接 · 冲刷
```

## 4. 落点文件

| 路径 | 职责 |
| --- | --- |
| `apps/web/src/lib/offlineStore.ts` | 在线态、事件 `aos-offline-changed` |
| `apps/web/src/lib/offlineQueue.ts` | 待同步条目 CRUD · 按工作区隔离 |
| `apps/web/src/lib/offlineSnapshot.ts` | GET 快照读写 · 按工作区隔离 |
| `apps/web/src/api/client.ts` | 读缓存 / 写入队；探针驱动在线态 |
| `apps/web/src/components/OfflineBanner.tsx` | UI-09 |
| `apps/web/src/lib/workspaceCache.ts` | 切区清 `aos.offline.*` 本前缀 |
| `*.test.ts` | 隔离 · 禁直写 · 横幅计数 |

桌面：嵌入 Web，无额外业务页；同构横幅即满足 D-A5 主路径。

## 5. 存储键

| 键 | 说明 |
| --- | --- |
| `aos.offline.queue.v1:{orgId}:{projectId}` | JSON 数组 |
| `aos.offline.snap.v1:{orgId}:{projectId}:{path}` | `{ body, savedAt }` |
| 单工作区快照上限 | 40 条；超限 FIFO 删最旧 |

队列条目：`{ id, method, path, body?, summary, createdAt }`。

## 6. 硬规则

- **禁止**离线时对生产 API 发起写请求  
- **禁止**切区后读到他区快照/队列（TWC.6）  
- 日志：`[aos-offline]` 仅 `org_id`/`project_id`/计数，无 token、无正文密钥  

## 7. 自测清单

1. `isOffline` 时 `apiPost` 不 `fetch`，队列 +1  
2. 切 `projectId` 后队列空（隔离）  
3. 在线 `apiGet` 写入快照；离线同 path 可读  
4. vitest 全绿  

## 8. 风险

| 风险 | 缓解 |
| --- | --- |
| localStorage 容量 | 快照条数上限；大 body 截断摘要 |
| 冲刷顺序冲突 | 按入队序；失败保留并标 `lastError` |
| 误当永久离线 | 横幅「重试连接」+ ApiStatusBar 并存（可达则静默 ApiStatus） |
