## 3. 清单与签名

```json
{
  "version": "0.2.1",
  "url": "https://updates.example/aos-desktop-0.2.1.dmg",
  "sha256": "…",
  "notes": "修复…",
  "force": false,
  "signature": "aos-v1:<hex>"
}
```

`canonical = version + "\\n" + url + "\\n" + sha256 + "\\n" + keyId`  
`signature = "aos-v1:" + hex(sha256(canonical + "\\n" + signingSecretId))`  

开发密钥 id 常量 `aos-desktop-dev-v1`（**非**私钥材料；生产换 cosign 公钥钉扎，换算法不改 UI）。
