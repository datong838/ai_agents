## 1. 目标

在既有 `/settings/local-platform`（TWB.3 文案页）上补齐 **UI-11 探活面板**：

| 项 | 行为 |
| --- | --- |
| 标题 | 恒为 `LOCAL_PLATFORM_NAME`（本机平台）；**侧栏 ∈ 运维交付**（[163](163-运维交付归口与禁演示临时候补方案.md)） |
| aos-api | 显示 Base + 可达/不可达（`probeApiHealth`） |
| 依赖 | 真端口探活 PG/MinIO；未齐则经 aos-api **自动 compose up**（[165](165-本机平台依赖自动拉起方案.md)）；失败如实显示 |
| 操作 | 「重新检测」· 「打开启停说明」链 72 |
| 桌面 | 托盘「本机平台」已深链本页（TWC.4）；本刀不改壳路由 |

## 2. 非目标

- 替代完整运维台 / Apollo Hub  
- 浏览器内直接执行 shell（一律经 `/v1/ops/local/deps/ensure`）  

## 3. 落点

| 路径 | 改动 |
| --- | --- |
| `LocalPlatformPage.tsx` | 探活态 · 自动 ensure · 文案 |
| `local_deps.py` · `ops_local.py` | 探活 / 拉起 API |
| 单测 | 页面文案 + API |

## 4. 硬规则

- 产品叙述不把本机平台叫 Apollo（工程注释可保留口径）  
- 仍只经 `aos-api`，不直连引擎  
- Banner **不含**「演示临时候补」话术（用户验收口径）
