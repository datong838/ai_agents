## 1. 目标

在既有 `/settings/local-platform`（TWB.3 文案页）上补齐 **UI-11 探活面板**：

| 项 | 行为 |
| --- | --- |
| 标题 | 恒为 `LOCAL_PLATFORM_NAME`（本机平台）；**禁** Apollo 作产品名 |
| aos-api | 显示 Base + 可达/不可达（`probeApiHealth`） |
| 依赖摘要 | 诚实：本刀不伪造 PG/MinIO 探活；提示按 72 检查 |
| 操作 | 「重新检测」· 「打开启停说明」链 72 |
| 桌面 | 托盘「本机平台」已深链本页（TWC.4）；本刀不改壳路由 |

## 2. 非目标

- 替代完整运维台 / Apollo Hub  
- 在浏览器内执行 `start-local` 脚本  

## 3. 落点

| 路径 | 改动 |
| --- | --- |
| `LocalPlatformPage.tsx` | 探活态 · 重测 · 72 链 |
| `productCopy.test.ts` / 新测 | 无 Apollo 产品名 · 有重测控件 |

## 4. 硬规则

- 界面产品叙述 **禁止**把本机平台叫 Apollo  
- 仍只经 `aos-api`，不直连引擎
