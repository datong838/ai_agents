## 目标

| SKU | `channel` | 默认 API Base | 欢迎页 |
| --- | --- | --- | --- |
| 私有化 | `private` | 空（须填） | 显示 UI-01 |
| SaaS | `saas` | 预置 SaaS URL | 可跳过欢迎（已有 Base） |
| 本机 | `local` | `http://127.0.0.1:8080` | 可跳过；露出本机平台 |

**同一安装器内核**；渠道 = 配置文件，不叉业务 UI。

## 落点

| 路径 | 职责 |
| --- | --- |
| `apps/desktop/src/channel.ts` | 读 `aos-channel-v1` / 构建注入 |
| `apps/desktop/channel.*.json` | 样例配置（local/saas/private） |
| `Welcome.tsx` | 渠道已预置 Base → 可「跳过」 |
| `apiBase` 启动时若空且渠道有默认 → 写入 |
| `channel.test.ts` | 三 SKU 解析 |

## 硬规则

- 不复制三套 Web 业务仓  
- 本机渠道文案仍用「本机平台」
