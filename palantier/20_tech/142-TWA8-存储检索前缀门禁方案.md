# 142 · TWA.8 存储/检索前缀门禁

> **版本**：v1.0.1 · 2026-07-19  
> **状态**：✅ 方案定稿 · ✅ 已编码 · ✅ 已自测  
> **对齐**：[20a](20a-多用户与工作区整站隔离方案.md) R-ISO-04 / P2 · [26 §14 TWA.8](26-AOS目标态开发计划.md) · TWA.5 [125](125-TWA5-漏网表读路径盘点销项方案.md)

## 1. 目标（DoD）

| 层 | 规则 | 验收 |
| --- | --- | --- |
| **对象存储** | Key = `{org_id}/{project_id}/mediasets/…` | put/get 拒他区前缀；媒体元数据带区 |
| **向量** | collection 强制租户前缀 `org__project__*` | upsert/search 他区名 → 403 |
| **Wiki** | 页带 `org_id`/`project_id`；读按区 | 跨区 GET → 404 |
| **迁移工具** | dry-run 报告无前缀 Key | 纯函数单测，不自动改生产数据 |

## 2. 非目标

- 历史 MinIO 对象全量搬迁脚本（仅 dry-run 报告）  
- 本体类型表全量加租户列（仍属 TWA.9 / 延期）  
- 端直连 MinIO/向量（仍禁）  

## 3. 前缀约定

```
object key:  {org_id}/{project_id}/mediasets/{rid}/{filename}
collection:  {org_id}__{project_id}__{logicalName}
wiki space:  wiki:{org_id}:{project_id}
```

非法字符在 org/project 中拒绝（仅允许 `[A-Za-z0-9._-]`）。

## 4. 落点

| 路径 | 改动 |
| --- | --- |
| `aos_api/tenant_prefix.py` | 前缀构建 · assert · dry-run |
| `aos_api/object_store.py` | `object_key_for` 带租户 |
| `aos_api/routers/wave_ext.py` | media / vector 接线 Principal |
| `aos_api/vector_index.py` | `resolve_tenant_collection` |
| `aos_api/db.py` + ontology/runtime_write | wiki 双字段 |
| `tests/test_twa8_tenant_prefix.py` | 门禁单测（无 MinIO/PG 也可跑纯函数） |

## 5. 硬规则

- **禁止**客户端传入任意 `objectKey` / collection 覆盖他区  
- 日志：`[aos-tenant-prefix]` 含 org/project，无密钥
