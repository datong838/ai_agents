## 1. 背景与分层

| 层 | 含义 | 本刀 |
| --- | --- | --- |
| A · 能力 | OIDC 验签 / claim / 关 Dev | 已有 |
| B · 本地伪生产 | 本机 `ALLOW_DEV=0` + Dev KC 真 JWT 走生产探针路径 | **本刀** |
| C · 客户现场 | 客户 issuer/JWKS/样例 token（用户计划：微商城线上案例） | **后序 · 不在本刀** |

[154] 已覆盖「拿真 JWT → `probe-prod-idp`」。本刀补齐：**显式拒绝 `Bearer dev`**、**`allowDevToken=false` 门禁**、**可复现脚本 + 无 Docker 常绿单测**。

## 2. DoD

| 项 | 验收 |
| --- | --- |
| `drill-local-pseudo-prod-idp.sh` | KC 起：临时 API（默认 :18080）`ALLOW_DEV=0` → `Bearer dev` **401** · OIDC JWT `/v1/me` **200** 且 `tokenKind≠dev` |
| 同上 · KC 未起 | **SKIP exit 0**（加 `--require` 则 FAIL） |
| pytest | 无 Docker：关 Dev 拒 `Bearer dev`；OIDC 形 JWT 仍可 `/v1/me` |
| `probe-prod-idp.sh --reject-dev` | `/v1/auth/oidc` 若 `allowDevToken=true` → FAIL |

| 默认演示 | `ensure-api` / `start-local*` **仍** `ALLOW_DEV=1` |

## 5. 临时 API 环境（伪生产）

```
AOS_AUTH_ALLOW_DEV=0
AOS_OIDC_ISSUER=http://127.0.0.1:8083/realms/aos
AOS_OIDC_AUDIENCE=aos-api
AOS_OIDC_JWKS_URL=…/certs
AOS_OIDC_TOKEN_URL=…/token
监听 127.0.0.1:18080（可用 AOS_PSEUDO_API_PORT 覆盖）
结束后杀临时进程；不碰 :8080
```
