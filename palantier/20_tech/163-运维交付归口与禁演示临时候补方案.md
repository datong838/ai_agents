## 1. 硬规则（已决）

### R-OPS-01 · 运维页统一归「运维交付」

侧栏分组 **`运维交付`**（`OPS_NAV_SECTION`，默认可收）收纳全部运维/交付面入口，包括但不限于：

- Apollo：Hub / Release / Spoke / Ferry / 资产包 / 变更 / 配置  
- SaaS 开通台  
- **本机平台**（原挂在顶栏「一般」区 → **迁入本分组**）

业务座舱（工作台 / AIP / 本体 / 数据）**不**再挂运维探活页。

### R-PROD-01 · 禁止演示临时候补

| 允许 | 禁止 |
| --- | --- |
| 正式产品页、可发布能力、Dev 鉴权开关（环境配置） | 「演示页 / 临时页 / 彩排按钮 / 一镜仅演示」端面 |
| `scripts/demo/*`、`/v1/demo/*` 作 **工程冒烟/种子**（不进侧栏推销） | 产品 UI 露出 ensure-seed / 业务一镜 / 「本环境演示」话术 |
| 案例数据进 **正式工作区**（如微商城案例） | 另开一套「演示导航」 |

续扫遗留文案：仍按 [75](75-去演示端面壳方案.md)；本刀不扩扫全站。
