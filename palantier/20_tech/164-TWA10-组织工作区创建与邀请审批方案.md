## 0. 一句话

| 能力 | 结论 |
| --- | --- |
| 新建组织 | 登录用户可 `POST /v1/orgs` → 自成为默认工作区 **owner** → 可立刻进入 |
| 新建工作区 | 组织内 **owner/admin** 可 `POST /v1/workspaces` → 创建者 owner |
| 邀请链接 | 组织管理员生成 token；持链用户 **接受** → 加入默认工作区 |
| 申请加入 | 非成员对可发现组织点「申请加入」→ 管理员 **批准/拒绝** |

## 1. 现状缺口（诚实）

| 已有 | 缺口 |
| --- | --- |
| `GET/POST …/enter` 切换组织、工作区 | **无** `POST` 创建组织 / 创建工作区 |
| 工作区目录硬编码两区 | 新工作区进不了目录 → 切换器看不见 |
| TWA.7 管理员可 **直接加 subject** | **无** 邀请链接、**无** 非成员自助申请 |
| SaaS `POST /v1/ops/tenants` | 运维开通台，**不是**业务用户自建组织 |

## 2. 产品口径

| 角色 | 动作 |
| --- | --- |
| 任意登录用户 | 新建组织；浏览可发现组织并申请；持邀请链接接受 |
| 组织内任一工作区的 owner/admin | 视为 **组织管理员**：建工作区、发邀请、批申请 |
| 普通成员 | 切已有组织/工作区；不可批申请 |

**加入策略（Org.joinPolicy）**

| 值 | 含义 |
| --- | --- |
| `invite_or_apply`（默认） | 可邀请 + 可申请（本刀默认） |
| `invite_only` | 仅邀请；申请接口 403 |
| `closed` | 仅管理员直接加员（TWA.7）；邀请/申请均关 |

种子组织默认 `invite_or_apply`。

**默认工作区**：新建组织时自动建 `dev-project`，显示名「默认工作区」（与历史种子「测试工作区」并存；种子 Org 不改名）。

## 3. API（MVP）

### 3.1 创建

| Method | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/orgs` | body `{ name, id?, joinPolicy? }` → org + `defaultProjectId`；caller = owner |
| `POST` | `/v1/workspaces` | body `{ name, id? }` → 当前 Org 下新工作区；需组织管理员 |

### 3.2 邀请

| Method | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/orgs/{orgId}/invites` | 生成邀请；需组织管理员；body `{ role?, projectId?, maxUses?, ttlHours? }` |
| `GET` | `/v1/org-invites/{token}` | 预览（需登录）；返回 org 名/角色/是否仍有效 |
| `POST` | `/v1/org-invites/{token}/accept` | 接受 → upsert 成员；返回 enter 载荷 |

### 3.3 申请

| Method | Path | 说明 |
| --- | --- | --- |
| `GET` | `/v1/orgs/directory` | 可发现组织列表（含未加入）；已加入标 `member: true` |
| `POST` | `/v1/orgs/{orgId}/join-requests` | 申请；已是成员 → 409；policy 不允许 → 403 |
| `GET` | `/v1/orgs/{orgId}/join-requests` | 待审列表；需组织管理员 |
| `POST` | `/v1/orgs/{orgId}/join-requests/{id}/decide` | body `{ decision: approve\|reject, role?, projectId? }` |

审计：`org.create` · `workspace.create` · `org.invite_create` · `org.invite_accept` · `org.join_request` · `org.join_approve` · `org.join_reject`。
