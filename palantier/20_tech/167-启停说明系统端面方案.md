## 1. 问题

「本机平台 → 打开启停说明」现为 `alert` 指向仓库路径 `72-….md`，运维/试用人员 **必须找文档**，不符合产品交付。

## 2. 已决

| 项 | 结论 |
| --- | --- |
| 形态 | Web **正式页** `/settings/ops-start-guide`（运维交付） |
| 分档 | 与 72 / 20a 一致四主档 + 气隙变体说明：①单机 ②标准企业 ③集团 ④SaaS · §气隙 |
| 内容 | 从 72 **摘录可操作摘要**进前端常量（非运行时读 md）；72 仍为工程真源 |
| 本机平台按钮 | **路由跳转**本页，废除「请在仓库打开」alert 主路径 |
| 真源关系 | 改脚本/端口仍回写 **72**；本页摘要随 72 大改再同步 |
