## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 先方案后编码 | 本文 |
| UI = 蓝图 [80] | 禁止 UA 默认白底按钮 |

| 不破坏 | 不改 API；已有 `btn*` 类名页不改语义 |

## 1. 审计结论

| 现象 | 根因 |
| --- | --- |
| 「新建组织」等大白块 | `<button>` **无 className** → 浏览器默认白底黑字 |
| 申请留言输入已暗色 | `aos-members-form input` 已有蓝图样式；**按钮未绑** |
| 蓝图目标 | [80]：`btn-nav` 导航 · `btn` 次要 · `btn-primary` 主操作 · `btn-outline-cyan` 强调次操作 |

### 本刀必改页（截图 + 同系）

| 页 | 路径 | 动作 |
| --- | --- | --- |
| 组织与加入 | `OrgMembershipPage.tsx` | 全部裸钮挂类 |
| 工作区成员 | `WorkspaceMembersPage.tsx` | 添加 / 移除 |
| 接受邀请 | `InviteAcceptPage.tsx` | 接受邀请 |
| 我的资料 | `MyProfilePage.tsx` | 保存 → `btn-primary` |

### CSS 兜底

| 规则 | 作用 |
| --- | --- |
| `button:not([class])` | 全站剩余裸钮对齐 `.btn`（暗底描边） |
| `.aos-members-form button` | 表单区内钮统一 |
| `.btn-danger` | 删除类操作：描边警示色（非白底） |

### 后置（不本刀）

Ontology / Data / AIP / Canvas 等已大量使用 `btn*` 或域内样式的页；若仍有裸钮，靠 CSS 兜底，深对齐另开刀。

## 2. 类名映射（本刀）

| 操作 | 类名 |
| --- | --- |
| 新建组织 / 工作区 / 生成邀请 / 添加成员 / 接受邀请 / 保存资料 | `btn-primary` |
| 清理数据 / 批准 / 拒绝 / 申请加入 / 移除 | `btn` |
| 删除组织 / 删除工作区 | `btn btn-danger` |
| 「工作区成员 →」等跨页 | `btn-nav`（`Link`） |
