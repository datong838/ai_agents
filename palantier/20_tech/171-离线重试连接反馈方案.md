# 171 · 离线「重试连接」反馈与 ensure-api

> **版本**：v1.0 · 2026-07-19  
> **状态**：✅ 方案定稿 · 可编码  
> **对齐**：TWC.8 OfflineBanner · [72](72-系统启停与健康检查手册.md) · [170](170-本机平台更名本机探活方案.md)  
> **点名**：用户 — 点「重试连接」也不行

## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 先方案后编码 | 本文 |
| 诚实 | 浏览器 **不能** 拉起本机 uvicorn；重试 = 再探活 |
| 最小 | 横幅反馈 + Hub 离线误导文案修正；不改离线队列协议 |

## 1. 根因

| 现象 | 原因 |
| --- | --- |
| 点「重试连接」无变化 | `probeApiHealth()` 失败时仍 offline；`setConnectivity` 同态早退 **无 UI 反馈** |
| API 真挂 | 须本机 `bash scripts/demo/ensure-api.sh`（或 start-local）；横幅无法代劳 |
| Hub 行误导 | API 离线时 `apiGet(/hub)` 失败，却提示 `start-local-native.sh` |

## 2. 已决

| 项 | 行为 |
| --- | --- |
| 重试中 | 按钮 disabled · 文案「探测中…」 |
| 仍失败 | 横幅旁显示失败摘要 + 指向 **启停说明** / `ensure-api.sh` |
| 成功 | 既有 `applyProbeResult(true)` → 横幅收起 |
| Hub | 若错误含「离线」→ 提示先恢复 aos-api，**不**提 native |

## 3. 落点

- `OfflineBanner.tsx`
- `LocalPlatformPage.tsx`（Hub catch hint）
- 72 §1.5 一句：离线重试 ≠ 自动 ensure
