## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 先方案后编码 | 本文 |

| 对齐蓝图暗色 | 字色/输入用 `--aos-text` / `--aos-input-bg` |

## 1. 根因

`main.tsx` 引入 `@aos-web/styles.css` → `body` 背景 `--aos-bg`（约 `#020617`）。  
欢迎/登录 `.aos-desktop-welcome` 写死 `color: #0f172a` → **深字压深底**，看起来黑乎乎。

## 2. 已决

| 项 | 值 |
| --- | --- |
| 欢迎/登录字色 | `var(--aos-text)` |
| 输入框 | 暗色蓝图输入（同 `aos-input`） |
| 主按钮 | 青主钮或浅描边可读 |
| 关于弹层 | 保持浅底（已可读） |
