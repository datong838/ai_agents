# 175 · 桌面座舱去工程条外观

> **版本**：v1.0 · 2026-07-19  
> **状态**：✅ 方案定稿 · 可编码  
> **对齐**：[20c](20c-AOS桌面端详细技术方案.md) §6.4 · [173](173-桌面欢迎登录产品话术方案.md)  
> **点名**：用户截图 —「你桌面这个样子」

## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 产品话术 | 座舱给人用，不像调试台 |
| 最小 | 收桌面顶条；概览「接口」不露工程错误原文 |
| 同构 | 仍嵌 Web；不拆第二套业务 UI |

## 1. 问题

| 现象 | 观感 |
| --- | --- |
| 顶条「Buddy 三栏 / 平台管理 / …」压在 Web 壳上 | 双顶栏 + 开发腔 |
| 「接口 · 离线且无缓存…」 | 把内部异常原文甩给用户 |
| 黄条暂无工单 | 可保留（业务提示），非本刀重点 |

## 2. 已决

| 项 | 行为 |
| --- | --- |
| 桌面顶条 | 只留 **关于**、**检查更新**；去掉默认可见的「Buddy 三栏」 |
| 平台管理 | 仍可进（克制）：改为次要或保留一钮「管理」不写 Hub/Buddy |
| 接口指标 | `ok/healthy`→「正常」；其它→「暂不可用」（禁贴 Load failed / 离线且无缓存） |

## 3. 落点

- `App.tsx` 顶条  
- `OverviewDomainGrid.tsx` 接口文案
