# 176 · 桌面主内容区铺满

> **版本**：v1.0.1 · 2026-07-19  
> **状态**：✅ 方案定稿 · 已编码  
> **对齐**：[20c](20c-AOS桌面端详细技术方案.md) · [175](175-桌面座舱去工程条外观方案.md)  
> **点名**：用户 — 右边没有两边展开；**Cmd+R 没效果**

## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 最小 | 仅桌面壳覆盖 `.content-inner`；Web 浏览仍可保持阅读宽 |
| 产品 | 桌面窗口要铺满可用宽度 |

## 1. 根因

Web `.content-inner { max-width: 72rem; margin: 0 auto; }` → 宽屏左右留白。桌面窗口更宽时右侧空洞明显。

## 2. 已决

桌面 `.aos-desktop-webhost .content-inner`：`max-width: none; width: 100%; margin: 0;`

## 2.1 刷新（v1.0.1）

Tauri 壳 **不是** Safari/Chrome，系统 **默认无 Cmd+R**。  
桌面前端监听 `Meta+R` / `Ctrl+R` → `location.reload()`。

若热更新未带上本文件：关掉桌面窗口，在终端里停掉再跑一次 `npm run tauri dev`。

## 3. 落点

`apps/desktop/src/desktop.css` · `apps/desktop/src/main.tsx`
