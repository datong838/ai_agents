> **点名**：用户 — 顶端挤压重叠

## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 最小 | 调 `.topbar` 高度/换行；桌面隐藏装饰性搜索 |
| 不破坏 | 组织/工作区切换功能保留 |

## 1. 根因

`.topbar { height: 3.5rem }` 固定高度 + 右侧控件多（环境/组织/工作区/平台/搜索/外观）→ 挤爆后 **叠画**。

## 2. 已决

| 项 | 行为 |
| --- | --- |
| topbar | `min-height` + `height: auto` + `flex-wrap` |
| breadcrumb / actions | `min-width: 0`；actions 可换行右齐 |
| 桌面 | 隐藏占位搜索框（本就 disabled）减负 |

## 3. 落点

`styles.css` · `desktop.css`
