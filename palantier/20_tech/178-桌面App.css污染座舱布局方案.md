# 178 · 桌面 App.css 污染座舱布局

> **版本**：v1.0 · 2026-07-19  
> **状态**：✅ 方案定稿 · 可编码  
> **对齐**：[176](176-桌面主内容区铺满方案.md) · [177](177-顶栏防挤压重叠方案.md)  
> **点名**：用户 — 顶端乱了、右边也没铺开（改 CSS 仍无效）

## 使用的 Rules

| Rule | 应用 |
| --- | --- |
| 诚实 | 根因是 **Buddy 遗留 App.css 全局污染**，不是用户没刷新 |
| 最小 | 作用域化 App.css；加固 desktop 铺满 |

## 1. 根因

`BuddyLegacyApp.tsx` 被 `App.tsx` **静态 import** → 即使不进 Buddy，也会执行 `import "./App.css"`。

`App.css` 全局定义了：

| 选择器 | 破坏 |
| --- | --- |
| `.topbar { height: 56px }` | 盖掉 Web 可换行顶栏 → 挤压重叠 |
| `.main { display:grid; 240px 1fr 280px }` | 把座舱主区掰成三栏 → 右侧铺不开、中间变窄 |

## 2. 已决

| 项 | 行为 |
| --- | --- |
| App.css | 全部规则挂在 `.buddy-legacy-shell` 下 |
| Buddy 根节点 | `className="buddy-legacy-shell app-shell"` |
| desktop.css | `#root`/`.layout`/`.content-inner` 铺满加固 |

## 3. 自检

- [ ] 座舱顶栏不重叠  
- [ ] 主内容区横向铺满（侧栏右侧）  
- [ ] Buddy 三栏模式样式仍可用
