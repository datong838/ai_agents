## 0. 红线（已决）

```text
平台技术方案 / aos-platform 代码
  = 通用能力（任意 Org · 任意外部 JDBC/文件源 · 任意行业）

外部案例目录（如 niushop电商案例/）
  = 仅用平台做「尽量全面」的功能验证夹具与临时脚本
  ≠ 平台方案正文；≠ 定制开发理由
```

| 允许 | 禁止 |
|------|------|
| 通用：JDBC 多表、Ontology、Action、Function、LLM Wiki、OKF、Agent Studio、模型实验… | 平台文档/代码出现具体商城品牌名 |
| 案例目录写物理世界画像、临时代手工脚本 | `if <行业>` / `<品牌>-connector` Host 分支 |
| 用案例验收 **平台** DoD | 为单一客户改产品主路径 |

**验证定位（182w）：** 外部库 → 数字孪生与本体 → Action / Function → LLM Wiki / OKF → Agent Studio / 模型实验等，**尽量拉全矩阵**；案例只是供数方。
