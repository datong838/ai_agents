## 1. 定位

> 用 **任意** 外部业务库（经 JDBC/隧道）+ 文件夹具，在 **某一 Org 的测试工作区** 内，尽量全面验证 AOS：  
> **数字孪生 → Ontology → Action / Function → LLM Wiki / OKF → Agent Studio / 模型实验** 等。

外部案例目录只提供：表结构说明、Excel/Media 夹具、**临时代手工脚本**。  
**平台方案与代码不出现、不依赖具体商城品牌。**

---

## 2. 目标 / 非目标

### 2.1 目标（平台 DoD）

| 面 | DoD（通用） |
|----|-------------|
| **数据孪生** | JDBC Source 绿；关键域表 Dataset；全字段 ingest（`includeAll`+`idField`）；Excel/Media 可对照 |
| **Ontology** | OT / Link / 属性 displayName；对象可检索 |
| **Action / Function** | 至少一条 Draft 写回纪律；Function 只读查询可调 |
| **LLM Wiki** | Wiki 只读可展；写经 Action/Draft |
| **OKF** | Constitution / 包绑定可校验（对齐既有 T2/T5） |
| **Agent Studio** | Agent 经 Tool Registry 调 Query/Function/Action/Wiki（不直连引擎） |
| **模型实验** | 网关路由 / Eval 或实验页至少一条可跑（对齐既有 LLM 网关刀） |
| **态势** | COP / Inbox / Schedule 批式可感知新对象（口径诚实） |

### 2.2 非目标

- 行业专用 Connector / Action 包名。  
- 支付/库存反写外部生产库（高门槛后置）。  
- 宣称「某客户全表零遗漏 OT」。

## 4. 脚本与平台分层（硬约束）

| 层 | 放哪 | 性质 |
|----|------|------|
| **临时脚本** | **仅** 外部案例目录 `…/scripts/` | 代手工调 `/v1/sources|pipelines|syncs|connectors/…`；**禁止**进 `aos-platform` |
| **平台能力** | `aos-platform` | 通用：`table` · `includeAll` · `idField` ·（183w）`query`/Join |
| **禁止** | — | 品牌/行业 `if`；脚本直写 PG；产品假保存 |

已落地（通用）：jdbc probe/ingest 请求体支持 `table` / 连接覆盖 / `includeAll` / `idField`。

### 4.1 本刀平台补齐（通用 · 解锁脚本全栈）

| 能力 | API / 行为 | 用途 |
|------|------------|------|
| ingest 自动建 OT | `autoCreateObjectType: true` | 解除 `obj_instance` → `meta_object_type` FK |
| 租户戳记 | ingest 写入 props `_aosOrgId` / `_aosProjectId` | 工作区溯源（不全表改 PK） |
| Link 实例写入 | `POST /v1/ontology/edges`（batch upsert `graph_edge`） | VERIFY.2 分表+Link |
| Schedule 执行 | `POST /v1/schedules/{id}/run` + 创建时 `ingest` 规格 | VERIFY.3 批式拉数（非真 cron，可点跑） |

案例 E2E 脚本（临时）：`niushop电商案例/scripts/qyh_bootstrap_e2e.py`  
编排：Org/测试工作区 → JDBC → OT/Link → Module Inbox → Draft/Action → Tool/Chat → Funnel。

### 4.2 UI 可读性（数据集预览等 · 本刀）

| 问题 | 修法 |
|------|------|
| 全局正文默认 `--aos-muted` 发灰 | `body` 主色改 `--aos-text`；次要信息仍用 `.muted` |
| 列表 `nav-link` 无样式、只见 `pipe-qyh-ns_* · READY` | 补 `.nav-link`；左栏中文名 + OT + 状态；`BpSplit` 主从 |
| 预览 Tab 假工单行（违上线态） | 去掉硬编码；`datasets/preview` 或 `objects/list` 真行 |
| Dataset 无 `objectTypeHint` | `POST /v1/pipelines` 接受 hint/name；脚本回写 |

## 5. 配置要点（摘要 · 无品牌）

| 项 | 做法 |
|----|------|
| 连接 | 环境变量或请求体：`host/port/user/password/database`；凭据不入库 |
| 多表 | 每表一次 ingest；或等 183w 后用 SQL/Join |
| Excel | 中文表头（COMMENT）+ 英文字段行 + 字段词典 → OT displayName |
| 写回 | 仅 Annotate* → Draft |
| 租户 | 在目标 **Org** 的 **测试工作区**（`X-Org-Id` / `X-Project-Id`）下跑 |
