## 二、Phase 1：基础增强（Q3-W1 ~ Q3-W2）

### 2.1 目标

完善 AIP Logic 核心能力，使其达到生产可用水平。

### 2.2 里程碑

**M1-1**：Logic LangGraph 运行时接入  
**M1-2**：ProposeEdits 功能实现  
**M1-3**：Wiki 字段支持  
**M1-4**：Logic 版本管理与状态管理  
**M1-5**：调试器增强（CoT 展开 / 工具调用追踪）

### 2.3 详细任务

| 任务 | 优先级 | 预估工时 | 依赖 | 交付物 |
| --- | --- | --- | --- | --- |
| 接入 LangGraph 运行时 | P0 | 3d | 后端 LLM 网关 | Logic 执行引擎 |
| 实现 ProposeEdits Block | P0 | 3d | LangGraph 运行时 | 提议编辑预览 |
| Get Object Property 添加 Wiki 字段 | P0 | 2d | Ontology API | Wiki 字段支持 |
| Logic 状态管理（草稿/发布/废弃） | P1 | 2d | 后端 API | 状态流转 UI |
| Logic 版本管理与回滚 | P1 | 3d | 状态管理 | 版本历史页 |
| 调试器 CoT 展开增强 | P1 | 2d | LogicPage | CoT 可视化 |
| 调试器工具调用追踪 | P1 | 2d | CoT 展开 | 工具调用链 |

### 2.4 验收标准

- Logic 可正常执行并写回 Ontology
- ProposeEdits 可预览编辑建议（不真写）
- Get Object Property 可选择 Wiki 字段
- Logic 支持版本历史查看和回滚
- 调试器可展开完整 CoT 和工具调用链

## 三、Phase 2：生产安全（Q3-W3 ~ Q3-W4）

### 3.1 目标

构建生产级安全保障体系，实现 Evals 门控和 L4 自动化熔断。

### 3.2 里程碑

**M2-1**：Evals 评测集管理  
**M2-2**：Evals 门控上线机制  
**M2-3**：跨模型对比评测  
**M2-4**：评测指标仪表盘  
**M2-5**：Chatbot Studio L4 门控检查  
**M2-6**：L4 自动化熔断

### 3.3 详细任务

| 任务 | 优先级 | 预估工时 | 依赖 | 交付物 |
| --- | --- | --- | --- | --- |
| Evals 评测集 CRUD | P0 | 3d | 后端 API | 评测集管理页 |
| Evals 门控上线机制 | P0 | 2d | 评测集 | 生产阻断逻辑 |
| 跨模型对比评测 | P0 | 3d | 评测集 | 对比报告 |
| 评测指标仪表盘 | P1 | 2d | 评测集 | 通过率/准确率展示 |
| RAG 评测类型 | P1 | 3d | 评测集 | 检索质量评估 |
| 生成评测类型 | P1 | 3d | 评测集 | 内容质量评估 |
| 工具调用评测类型 | P1 | 3d | 评测集 | 工具调用正确性评估 |
| Chatbot Studio L4 门控检查 | P0 | 2d | Evals 门控 | L4 门禁检查 |
| L4 自动化熔断（失败率>5%降级） | P0 | 3d | 可观测性 | 熔断状态机 |
| Application State 管理 | P1 | 3d | Chatbot Studio | 应用变量管理 |
| RAG 检索上下文增强 | P1 | 2d | 知识库 | 召回率优化 |
| 长期记忆管理 | P1 | 2d | 线程存储 | 长期记忆 |

### 3.4 验收标准

- 未过 Evals 门禁的 Logic 不可挂生产 Automate
- 支持 GPT-4 vs 3.5 等跨模型对比
- 仪表盘展示通过率/准确率/F1/召回率
- L4 Agent 失败率 >5% 自动降级到 L3
- Chatbot Studio 支持 Wiki 字段优先

## 四、Phase 3：能力扩展（Q4-W1 ~ Q4-W2）

### 4.1 目标

扩展 AIP 平台能力，增加可观测性、分析助手、文档智能等模块。

### 4.2 里程碑

**M3-1**：AIP Observability 可观测性平台  
**M3-2**：Model Catalog 模型目录  
**M3-3**：AIP Assist 平台级智能助手  
**M3-4**：AIP Analyst 分析助手  
**M3-5**：AIP Document Intelligence 文档智能

### 4.3 详细任务

| 任务 | 优先级 | 预估工时 | 依赖 | 交付物 |
| --- | --- | --- | --- | --- |
| Logic 执行链路追踪 | P0 | 3d | LangGraph | 追踪面板 |
| 指标监控（token/延迟/成本） | P0 | 2d | LLM 网关 | 指标采集 |
| 可观测性仪表盘 | P0 | 3d | 指标采集 | 统一视图 |
| 告警系统（阈值告警） | P1 | 2d | 指标采集 | 告警规则 |
| Model Catalog 模型登记 | P1 | 3d | 模型网关 | 模型目录页 |
| 模型容量管理（Rate Limits） | P1 | 3d | 模型网关 | 容量控制 |
| 模型生命周期管理 | P1 | 2d | 模型登记 | 状态流转 |
| AIP Assist 全局上下文 | P1 | 4d | Ontology | 跨应用理解 |
| AIP Assist 权限感知 | P1 | 3d | 权限系统 | 数据权限过滤 |
| AIP Analyst 自然语言到图表 | P2 | 4d | Workshop | NL2Chart |
| AIP Analyst 数据探索 | P2 | 3d | NL2Chart | 自动发现 |
| Document Intelligence 文档解析 | P2 | 3d | 文档服务 | PDF/Word/图片解析 |
| Document Intelligence 信息提取 | P2 | 3d | 文档解析 | 表格/表单提取 |
| Document Intelligence 语义理解 | P2 | 4d | 信息提取 | 文档问答 |

### 4.4 验收标准

- 可观测性仪表盘展示完整的 token 用量/延迟/成本
- Logic 执行链路可追踪到每一步
- 模型目录支持版本管理和容量控制
- AIP Assist 仅回答有权限的数据
- AIP Analyst 可根据自然语言生成图表
- Document Intelligence 可解析 PDF 并提取表格

## 六、风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
| --- | --- | --- | --- |
| LangGraph 接入复杂度高 | 中 | 高 | 先做最小可行接入，逐步扩展 |
| Evals 评测指标设计 | 中 | 中 | 参考官方指标体系，先实现核心指标 |
| 性能瓶颈（LLM 延迟） | 高 | 高 | 引入缓存、预热、异步处理 |
| 数据权限安全 | 高 | 高 | 严格权限校验，敏感数据脱敏 |
| 文档解析准确性 | 中 | 中 | 多引擎对比，选择最佳方案 |
