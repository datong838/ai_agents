## 四、系统性问题根因

### 4.1 圆角不一致（最影响"精细感"）
```
Foundry 规范：2px（卡片/节点） / 4px（按钮）
React 实际：  4-12px（各页自定义，无统一标准）
```
**根因**：缺少全局 `.p-card` / `.p-btn` 基础类，每个页面用 inline style 各自定义圆角。

### 4.2 Hover 反馈缺失
Foundry 设计中每个可交互元素都有 hover 反馈（border 变色 + 微阴影）。React 实现中约 60% 的卡片/节点缺少 hover。

### 4.3 间距偏松
Foundry 使用紧凑间距（10-14px），React 习惯用 16px 起步，导致内容密度不够、显得"空旷不专业"。

### 4.4 字号层级过多
Foundry 严格 3 级（正文 13px / 辅助 12px / 微标注 11px），React 各页自创 4-5 级字号。

### 4.5 CSS 类未同步
部分页面（如对象探索）直接从 HTML 复制了类名（`.p-objx-*`），但 React 端 styles.css 从未定义这些类。

## 六、建议执行方案

1. **Phase 1**：在 styles.css 中定义全局基础类（`.p-card` 2px 圆角、`.p-btn` 4px 圆角、`.p-hover-card` hover 效果）
