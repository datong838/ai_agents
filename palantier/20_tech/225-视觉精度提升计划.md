## Phase 1：全局基础对齐（最高优先级）

> **原则**：修 1 处全局样式 → 全站 66 页自动受益

### 1.1 Shell 修复 — 顶栏精简

**目标**：从 5 控件 → 2 控件，搜索框居中

| 变更 | 详情 |
|------|------|
| 顶栏右侧只保留 | `WorkspaceSwitcher` + 主题切换 |
| 移入用户菜单 | `OrgSwitcher`、`PlatformBaseSwitcher`、`EnvReadonlyBadge` |
| 搜索框 | 三栏布局（left/center/right），center 独立居中，max-width: 480px |
| 去掉 flex-wrap | `flex-wrap: nowrap`，禁止折行 |
| 搜索框启用 | 去掉 `disabled` + `aria-hidden`（至少视觉可用） |
| 面包屑分隔符 | chevron → 文字 `/`（11px，与视觉稿一致） |

**涉及文件**：
- `apps/web/src/shell/AppShell.tsx`（结构调整）
- `apps/web/src/styles.css`（.topbar 三栏布局）

### 1.2 Shell 修复 — 侧边栏对齐

| 变更 | 视觉稿值 | 当前值 |
|------|---------|--------|
| 导航项 padding | `8px 16px` | `8px 12px` |
| 图标-文字 gap | `10px` | `8px` |
| active 指示条 | 满高 `top:0;bottom:0` 无圆角 | 居中 `height:20px` 圆角 |
| 分组标题 | 正常大小（无 uppercase） | `text-transform: uppercase` |
| 折叠时隐藏 section toggle | 有 | 缺失 |

**涉及文件**：`apps/web/src/styles.css`（.aos-nav-* 样式）

### 1.3 Bp 组件圆角对齐

**这是影响面最大的变更**——所有使用 BpCard 的页面都会受益。

| 组件 | 视觉稿圆角 | 当前圆角 | 修改后 |
|------|-----------|---------|--------|
| `.bp-card` | 2px | **4px** | → 2px |
| `.bp-card-pad-md` body padding | 14px | **16px** | → 14px |
| `.bp-card-pad-lg` body padding | 20px | **16px** | → 20px |
| `.bp-toolbar` 圆角 | 无 | 有 | → 去掉 |
| 按钮 `.p-btn` | 4px | 不统一 | → 统一 4px |

**涉及文件**：`apps/web/src/styles.css`（.bp-card-* 样式）

### 1.4 全局 hover 反馈类

新增 `.bp-hover-card` 通用类：
```css
.bp-hover-card {
  transition: border-color 0.15s, box-shadow 0.15s;
}
.bp-hover-card:hover {
  border-color: var(--aos-accent-border);
  box-shadow: 0 2px 8px rgba(0,0,0,0.06);
}
```

| 正文 | 13px | 描述/表格 |
| 辅助 | 12px | meta/时间 |
| 微标注 | 11px | badge/tag |

### 间距
| 用途 | padding |
|------|---------|
| 卡片体 | 14px |
