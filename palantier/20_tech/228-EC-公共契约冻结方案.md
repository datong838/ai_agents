## 一、冻结结论

### 1.1 能力 ID 与平台数量

代码和接口使用稳定命名空间，不再使用含义冲突的 G9/G10：

| 能力 | canonical ID |
|---|---|
| REST 只读 | `ec.connector.rest.read` |
| OAuth 授权与刷新 | `ec.auth.oauth2` |
| 平台签名 | `ec.auth.signed-request` |
| GraphQL 只读 | `ec.connector.graphql.read` |
| Webhook 接收 | `ec.connector.webhook.receive` |
| 增量一致性 | `ec.sync.incremental` |
| 核心本体 | `ec.ontology.core7` |
| Pipeline 真实执行 | `ec.pipeline.evidence` |

G1-G20 只保留为历史文档别名，不进入代码、权限或配置主键。平台口径固定为：7 个独立技术适配对象；8 个方案目录（含天猫指向目录）；9 个规划入口（再含尚无 P0 方案的快手）。本 Wave 不实现其中任何适配对象。

### 1.2 租户与外部身份

- 公共 `workspace_id` 对应现有 `project_id`；内部安全作用域必须同时包含 `org_id`，不得假设 `project_id` 全局唯一。
- 公共身份：`(workspace_id, platform, shop_or_marketplace_id, external_id)`。
- 内部唯一身份：`(org_id, workspace_id, platform, shop_or_marketplace_id, external_id)`。
- `platform` 小写并去首尾空白；其余 ID 只去首尾空白、保留大小写；任一字段为空均拒绝。
- 缓存、Token、Checkpoint、对象、Link、Trace、Memory、Eval 必须使用内部安全作用域。

### 1.3 TaskStatus 与 TAOR

canonical 状态：`pending`、`planning`、`awaiting_approval`、`approved`、`executing`、`paused`、`completed`、`failed`、`cancelled`、`rolled_back`。

- 终态：`completed|failed|cancelled|rolled_back`。
- 主链：`pending→planning→awaiting_approval→approved→executing→completed|failed`。
- `planning|awaiting_approval|approved|executing→cancelled`；`executing→paused→executing`；已完成任务可由受控回滚动作进入 `rolled_back`。
- 旧值：`created→pending`；其余已在 canonical 集合中的旧值保持不变。
- 重复提交到当前状态按幂等处理；非法跳转返回稳定冲突错误，不静默改状态。
- TAOR 的单步执行与 until-complete 共用同一转换表，不能各自定义状态机。

### 1.4 Money

- API/模型以 Decimal 主单位字符串表达，禁止用二进制 float 参与金额运算。
- 币种使用大写 ISO 4217；CNY/USD 默认 2 位，JPY 0 位，未知币种必须显式给 scale。
- 量化使用 `ROUND_HALF_EVEN`；序列化保持币种规定的小数位。
- 不同币种禁止直接相加；`MoneyBag` 按币种分桶。
- 汇率换算必须携带 `source`、`as_of`、原币种、目标币种和 Decimal rate。

### 1.5 Time 与稳定游标

- 输入必须是带时区 ISO8601；naive 时间拒绝。
- 内部比较统一 UTC，同时保留原始时区/offset。
- 稳定游标固定为 `(source_updated_at_utc, external_id)`，按时间后按 ID 排序。
- 同毫秒多对象不得遗漏；序列化必须确定性。

### 1.6 Enum 与 Error

- 外部枚举统一为 `canonical_value + raw_status + unknown`；未知值映射 `unknown` 且保留原文，不因平台新增值中断只读同步。
- 错误信封固定为 `{code,message,details,traceId}`。
- Token、Secret、Authorization、Cookie、密码及常见 PII 在嵌套结构、校验错误、日志中递归脱敏。
- 未处理异常对外只返回稳定 500 信息，不回显异常正文；内部日志也不得记录敏感正文。
