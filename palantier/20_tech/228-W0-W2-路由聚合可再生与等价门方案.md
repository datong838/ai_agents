# 228-W0-W2 路由聚合可再生与等价门方案

> 日期：2026-07-31
> Worker：W2 / `aos-platform-w2` / `feature/223-worker-2`
> 基线：`14e6bb2`
> 状态：已合并并通过 Wave 0 最终回归

## 1. 目标

把当前不可再生的 505 Router 聚合文件改为“稳定 manifest → 确定性生成 → 动态等价验证”，防止新增/移动 Router 时静默遗漏、重复或改变路由顺序。

## 2. 设计

### 2.1 单一事实源

新增机器可读 Router manifest，至少记录：

- domain
- module import path
- router attribute
- registration order
- 可选说明

生成器只读取 manifest，不再从生成后的 `main.py` 反向解析。

### 2.2 确定性生成

- 相同 manifest 连续生成两次内容一致。
- domain 内保持原注册顺序。
- import 和 include 规则统一，消除重复 import。
- 生成文件标注“勿手改”和来源。

### 2.3 等价门

测试比较：

- manifest router 数量及唯一键。
- import 可用性。
- `(path, methods, name)` 集合。
- 重复 method+path。
- 关键业务路径。
- OpenAPI 可生成性与 tags 变化。

本 worker 可先完成静态测试；动态 app 测试在 W1 合入修复依赖后由总控复跑。

## 3. 文件所有权

可修改：

- `services/aos-api/aos_api/main.py`
- `services/aos-api/aos_api/routers/domain_aggregates.py`
- 新增 Router manifest
- `scripts/generate_domain_aggregates.py`
- 新增路由专项测试

禁止修改：

- `pyproject.toml`、`alembic/**`、`migrations.py`
- `scripts/ci.sh`
- 前端、package manifests、部署文件
