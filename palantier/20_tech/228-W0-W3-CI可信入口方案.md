## 1. 目标

修复统一 CI 入口的根路径错误，建立可组合、不可静默跳过、退出码可信的 quick/full 门禁。

## 2. 当前问题

- `scripts/ci.sh` 把 `ROOT` 指向 `scripts/`。
- 后端子脚本路径变成 `scripts/scripts/ci/run-pytest.sh`。
- Web 目录误判不存在，Vitest/tsc 被跳过。
- 必需工具缺失可能被当作 skip。
- 当前没有远端 workflow，本波先保证本地统一入口可信。

## 3. 设计

### 3.1 模式

| 模式 | 内容 |
|---|---|
| `quick` | 语法/静态检查 + 目标专项测试 |
| `wave` | 后端目标域 + Web/Desktop/SDK 受影响域 |
| `full` | 后端全量、Web、Desktop、SDK、typecheck/build 和安全/契约扩展钩子 |

### 3.2 执行原则

- 从脚本路径推导 repo root，与调用 cwd 无关。
- 子门结果独立记录，最后统一返回。
- 必需目录/命令缺失即失败。
- 只有显式声明的外部集成可 skip，并输出原因。
- 支持环境变量覆盖 Node/Python 工具路径，但不得写死个人绝对路径。
- 不在本波自动联网安装依赖。

## 4. 文件所有权

可修改：

- `scripts/ci.sh`
- 新增或调整 `scripts/ci/run-*.sh`
- CI shell 自测

禁止修改：

- 后端业务代码、`pyproject.toml`、Alembic
- Router manifest / `main.py`
- package manifests / locks
- `styles.css` / `nav.ts`

## 5. 测试

- 从 repo root、子目录和外部 cwd 调用均能定位仓库。
- 缺命令、缺目录、子门失败时退出码非零。
- 成功/失败/skip 汇总正确。
- `bash -n` 和 shell 测试通过。
- 在 W1 合入前允许记录“后端因已知 Alembic 阻断失败”，不得伪装为通过。
