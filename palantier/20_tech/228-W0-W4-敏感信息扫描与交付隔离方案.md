# 228-W0-W4 敏感信息扫描与交付隔离方案

> 日期：2026-07-31
> Worker：W4 / `aos-platform-w4` / `feature/223-worker-4`
> 基线：`14e6bb2`
> 状态：代码与 CI 门已完成；外部凭据处置仍待责任人完成

## 1. 目标

建立仓库级 Secret/PII/交付产物扫描门，确保私钥、Token、明文凭据和明显个人数据不能进入代码提交、测试夹具、日志、镜像或客户包。

## 2. 安全约束

- 已发现的真实敏感正文不得复制到代码、测试、日志或本文档。
- 测试只使用明确标注为 synthetic 的无效假值。
- 本 worker 不删除、不改写外部原始 SQL，不执行密钥轮换。
- 密钥有效性确认、轮换/吊销和历史清理由凭据责任人完成。

## 3. 设计

### 3.1 扫描范围

- 默认扫描 Git 跟踪文件。
- 可显式传入目录扫描交付 staging。
- 默认排除 `.git`、`node_modules`、构建缓存和二进制文件。
- 对超大文件使用流式/分块扫描，避免整文件载入内存。

### 3.2 检测类型

- PEM/SSH 私钥标记。
- 常见 access/refresh token、secret、password 赋值。
- 高置信度云凭据模式。
- DSN/URL 中的明文密码。
- 明显邮箱、手机号、身份证/银行卡候选只做高置信度告警，降低误报。

### 3.3 结果和脱敏

- 命中时只输出文件、行号、规则 ID 和脱敏摘要。
- 绝不输出完整 Secret。
- 严重命中退出码非零。
- 支持 allowlist，但必须精确到规则+文件+原因，禁止全局忽略。

## 4. 文件所有权

可修改：

- 新增 `scripts/security/**`
- 新增安全扫描专项测试和 synthetic 夹具
- 必要的安全说明文件

禁止修改：

- 真实电商 SQL 转储
- `scripts/ci.sh`（由 W3/总控接线）
- 后端、前端、package manifests、部署文件

## 5. 测试

- synthetic 私钥标记被阻断且输出不含正文。
- 假 Token/明文 DSN 被阻断。
- 正常代码和文档不误报。
- allowlist 仅精确生效。
- 大文件扫描不会整文件回显。
- 路径含空格和中文可处理。
