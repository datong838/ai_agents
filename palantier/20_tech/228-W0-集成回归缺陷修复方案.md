# 228-W0 集成回归缺陷修复方案

> 日期：2026-07-31
> 基线：Wave 0 四 Worker 已合并到 `m1`
> 状态：已完成并通过 Wave 0 最终 10/10 full 回归

## 1. 触发原因

Wave 0 合并回归真实暴露以下问题：

- W1+W2 在 FastAPI 0.141 的惰性 Router 结构下，原路由探针只枚举顶层包装器。
- W1 的合成 DSN 日志测试被 W4 安全扫描识别为 critical。
- Web 测试 1555/1555 通过，但 `tsc --noEmit` 存在 26 个存量类型/未使用符号错误。
- Desktop 测试 39/40，通过失败项为导航状态契约断言。
- 托管 pnpm fallback 会在依赖由 npm 安装时尝试修复依赖；本仓库有 npm lockfile，本轮回归固定使用 npm。

## 2. 修复原则

1. 不改业务数据、不新增页面、不改变 API 契约。
2. FastAPI 探针兼容 eager 与 lazy Router，只改测试枚举方式。
3. synthetic 敏感数据只允许精确到规则+文件+原因的 allowlist。
4. Web 仅处理编译器指出的未使用符号、窄化和索引类型，不重构页面。
5. Desktop 先核对产品导航状态；若页面可访问且测试契约已过时，更新断言为“路径完整且状态值合法”，不得为了测试把 planned/mock 页面伪标 live。
6. CI 回归固定使用与 lockfile 一致的 npm；不得自动安装或切换 package manager。

## 3. Worker 分工

| Worker | 范围 | 文件边界 |
|---|---|---|
| 总控 | FastAPI 探针、安全 allowlist、合并与回归 | `test_domain_router_manifest.py`、`scripts/security/allowlist.json` |
| W2 | Web TypeScript 26 项错误 | 仅错误清单涉及的 `apps/web/src/**` |
| W3 | Desktop 导航契约失败 | `apps/desktop/src/parity.test.ts`；如需共享导航只提交建议，不越权改 |
| W1 | 后端全量失败分析 | 先只读分析；未经总控确认不改业务代码 |
