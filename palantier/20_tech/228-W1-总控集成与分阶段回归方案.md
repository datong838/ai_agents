## 4. CI 设计

- Node 门只接受 pnpm；版本由根 `package.json#packageManager` 固定。
- 依赖存在性以 pnpm workspace 的真实可执行文件/模块链接为准，不能仅检查根 `node_modules` 目录。
- OpenAPI 门使用项目 Python 运行导出 `--check` 与契约测试，不在 CI 内生成或覆盖基线。
- Helm 门要求 CLI 存在并执行 `--require`；不连接集群、不创建资源。
- 所有门均延续“只验证、不自动安装依赖”的原则；依赖准备属于环境初始化步骤。
