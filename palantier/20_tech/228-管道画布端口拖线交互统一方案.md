## 1. 使用 Rules

1. 统一同一系统的主要连线心智：输出端口拖到输入端口；不强行合并 AIP Logic 与 Pipeline Builder 的底层组件和数据契约。
2. 保留现有右键“建立连接/删除连接”和点击源端口→点击目标端口，作为辅助、键盘与无障碍路径。
3. 只扩展管道前端交互；连接仍写入现有 `connections`，保存仍使用原 Graph DTO、完整快照校验与服务端回读。
4. 拖动预览不改 graph、不标 dirty；仅合法落到目标输入端口后新增连接。空白释放、重复边和自连接 fail-closed。
5. 不改变节点拖动、算子拖入、右栏属性、历史、部署、输出预览和已持久化数据。
6. 完成后执行专项、Web 全量、TypeScript、production build、36 页 interaction-honesty 与真实浏览器验收。

## 2. 产品决策

1. AIP 与管道都是“节点＋有向边”编排画布，主要连线方式应一致，降低学习成本并提升可发现性。
2. 统一的是交互规则与视觉语言：左输入端口、右输出端口、拖线预览、目标高亮、有向箭头、无效落点取消。
3. 不在本波抽共享画布组件：AIP 有 Branch/多端口/严格 canonical DAG，Pipeline 有独立节点、保存和部署契约；过早合并会放大回归面。
4. 右键菜单保留为高级辅助入口，但不再是唯一可发现的建连方式。

## 3. 冻结交互

1. 每个管道节点展示左侧输入端口和右侧输出端口；端口为独立按钮，不能嵌套在节点拖动按钮内。
2. 输出端口按下并移动超过 4px 后进入拖线态，实时绘制带箭头的预览曲线，并高亮所有输入端口。
3. 在输入端口释放时复用现有 `completeLink`/`connections` 路径；成功只新增一条边并标记 dirty。
4. 在空白或非输入端口释放时取消并清理预览；重复边、自连接不增加边。
5. 未超过阈值时保留点击源端口→点击目标端口；拖动后的合成 click 被抑制。
6. 画布容器兜底接收 Pointer move/up/cancel，避免指针捕获差异造成预览滞留。

## 5. 验收与风险

1. 输出端口拖到输入端口后连接数增加 1、保存变 dirty、正式边带箭头；刷新前不写服务端。
2. 空白释放、重复边和自连接不修改连接数组，预览一定清理。
3. 节点本体仍可拖动和点击选中；端口操作不得误触节点拖动、双击删除或右键菜单。
4. 右键连接、点击端口连接、删连接、节点拖动、算子添加、缩放、保存与重载回归通过。
5. 结构风险：现有节点是单一 `<button>`，不能合法嵌套端口按钮；改为定位容器＋内部拖动按钮，保持原 DnD listeners/attributes 在内部按钮上。
6. 回滚仅涉及上述三个前端文件，无数据迁移。
