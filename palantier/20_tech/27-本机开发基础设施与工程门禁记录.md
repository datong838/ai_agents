### 3.4 基础设施运维手册（启动 / 关闭 / 在线检测）

> **工作目录（以下命令均先执行）：**  
> `cd c:\work\projects\wchat\aos-platform`  
> Compose 文件：`deploy/dev/docker-compose.yml`  
> 一键检测脚本：`deploy/dev/status.ps1`

#### 3.4.1 全家桶（PG + MinIO）

| 动作 | PowerShell | 期望 |
| --- | --- | --- |
| **启动** | `docker compose -f deploy/dev/docker-compose.yml up -d` | 创建并后台运行 `aos-dev-pg`、`aos-dev-minio`；init 容器跑完退出码 0 |
| **关闭（停容器，保留数据卷）** | `docker compose -f deploy/dev/docker-compose.yml stop` | 端口 5433/9000/9001 不再监听；数据仍在 volume |
| **关闭并删除容器（仍保留卷）** | `docker compose -f deploy/dev/docker-compose.yml down` | 容器删除；`aos_dev_pg_data` / `aos_dev_minio_data` 默认保留 |
| **危险：连数据卷一起删** | `docker compose -f deploy/dev/docker-compose.yml down -v` | **清空** Dev 库与对象；仅重建环境时用 |
| **看状态** | `docker compose -f deploy/dev/docker-compose.yml ps -a` | `aos-dev-pg` / `aos-dev-minio` 为 `Up … (healthy)` |
| **一键在线检测** | `powershell -File deploy\dev\status.ps1` | 末行 `RESULT: Dev prereq ONLINE`；exit 0 |

#### 3.4.2 PostgreSQL（`aos-dev-pg`）

| 动作 | 命令 | 在线判定 |
