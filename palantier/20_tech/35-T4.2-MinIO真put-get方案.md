## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| `POST /v1/media-sets` 带 `bytesBase64` → **真 Put** 到 bucket `aos-media` | 客户现场装 MinIO（24 前置） |
| `GET /v1/media-sets/{rid}/content` → **真 Get** 字节 | 预签名 URL 产品页 |
| 元数据仍返回 rid / objectStore / etag | 多租户前缀产品化（可先 `org/project/`） |
| 无 MinIO 时降级 `metadata-only`（单测不挡） | 换 S3 厂商全家桶 |

---

## 2. 设计

```
UI/DataPage → aos-api /v1/media-sets
                 │
                 ▼
         aos_api/object_store.py
                 │  S3 兼容 API（path-style）
                 ▼
         MinIO :9000 / bucket aos-media
```

**配置（env / .secrets.env）：**

| 变量 | 例 |
| --- | --- |
| `AOS_S3_ENDPOINT` | `http://127.0.0.1:9000` 或 `http://<wsl-ip>:9000` |
| `AOS_S3_BUCKET` | `aos-media` |
| `AOS_S3_ACCESS_KEY` | 来自 secrets（勿回响应） |
| `AOS_S3_SECRET_KEY` | 来自 secrets |
| `AOS_S3_REGION` | `us-east-1` |

实现优先用 **`minio` Python 客户端**（Dev 依赖）；失败则 metadata-only + 日志。

## 3. API 变更（兼容）

| 方法 | 行为 |
| --- | --- |
| `POST /v1/media-sets` | 有 bytes → put；`objectStore=minio` · `stored=true` · `etag` |

| `GET /v1/media-sets/{rid}/content` | **新增** 返回原始 bytes（或 base64 JSON） |
| `GET /v1/object-store/health` | **新增** put/get 探针摘要 |
