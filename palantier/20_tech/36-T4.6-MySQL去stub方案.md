## 7. 补丁 · utf8mb4（v1.1 · 图谱乱码）

**现象**：知识图谱选中 `mysql-wo-001` 时标题显示 `MySQLä¾…`；静态 UI 中文正常。

**根因**：
1. Dev MySQL init / 连接未钉死 **utf8mb4**，源表 `title` 被双重编码写入；
2. PyMySQL 未显式 `charset=utf8mb4`，ingest 把乱码原样写入 `obj_instance`；
3. 图谱列表按 id 排序，`mysql-wo-*` 排在 `wo-1001` 前，默认 Selection 即乱码条。

**定稿（最小）**：

| 项 | 动作 |
| --- | --- |
| PyMySQL | `charset=utf8mb4` · `use_unicode=True` |
| compose / init.sql | server + 表 **utf8mb4**；init `SET NAMES utf8mb4` |
| 幂等修复 | `ensure-seed` / `repair_demo_workorders` 纠正 `mysql-wo-001/002` 标题；并 `repair_mysql_source_titles` 纠正源表 |
| 验收 | `GET /v1/objects/WorkOrder` 中 `mysql-wo-*` / `wo-1001` 标题均为合法中文 |

**非目标**：不删 MySQL volume；不改 Object API 契约。
