## 1. 目标 / 非目标

| 目标（DoD） | 非目标（本刀不做） |
| --- | --- |
| OCR **独立进程/容器** | 生产 GPU 集群 / 多语种调优 |
| aos-api 仅 HTTP 调边车 | UI 内嵌 paddleocr / 浏览器 OCR |
| **一页** OCR 结果入 DocIntel 链路 | 整本 PDF 批处理产品页 |
| 可选真 `paddleocr`（已装则用） | 强制本机 pip 装全量 paddle（体积大、易炸） |
| pipeline 可带 `ocr` 字段 | T4.17 DLQ 语义重写 |

## 2. 架构

```
apps/web / Logic ──► aos-api POST /v1/docintel/ocr
                           │
                           │ HTTP
                           ▼
                   aos-dev-ocr :8082   ←── 进程隔离边车
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
         paddleocr    pillow+启发式   textHint 透传
         (若已装)      (图元/文件名)   (无图时 Dev)
```

**Dev 默认** = 边车在线 + 引擎 `paddleocr-shaped`（无重依赖也可绿）；装了 `paddleocr` 则 `engine=paddleocr`。  
**与 T3.9 同构**：官方重镜像可后插；本刀先保证隔离 + 契约 + 入链路。

---

## 3. 配置

| 项 | 值 |
| --- | --- |
| `AOS_OCR_URL` | `http://127.0.0.1:8082`（WSL 场景可用 `http://<wsl-ip>:8082`） |
| `AOS_OCR_FALLBACK` | `mock`（pytest 默认）/ `off`（集成要求边车） |
| `AOS_OCR_TIMEOUT` | `30`（秒；真 paddle 首推理可慢） |

请求体（Facade 入参，与现 stub 兼容）：

```json
{
  "page": 1,
  "textHint": "可选",
  "imageBase64": "可选；data URL 或纯 base64",
  "mediaRid": "可选；仅审计字段"
}
```

响应（扩展字段可加，不删既有）：

```json
{
  "engine": "paddleocr|paddleocr-shaped|fallback-mock",
  "page": 1,
  "text": "...",
  "sidecar": "ocr|fallback-mock",
  "confidence": 0.0,
  "boxes": []
}
```
