## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |

## 2. 架构

```
POST /v1/parsers/extract
   body: { name?, contentType?, bytesBase64? } | { mediaRid? }
        │
        ▼
 aos_api/file_parsers.py
   detect → parser-* → { text, sheets?, meta, engine }
        │
        ├─► Media meta.extractedText（可选）
        └─► DocIntel pipeline.parse
                 │
                 └─► 若 pdf-scan / image → ocr_gateway（已有）
```

**依赖策略：**  
- txt/md/csv/docx/xlsx：**标准库**（zipfile + XML）  
- pdf 文本层：优先 `pypdf`（若已装）；未装则启发式抽字 + `engine=pdf-heuristic`；单测用可解析最小 PDF fixture

---

## 3. API

| 方法 | 行为 |
| --- | --- |
| `POST /v1/parsers/extract` | 抽文本；返回 `parser`/`ok`/`text`/`preview` |
| `GET /v1/parsers` | 已注册插件列表 |
| `POST /v1/docintel/pipeline` | 成功时增加 `parse` 字段（有字节或 textHint） |
| `POST /v1/media-sets/{rid}/parse` | 对已存 Media 再解析（有 object store 或内存字节） |

响应示例：

```json
{
  "ok": true,
  "parser": "parser-office-word",
  "format": "docx",
  "text": "...",
  "charCount": 120,
  "sheets": null,
  "hint": null
}
```
