## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| **非 Dev opaque token** 可登录（JWT） | 本刀强制起全量 Keycloak 集群 |
| `/v1/me` 反映 `tokenKind=oidc|dev` | 改 UI 登录页产品化 |
| 配置：`AOS_OIDC_*` · vault ref 声明 | 抄 Keycloak Admin 壳 |
| Marking/roles 从 JWT claims 进 Principal | TX.4 完整 Marking 引擎 |

**诚实：** Dev 默认 = **HS256 自签 JWT**（IdP 形）；设 `AOS_OIDC_JWKS_URL` 后可验真 Keycloak/任一 OIDC JWKS。

---

## 2. 架构

```
Client
  │  POST /v1/auth/token  (Dev only; grant=dev)
  │  ← JWT (HS256)
  │
  │  Authorization: Bearer <jwt>
  ▼
aos-api require_principal
  ├─ JWT → 验签 (HS256 secret 或 JWKS)
  └─ token=="dev" → 仅当 AOS_AUTH_ALLOW_DEV=1
```

---

## 3. 配置

| 变量 | 含义 |
| --- | --- |
| `AOS_AUTH_ALLOW_DEV` | 默认 `1`；生产务必 `0` |
| `AOS_OIDC_ISSUER` | 默认 `http://aos-dev-oidc` |
| `AOS_OIDC_AUDIENCE` | 默认 `aos-api` |
| `AOS_OIDC_DEV_SECRET` | HS256 密钥（仅 Dev；secrets） |
| `AOS_OIDC_JWKS_URL` | 可选；有则优先 JWKS 验签 |
| `AOS_OIDC_CLIENT_ID_REF` | 响应只回 vault/env ref |

---

## 4. API

| 方法 | 行为 |
| --- | --- |
| `GET /v1/auth/oidc` | issuer/audience/clientIdRef/jwksConfigured（无密钥） |
| `POST /v1/auth/token` | Dev：`{"grantType":"dev","subject":"alice"}` → accessToken JWT |
| `GET /v1/me` | 已有；JWT 时 `tokenKind=oidc` |

JWT claims（最小）：`sub` · `org_id` · `project_id` · `roles` · `markings` · `iss` · `aud` · `exp`

## 6. 自测

- `POST /v1/auth/token` → JWT  
- `Bearer JWT` → `/v1/me` 200 · `tokenKind=oidc`  
- `AOS_AUTH_ALLOW_DEV=0` + `Bearer dev` → 401  
- 回归既有 Bearer dev 单测（默认 allow）
