## 2. 设计

```
Request → TraceLogMiddleware
  1. trace_id = X-Trace-Id | parse(traceparent) | uuid
  2. call_next
  3. record(method, path_template?, status, duration_ms)
  4. log + X-Trace-Id header
```

**路径归一**：高频动态段降基数（如 `/v1/objects/{type}/{id}` → `/v1/objects/{object_type}/{object_id}`）；未知路径保留原 path（Dev 可接受）。

**存储**：模块级 `MetricsRegistry`（线程锁）；进程重启清零（Dev MVP）。

**出口**：
- `GET /v1/metrics` → `{ "requests": [...], "totals": {count, errors, p50Ms, p95Ms} }`
- `GET /v1/metrics?format=prom` → Prometheus exposition（无第三方库手写）
- 鉴权：与其它 `/v1/*` 同 Bearer（或 health 旁路？→ **需鉴权**，避免裸奔）

**Web（可选薄页）**：概览旁链或 `/dev/metrics` 不进 DEMO_PAGES；本刀 **不做侧栏项**，只 API + pytest。若时间够加 Overview 一行「metrics 可达」。
