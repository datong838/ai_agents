## 1. 目标 / 非目标

---

## 2. API

| Method | Path | 行为 |
| --- | --- | --- |
| GET | `/v1/plugins` | 汇总 kind=tool\|parser\|source\|capability |
| GET | `/v1/aip/models` | 可路由模型（来自 providers/warmup） |
| POST | `/v1/aip/tools/{id}/invoke` | 真调：query.objects / fn.echo / wiki.read |
| POST | `/v1/aip/chat` | withTools 时先/后执行 tools，结果入 toolCalls |
| POST | `/v1/modules` | 支持 `entryPath` · `widgets` |
| GET | `/v1/modules/{id}/runtime` | 回传 entryPath / buddyBound |
| POST | capabilities submit | artifact 含 `mediaRid`（写 media 元数据） |
