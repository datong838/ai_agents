## 3. T0.10 SBOM 最小

### 3.1 生成

`scripts/ci/generate-sbom.ps1` → `deploy/dev/sbom-dev.json`（CycloneDX-lite 形）：

| 源 | 内容 |
| --- | --- |
| `apps/web/package.json` | dependencies + devDependencies |
| `services/aos-api/pyproject.toml` | project.dependencies |
| `deploy/dev/docker-compose.yml` | `image:` 行（标 `scope=dev-prereq`） |

### 3.2 门禁

`scripts/ci/check-sbom-gate.ps1`：

| 检查 | 规则 |
| --- | --- |
| AGPL 服务端名 | 在 **非** `deploy/dev/` · **非** `docs/` 的客户向路径命中 `minio/minio`、`grafana/grafana` 等 → 违规 |
| 黑名单路径引用 | 产品源（`apps/`·`services/`·`packages/`）出现 `refs/`、`ToolJet`、`B7_Wiki` 等 → 违规 |
| 客户包目录 | 若存在 `dist/customer/`，对其额外严扫 |

默认：有违规打印 WARN exit 0；`-Strict` exit 1。  
清单：`agpl-denied-images.txt` · `forbidden-product-paths.txt`。
