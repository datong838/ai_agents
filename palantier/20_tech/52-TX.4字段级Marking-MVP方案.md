---

## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| ObjectType `properties[].requiredMarkings` 生效 | 完整 OpenFGA / 继承树 |
| **读**：缺 Marking → 字段从响应剔除，附 `_redactedFields` | UI 逐格像素脱敏产品 |
| **写**：Draft/execute `proposed` 含受限字段且无 Marking → 403 `FORBIDDEN` | 字段级审计 UI |
| WorkOrder 种子：`internalCost` → `secret` | 改客户包 / Ferry |

---

## 2. 模型

```json
{
  "name": "internalCost",
  "type": "number",
  "requiredMarkings": ["secret"]
}
```

规则（与对象级一致）：`principal.markings ⊇ required`；`admin` 角色跳过。

---

## 3. API 行为

| 路径 | 行为 |
| --- | --- |
| `GET /v1/objects/{type}` · `/{id}` | 按类型 properties 脱敏 |
| `POST /v1/object-sets/query` | 同上 |
| `POST /v1/actions/validate` · `/execute` · Draft approve | `proposed` 键命中受限字段 → `ensure_markings` |

响应形：

```json
{
  "id": "wo-1001",
  "type": "WorkOrder",
  "title": "...",
  "_redactedFields": ["internalCost"]
}
```

（有权用户不出现 `_redactedFields` 或缺省 `[]`。）
