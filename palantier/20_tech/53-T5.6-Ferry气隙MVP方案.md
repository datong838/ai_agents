## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| `POST /v1/apollo/ferry/export` → base64 **tar.gz**（manifest + assets + checksums + signature.sig） | Skopeo 镜像 archive / Helm 全集 |
| `POST /v1/apollo/ferry/import`：验签+校验和；**缺签 / 坏签 → 403/400** | cosign / notation 生产 PKI |

| UI Ferry 页可 Export / Import 演示 | html 像素 1:1 |

---

## 2. 介质（对齐 T09 §9.1 · 瘦身）

```text
ferry-bundle-{env}-{ts}.tar.gz
├── manifest.json
├── assets/payload.json      # MVP：Asset/模块/对象类型快照
├── checksums.sha256
└── signature.sig            # HMAC-SHA256(manifest.json) hex
```

| 项 | MVP |
| --- | --- |
| 签名 | `AOS_FERRY_HMAC_SECRET`（Dev 默认仅本机；生产必换） |
| 校验顺序 | 有 signature → 验 HMAC → 校验 checksums → 接受 |
| 缺 `signature.sig` | **拒导入**（A6） |

---

## 3. API

| Method | Path | 行为 |
| --- | --- | --- |
| GET | `/v1/apollo/ferry/status` | `{ deferred:false, mode:"mvp-hmac", skopeo:false, cosign:false }` |
| POST | `/v1/apollo/ferry/export` | body 可选 `{ env, channel, contents[] }` → `{ filename, contentBase64, manifest }` |
| POST | `/v1/apollo/ferry/import` | `{ contentBase64 }` 或 `{ omitSignature:true }` 测拒 → 结果 |

错误码：`FERRY_SIGNATURE_MISSING` · `FERRY_SIGNATURE_INVALID` · `FERRY_CHECKSUM_MISMATCH`
