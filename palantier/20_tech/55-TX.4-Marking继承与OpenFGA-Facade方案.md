## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| **类型级** `meta_object_type.required_markings` | 完整继承树 / 多跳递归产品 |
| **实例级** props.`_requiredMarkings` | UI 策略编辑器 |
| **1 跳继承**：`graph_edge.rel = inherits_markings_from` → 子有效 Marking ⊇ 父有效 | 任意 rel 自动继承 |
| **OpenFGA 形**：`POST /v1/authz/check` · PG 元组表；`AOS_OPENFGA_API_URL` 可外呼 | 本机强制起 openfga 容器 |
| 对象 GET/LIST：缺 Marking → 403 / 列表剔除；有元组则另需 `viewer` | 前端直连 OpenFGA SDK |

## 2. 有效 Marking 计算

```
effective(type, id) =
  type.required_markings
  ∪ props._requiredMarkings
  ∪ effective(parent)   // 仅 1 跳：edge rel=inherits_markings_from
```

规则：`principal.markings ⊇ effective`；`admin` 跳过。

| 读路径 | 行为 |
| --- | --- |
| `GET /v1/objects/{type}/{id}` | 不足 → **403 FORBIDDEN** |
| `GET /v1/objects/{type}` · object-sets query | 不足 → **从 items 剔除**（不整表 403） |
| 字段级 redact | 仍按 [52]；在对象级通过之后执行 |

## 3. OpenFGA Facade

| 能力 | 行为 |
| --- | --- |
| 存储 | `authz_tuple(user_key, relation, object_key)` |
| Check | `user:{sub}` · `viewer` · `object:{type}:{id}` |
| 写元组 | `POST /v1/authz/tuples`（需 principal；Dev 可写） |
| 外呼 | `AOS_OPENFGA_API_URL` 非空 → HTTP Check（失败记 WARN，**不**静默放行若配置了 Require）；默认本地表 |
| 挂钩 | 仅当该 `object_key` **存在至少一条元组** 时，读对象额外要求 `viewer`；无元组 → 不拦（兼容） |

API：

```http
POST /v1/authz/check
{ "user": "user:alice", "relation": "viewer", "object": "object:WorkOrder:wo-fga-demo" }
→ { "allowed": true|false }

POST /v1/authz/tuples
{ "user": "user:alice", "relation": "viewer", "object": "object:WorkOrder:wo-fga-demo" }
→ { "ok": true }
```

（`user` 可省略 → 用当前 `user:{principal.subject}`。）
