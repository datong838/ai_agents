## 1. 目标 / 非目标

| 目标（DoD） | 非目标 |
| --- | --- |
| 包内对齐 T09：`artifacts/images.json` + `artifacts/images.sig` | 强制本机安装 skopeo/cosign |
| PATH 有 **skopeo** → 可把镜像拷成 `artifacts/archives/*.tar` | Helm 全集 / Full Channel |
| PATH 有 **cosign** → `sign-blob`/`verify-blob`；否则 **cosign-dev-hmac** | 生产 PKI / Fulcio |
| status：`skopeo`/`cosign` 布尔 · `mode: mvp-hmac+images` | HA 气隙硬件 |
| 缺 images.sig（当有 images.json）→ 拒导 | UI 像素 1:1 |

## 2. 介质（相对 53 增量）

```text
ferry-bundle-....tar.gz
├── manifest.json
├── assets/payload.json
├── artifacts/
│   ├── images.json      # refs · digests · archive 相对路径
│   ├── images.sig       # cosign 或 cosign-dev-hmac
│   └── archives/*.tar   # 可选；仅 skopeo 成功时
├── checksums.sha256
└── signature.sig        # 仍签 manifest（A6）
```

`images.json` 形：

```json
{
  "version": "1",
  "cosignMode": "cosign-dev-hmac",
  "skopeoUsed": false,
  "images": [
    {
      "ref": "postgres:16-alpine",
      "digest": "sha256:…",
      "digestSource": "docker-inspect|synthetic",
      "archive": null
    }
  ]
}
```

默认镜像列表：env `AOS_FERRY_IMAGES`（逗号分隔），否则 Dev 默认 `postgres:16-alpine,minio/minio:RELEASE.2025-04-22T22-12-26Z`（与 compose 对齐，**不**拉新镜像强制）。

---

## 3. 签名

| 层 | 算法 | 密钥 |
| --- | --- | --- |
| manifest | HMAC-SHA256（[53]） | `AOS_FERRY_HMAC_SECRET` |
| images.json | cosign blob **或** HMAC-SHA256(`ferry-images:`‖body) | cosign key / 同 secret |

导入顺序：manifest 签 → checksums →（若有 images.json）images.sig → 接受。

---

## 4. API / status

| 字段 | 含义 |
| --- | --- |
| `mode` | `mvp-hmac+images` |
| `skopeo` / `cosign` | PATH 探针 |
| `imageFerry` | `digest+sig`（总有）· `archives` 仅 skopeo |

`POST export` body：`includeImages` 默认 **true**；`false` 可退回纯 [53] 包。
