## 2. 客户演示 DoD（总退出条件）

本地（Windows/本机 Docker）满足：

1. **一键/一脚本** 拉起：`aos-api` + `web` + PG + MinIO（+ 既有 Dev 边车按需）  
2. **一条行业故事**（建议：工单 WorkOrder）从「数据进 → 对象可见 → Action/Draft 写回 → Workshop 运营台可见 → AIP 辅助决策」可走通  
3. 演示中 **不依赖** Apollo Full / 现场 Ferry / 客户 IdP  
4. 每屏能回答客户：「这解决什么业务问题」
