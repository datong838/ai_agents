## 1. 优先级翻转（硬规则）

| 优先 | 后置（停车场） |
| --- | --- |
| L1 数据接入演示故事 | Full Spoke K8s/Helm 运行时 |
| L2 Ontology 建模/对象浏览/写回 | 生产 IdP 真 token（客户环境） |
| L3 Workshop Inbox/画布/发布 | Ferry 大镜像现场加严 / cosign 生产链 |
| AIP Assist / Logic / Draft 决策链 | Channel/Release 运维加深 |
| 本地一键启动 + 行业种子数据 | Hub 多 Spoke 舰队 |

**禁止话术：** 因 Apollo Lite/Ferry MVP 已有，就冲运维；因画布在，就宣称分析建模（1.3）已交付。

## 2. 客户演示 DoD（总退出条件）

本地（Windows/本机 Docker）满足：

1. **一键/一脚本** 拉起：`aos-api` + `web` + PG + MinIO（+ 既有 Dev 边车按需）  
2. **一条行业故事**（建议：工单 WorkOrder）从「数据进 → 对象可见 → Action/Draft 写回 → Workshop 运营台可见 → AIP 辅助决策」可走通  
3. 演示中 **不依赖** Apollo Full / 现场 Ferry / 客户 IdP  
4. 每屏能回答客户：「这解决什么业务问题」
