## 1. 目标 / 非目标

| 目标 | 非目标 |
| --- | --- |
| 顶层 Tab：**数据源 · 同步 · 代理 · 导出**（对齐蓝图） | 一次做完全部 deep 页（管道/计划编辑器可链出） |
| 数据源主舞台：KPI → 工具条 → **一张主表** → 新建 | 重写 aos-api |
| 新建：页内 **4 步向导**（连接器→运行时→连接→凭证），主列表不与向导叠层 | 真 Magritte 集群运维 |
| L1 链路态 / Storage Router / 种子 → **「高级 · 演示」折叠区** | 侧栏工作台收口（另案） |

## 2. 信息架构（定稿）

```text
/data  数据连接
├─ Tab 数据源
│   ├─ 视图 list（默认）：4 KPI + 筛选占位 + 新建 + **六列** Sources 主表
│   ├─ 视图 new：4 步向导（对齐 source-new）
│   └─ 视图 detail：选中源详情 + 关联同步/管道（链到既有子页）
├─ Tab 同步：Sync 任务表（中文列）+ 链「计划编辑器 / 管道」
├─ Tab 代理：边缘代理卡片（配置面；无真集群时占位说明）
└─ Tab 导出：蓝图占位（后置能力说明）

种子 / L1 / 路由调试：仅 API + scripts/demo，不上本页
```

**层次原则**：同一屏只突出一个主焦点；演示基建不进产品主舞台。

## 5. 验收

| 项 | 通过 |
| --- | --- |
| 打开 `/data` | 默认「数据源」**六列**主表，风格对齐蓝图 |
| 新建 | 进入 4 步向导；创建后回详情或列表 |
| 同步 / 代理 / 导出 | Tab 可切；导出可占位 |
| 无演示壳 | 页内无「高级 · 演示」/「初始化业务数据」按钮 |
| 回归 | API 契约不变；ensure-seed 仍可由脚本调用；子路由可链出 |

## 6. 风险

| 风险 | 缓解 |
| --- | --- |
| 演示员找不到种子 | 概览 Banner / 手册指向 `scripts/demo/ensure-seed.ps1` |
| 运行时未入库 | 新建时前端记忆；类型启发式兜底；后置 API 字段 |
