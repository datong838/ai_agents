# 75 · 去演示端面壳（产品 UI）

> **版本**：v1.0 · 2026-07-18  
> **状态**：✅ 可编码  
> **范围**：**仅端面展示**（文案 / Banner / 演示按钮 / 假行）；**不删** `/v1/demo/*`、ensure-seed 脚本、冒烟与数据种子能力  
> **上游**：用户反馈 · 数据连接去演示壳后，全站仍有「种子 / 一键写回 / 业务一镜 / 护栏演示 / scripts/demo」露出

---

## 1. 原则

| 保留（线上能力） | 去掉（端面壳） |
| --- | --- |
| API `/v1/demo/ensure-seed` · `run-story` · `run-capability` | 页内「初始化种子 / 一键写回 / 业务一镜 / 护栏演示」按钮与脚本路径 Banner |
| `overviewMetrics` 拉 story 计数 | KPI 文案「种子」、空态「请跑 ensure-seed.ps1」 |
| 真实数据集名若叫 WorkOrder-demo | 旁注「演示 / seed / TB.9」话术 |
| 蓝图占位导航（能力未接线） | 「Dev 示意 / 后置深化 / 本阶段不深化」产品话术 |

空态统一：**暂无数据 · 请到数据连接新建数据源（或完成同步）** — 不提演示基建。

---

## 2. 落点清单

| 文件 | 动作 |
| --- | --- |
| `OverviewPage.tsx` | 去掉脚本路径 Banner；空工单仅产品提示或静默 |
| `OverviewDomainGrid.tsx` | 「种子」→「工单」或「同步」；Apollo「后置」→「规划中」 |
| `InboxPage.tsx` | 去掉 `LargeResultSimulator` |
| `DraftInboxPage.tsx` | 去掉「一键写回闭环」；示例按钮改产品文案 |
| `CapabilityPage.tsx` | 去掉「业务一镜」按钮 |
| `BuddyPage` / `Canvas` / `workshop` / `extras` / `remainder` / `data` | 空态去种子话术 |
| `ontology.tsx` | 去掉 GH-04 演示假行；Wiki「演示只读」改产品表述 |
| `aip.tsx` | 去掉 ensure-api.sh Banner；谱系空态去「一键写回」 |
| `DataPage.tsx` | 代理/导出文案去「后置 / 本环境演示」口吻 |
| `PublishPage` / `StudioPage` 等 | 「后置 / 示意」→ 中性产品句 |
| `analytics.tsx`（118 补） | 去掉「演示一镜 / 试* / TA.*」；一镜仅 `/v1/demo/*` |
