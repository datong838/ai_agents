## 1. 目标 / 非目标

| 目标 | 非目标 |
| --- | --- |
| **三层视图**：`list` ↔ `configure` ↔ `credentials` | 一次做完供应商持久化 CRUD |
| 列表层只露：**已接入** + **可接入类型**（对齐蓝图 fig2） | 列表层再挂 MetricGrid / 目录表 / Debug JSON |
| **配置**：显示名 / URL / 模型 + **测连通** + 保存 | UI 直连厂商 SDK |
| **管理凭据**：仅绑定状态 / 引用 / 轮换；**不含**测连通与连接表单 | 明文 API Key |
| 卡片干净：名称 · 短 meta · 状态徽标 · 配置/凭据按钮 | 卡片 meta 刷 vault path / keyRef 全文 |
| 接入 ≠ 路由（脚注链到模型路由） | 把路由规则表并进本页 |

## 2. 信息架构（定稿）

```text
/aip/model-providers
├─ view = list（默认）
│   ├─ 标题 + 短 lede（先选类型再填配置；Facade → 边车）
│   ├─ Toolbar：刷新 · Adapter 管理（可占位）· 路由策略 →
│   ├─ 节「已接入」：就绪卡片网格
│   │     └─ 按钮：配置 → configure · 管理凭据 → credentials
│   └─ 节「可接入类型」：类型卡片
│         └─ 接入 →  → 进入 view=configure（带 type）
│
├─ view = configure（连接与模型；不与凭据页混同）
│   ├─ 返回 ← 模型供应商 · 管理凭据 → · 路由策略 →
│   ├─ 显示名 · Base URL · 启用模型（API Key 仅一行绑定摘要，点「管理凭据」去改）
│   ├─ 测连通 · 保存并启用 · 去路由
│   └─ 高级：网关 / endpoint / 探测详情
│
└─ view = credentials（仅凭据）
    ├─ 返回 ← 模型供应商 · 打开配置 →
    ├─ 绑定状态 · 凭据引用（短名；全路径高级）
    ├─ 轮换 / 重新绑定（未接线 disabled）
    └─ 不含测连通、不含 Base URL / 模型勾选
```

**层次原则**：同一屏只突出一个主焦点；**配置 ≠ 凭据**。

**相对蓝图的加强**：蓝图 HTML 仍是同页展开配置面板；本方案改为 **list / configure / credentials** 视图切换。

## 3. 列表层卡片规范

### 3.1 已接入

| 露 | 不露 |
| --- | --- |
| 显示名 | `vault:...` / `keyRef=` 全文 |
| 短 meta：`text · agnes-2.0-flash`（kind · 模型 id） | `.env` 路径、完整 endpoint URL |
| 徽标：就绪 / 未就绪 | sidecar 技术名作主标题 |
| 按钮：配置 · 管理凭据 | 整卡点击直接摊开 JSON |

### 3.2 可接入类型

对齐蓝图五卡：OpenAI 兼容 · Azure · Anthropic · 本地 vLLM/Ollama · 自定义 Adapter。  
点「接入 →」只切到 configure，**不**在列表下方再叠一块表单。

## 4. 配置层 · 测连通（必须保留）

| 项 | 定稿 |
| --- | --- |
| API | 仍 `POST /v1/aip/chat`（query=连通探测；withTools=false） |
| 主按钮 | **测连通**（探测中禁用） |
| 成功摘要 | 一行中文 + `route` / `provider`；勿默认展开 JSON |
| 高级 | 折叠 `BpDebugPanel`；另列 sidecar / endpoint / secret ref 只读 |
| 保存并启用 | 持久化未接线时 **disabled** + 短说明（.env / 规划中） |
| 管理凭据 | 同 configure；焦点在 secret ref 只读区（无明文 key） |

## 9. 补丁 · 配置 ≠ 凭据（v1.1）

**问题**：`管理凭据` 只设 `focusCreds`，仍渲染 configure 全表单 → 两按钮同页。  
**定稿**：独立 `view=credentials`；测连通仅 configure。

---

## 10. 补丁 · 表单可编辑（v1.2）

**问题**：配置/凭据页输入框全部 `readOnly`，用户无法改。  
**定稿**：

| 页 | 可编辑 | 仍只读 |
| --- | --- | --- |
| configure | 显示名 · Base URL · 模型勾选 | API Key 摘要行（点管理凭据） |
| credentials | 凭据引用 · 新密钥（password，不回显） | 绑定状态摘要（由引用推导） |

**保存**：`保存并启用` / `轮换·重新绑定` **启用**；写入 `sessionStorage` 草稿（`aos.mp.draft.*`）。服务端尚无 PUT `/aip/providers`，草稿不替代运行时网关；测连通仍打现网。明文密钥不写入列表/高级日志。
