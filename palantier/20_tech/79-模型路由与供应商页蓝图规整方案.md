## 4. 路由页层次

```text
/aip/model-router
├─ view = rules（默认）
│   ├─ 产品提示条（无 env 字样）
│   ├─ 卡片：路由规则表（表头小字号 · 行距规整）
│   │     └─ 底栏：保存策略 · 熔断演练 · 导出审计（未接线可 disabled）
│   └─ 不展示：预热列表、试聊、Providers 目录表、sidecar 调试行
└─ view = warmup
      ├─ ← 返回路由策略
      ├─ 模型预热状态
      └─ 试聊（选模型 + 提问）；JSON 进高级折叠
```

供应商配置：主表单 + 测连通/保存；**探测 JSON / vault 全路径**仅「高级」；测连通结果一行摘要，不自动摊 JSON。
