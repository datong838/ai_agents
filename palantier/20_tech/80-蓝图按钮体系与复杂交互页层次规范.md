## 1. 按钮体系（全局）

| 类名 | 用途 | 蓝图对应 |
| --- | --- | --- |
| `btn-nav` | 页内/顶栏**导航**（返回、跨页链） | `border-white/08` 小圆角描边 |
| `btn-nav-accent` | 当前相关/主跳转导航 | 琥珀描边浅底 |
| `btn` | 次要操作（刷新、收起步骤） | 现有 ghost 描边 |
| `btn-primary` | 主操作（保存并启用、试聊、新建） | 实心青/琥珀按域 |
| `btn-outline-cyan` | 强调次操作（测连通、试跑） | 青色描边 |
| `bp-action-link` | **仅**表内行级文字链（非顶栏） | 青字链 |

**禁止**：顶栏用 `className="muted"` 当导航；复杂页把试跑 JSON 默认摊开。

## 2. 复杂交互页层次

| 层 | 放什么 | 不放 |
| --- | --- | --- |
| 顶栏 | 模式选择 + `btn-nav*` 跨页 | 插件目录刷屏 |
| 主舞台 | 一屏一个主焦点（工具=三栏；路由=规则表） | 调试 JSON、sidecar |
| 细项 | 策略/表单（radio、字段） | `模式=xx` 开发腔 Banner |
| 底栏/高级 | 保存、试跑、JSON 折叠 | 与主表单抢视线 |

**Tools 定稿（对齐 aip-tools）：**

```text
标题：Agent 工具面板 · 维修派单 Buddy
顶栏：调用模式 | 重能力 → | ← 成熟度 | Logic →（accent）
三栏：目录（含 Wiki 高亮卡）| 已启用列表 | 工具卡细项（策略 radio）
底栏：说明 + 保存工具配置；试跑 Invoke 进细项次级区，JSON 高级折叠
```
