## 2. 模型路由

### 2.1 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/aip/model-routes` | 返回 `{ items: RouteRule[] }`；无存档时用默认任务行 + 当前可路由模型填首选 |
| PUT | `/v1/aip/model-routes` | body `{ items: RouteRule[] }`；写入 PG `meta_aip_model_routes`（单行 JSON） |
| POST | `/v1/aip/model-routes/circuit-drill` | 按当前规则返回熔断演练结果（不改生产路由） |
| GET | `/v1/aip/model-routes` 同载荷可导出 | 前端「导出审计快照」= 下载当前已保存 JSON |

`RouteRule`：

```ts
{
  id: string;           // summarize | wiki_qa | logic_long | chatbot | pii | provider_down
  task: string;         // 展示名
  primary: string;      // 模型 id 或「—」
  fallback: string;     // 模型 id 或「—」或 ""
  egress: string;       // 禁公网 | 审批后 | 继承 | 强制不出域 | fallback
  span?: boolean;       // Provider 不可用行：首选跨列
}
```

### 2.2 UI

- 首选 / 回退：`<select>`，选项 = `/v1/aip/models` 的 id +「—」
- 出境：固定枚举 select
- `span` 行：首选为「熔断降级 → {model}」用单个 model select
- **保存策略**：`btn-primary` / `btn-nav-accent`，PUT 成功后提示
- **熔断演练**：POST，展示返回文案（非 disabled）
- **导出审计快照**：下载当前规则 JSON（非 disabled）

## 3. 工具面板

### 3.1 标题

- 改前：`Agent 工具面板 · 维修派单 Buddy`
- 改后：`Agent 工具面板`
- lede 保持权限/提案说明；foundry 样板可同步去掉演示后缀（产品真源一致）

### 3.2 目录中文注释

| 英文 | 中文注释 |
| --- | --- |
| Action | 写回动作（可 HITL） |
| Object Query | 对象属性查询 |
| Function | 函数 / 已发布 Logic |
| Update App Var | 更新应用变量 |
| Command | 命令类工具 |
| Request Clarification | 向用户澄清 |
| Capability | 重能力（平台代调） |
| Wiki Field Tool | Wiki 结构化字段 |

展示：`Action` + 灰色小字注释；Wiki / 重能力入口保持强调色。

### 3.3 重能力入口风格

与 Wiki 同为「目录底部分隔后的强调卡」：

- Wiki：`bp-tool-cat is-wiki`（橙）
- 登记重能力：`bp-tool-cat is-capability-entry`（青）+ 一行说明「登记 Adapter · 写回经 Action」

### 3.4 保存工具配置

- `GET/PUT /v1/aip/tools/config`：`{ categories: string[], mode, hitl }`
- 禁止「本地会话」假提示
