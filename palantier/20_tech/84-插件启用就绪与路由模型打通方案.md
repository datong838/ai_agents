# 84 · 插件「安装 → 启用就绪」与路由可选模型打通

> **版本**：v1.0 · 2026-07-18  
> **状态**：✅ 方案定稿 · 可编码  
> **对齐**：[83](83-LLM-Provider插件化整改方案.md) · [20 §3.1](20-AOS整体技术方案.md) · T07 Model Gateway  
> **Rules**：安装≠就绪；保存并启用须真持久化并进入 `/v1/aip/models`

---

## 问题

用户安装 DeepSeek 后，路由首选下拉只有 Agnes：因 `/v1/aip/models` 仅来自网关运行态；插件「安装」只写 install 集合，**无就绪态、无模型登记**。配置页「保存并启用」此前只写 sessionStorage。

## 生命周期（定稿）

```text
catalog → install（已安装）→ configure + 保存并启用（就绪）→ 出现在路由/预热候选
```

| 状态 | 含义 | UI |
| --- | --- | --- |
| catalog | 可安装 | 可安装区 |
| installed | 已装未进路由 | 已安装 · 配置 / 启用就绪 |
| ready | 配置已保存且启用 | 徽标「就绪」· 模型进 `/v1/aip/models` |

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| PUT | `/v1/aip/llm-provider-plugins/{id}/config` | 存 baseUrl/models/secretRef；`ready:true` 时登记可路由模型 |
| POST | `/v1/aip/llm-provider-plugins/{id}/enable` | 快捷：用默认模型标就绪 |
| POST | `/v1/aip/llm-provider-plugins/{id}/disable` | 取消就绪（仍保留安装） |

`GET /v1/aip/models`：运行态 items **∪** 已就绪插件的 `enabledModels`。

## UI

- 「保存并启用」→ PUT config + ready  
- 已安装卡：「启用就绪」+「配置」+「管理凭据」  
- 就绪后徽标「就绪」

## 自测

1. 安装 deepseek → 启用就绪 → `/v1/aip/models` 含 `deepseek-chat`  
2. 路由下拉可选  
3. disable 后下拉不再出现（已保存策略中的旧值可保留显示）
