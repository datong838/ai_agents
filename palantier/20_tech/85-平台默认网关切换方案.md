| --- | --- |
| 就绪 ≠ 运行态 | 本刀补「把谁设为平台默认网关」→ 运行态卡片与无 model 的 chat 跟默认走 |
| production-ui-no-temp | PUT 真写 KV；禁止只改前端文案 |

---

## 1. 目标

| 目标 | 非目标 |
| --- | --- |
| 供应商页可切换**平台默认网关**：Agnes（环境）/ 已就绪插件 / LiteLLM | 改 `.env` 文件自动写回 |
| 切换后：运行态卡片、概览默认大模型、试聊未选手动 model 时，跟默认网关 | 一次迁完所有历史会话路由 |
| Agnes 仍可作为选项保留 | 删除 Agnes 接入能力 |

---

## 2. 契约

```json
{
  "kind": "agnes" | "plugin" | "litellm",
  "pluginId": "deepseek" | null,
  "defaultModel": "deepseek-chat" | null
}
```

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/aip/gateway-default` | 当前默认 + 可选列表 |
| PUT | `/v1/aip/gateway-default` | 保存默认 |

未配置时：有 Agnes → `agnes`；否则有 LiteLLM → `litellm`；否则 `mock`。

---

## 3. 行为

| 能力 | 行为 |
| --- | --- |
| `GET /v1/aip/providers` | 按默认网关生成「运行态」items（plugin 时用就绪模型） |
| `GET /v1/aip/models` defaultTextModel | 取默认网关主模型 |
| `POST /v1/aip/chat` 无 model | 走默认网关（不再无脑 Agnes 优先） |
| 有显式 model | 仍按所选模型路由（84） |

候选列表：
- `agnes`（若 `agnes_configured`）
- 每个 `ready` 插件一项 `plugin:<id>`
- `litellm`（若 `AOS_LITELLM_URL`）

## 5. 自测

1. 默认 Agnes → 运行态为 Agnes；chat 无 model → Agnes  
2. 切到 deepseek（须已就绪+密钥）→ 运行态为 DeepSeek；chat 无 model → deepseek  
3. 切回 Agnes 恢复
