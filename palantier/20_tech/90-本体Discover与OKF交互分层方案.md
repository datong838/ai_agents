## 2. 目标层次（本体管理页）

```text
L1 顶栏：搜索 · 分支 · 健康 · 刷新 · OKF（唯一）
L2 域导航：分支 / 漏斗 / Wiki / 健康（无重复 OKF）
L3 Discover 主舞台：收藏卡 + 重要表（含深页）
L4 标准水合条：OKF → Funnel → Workshop（承接原「快捷入口」）
L5 Object Type 详情：七 Tab（选中后主焦点）
L6 次级：类型切换（紧凑列表，非双栏空舞台）
L7 新建 OT：默认折叠，点开再填表
```

**快捷入口改法：** 删除独立「快捷入口」区块；职责并入 **L4 水合条**（路径 CTA）+ **L2 域导航**（常驻深链）。功能不丢，只去第三套入口。

**OKF：** 仅顶栏 `btn-nav-accent` 保留一枚；L2 不再放 OKF。
