| # | 刀 | 做法 |
| --- | --- | --- |
| **A** | 最近查看真持久化 | `localStorage` 存 `{ kind, id, label, href?, at }`；相对时间由 `at` 计算；禁写死「昨天」 |

## 2. 契约（前端）

### A · storage

```text
key: aos.ontology.recent.v1
value: RecentEntry[]  max 8
RecentEntry = { kind: "objectType"|"link", id, label, href?, at: epochMs }
```

- `openDeep` / `openType` / 深页挂载 → `pushRecent(objectType)`
- 相对文案：刚刚 / N 分钟前 / N 小时前 / 昨天 / N 天前
- Funnel / Wiki：用户点过则写入 `kind=link`；未点过不伪造时间

### B · 分支

- 深页：`GET /v1/ontology/branches` + `<select>` → `setBranchId` → 重拉 `/v1/objects/{type}?branch=`
- 实例详情：`GET /v1/objects/{type}/{id}?branch=`
- 偏好：`aos.ontology.branchId`（可选，缺省 main）
