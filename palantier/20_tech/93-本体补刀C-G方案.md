## 2. 契约

### C
沿用 `GET /v1/ontology/branches/{id}/diff`；UI 展示字段级 diff。

### D
```sql
wiki_page_version (
  id BIGSERIAL PK,
  object_type TEXT, object_id TEXT,
  body JSONB,
  draft_id TEXT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
)
```
```text
GET /v1/wiki/{type}/{id}/versions → { items: [{ id, createdAt, summary, draftId? }] }
GET /v1/wiki/{type}/{id}/versions/{vid} → { id, body, createdAt }
```
approve UpdateWikiCard：若旧 body 存在则先 INSERT 快照再 upsert。

### E
```text
PUT /v1/objects/{type}/{id}?branch=X { props, op? }
```
UI：深页/内嵌 Data 区，仅 `!readonly && branch≠main` 可保存。

### F
```text
key: aos.ontology.favorites.v1 → string[]  // object type ids
```

### G
`FunnelPage` / `OkfFunnelPage` children 外包 `div.ont-page`。

## 5. 风险
