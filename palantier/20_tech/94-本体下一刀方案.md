## 2. 契约摘要

### Graph health metrics 增补
```json
{
  "danglingEdges": 0,
  "propConflicts": 0,
  "archiveCandidates": 0
}
```
- GH-01：danglingEdges > 0  
- GH-02：实例 props 键 ∉ OT properties（抽样/全量）  
- 前端 metric 只读 issues/metrics，禁写死 0

### Link editor
沿用 `GET/POST/PUT/DELETE /v1/ontology/link-types`

### Wiki / Funnel
```text
/ontology/wiki?type=WorkOrder&id=wo-1001
/ontology/funnel?type=WorkOrder
```
