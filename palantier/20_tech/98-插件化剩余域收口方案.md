## 1. 问题

| 域 | 写死点 | 目标 |
| --- | --- | --- |
| 文件解析器 | `file_parsers.list_plugins()` 硬编码 5 项 | `plugins/parsers/` + registry |
| Widget | `CanvasPage.WIDGET_PALETTE` 常量 | `plugins/widgets/` + API 拉表 |
| 通知通道 | 无插件目录；webhook 内存 | `plugins/channels/` + 注册表（运行时仍可 stub） |
| Embedding/Rerank | 无独立域 | `plugins/embeddings/` 诚实 stub 目录 |
| DataPage | API 失败时硬编码两卡 fallback | 改为诚实空态 |

**本刀不做：** 拆 extract 为多进程 · Widget 真 iframe · Embed 生产向量 API · Action 模板迁出 DB · MySQL 运行时迁插件进程。

---

## 2. 契约

```text
GET /v1/parser-plugins
GET /v1/parsers                 # 兼容；items 来自 registry
GET /v1/widget-plugins
GET /v1/channel-plugins
GET /v1/embedding-plugins
GET /v1/plugins                 # 聚合含上述 kind
```

install/uninstall：parsers/widgets 默认已装 P0；可选通道/embed 可 install（与 connector 同 KV 模式，按域分 key）。
