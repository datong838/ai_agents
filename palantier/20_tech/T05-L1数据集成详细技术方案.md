## 使用的 Rules

P0 文件必做 · P1 连接器尽量多做（MySQL 必做）· **不强制 200+** · Connector/解析器 **插件化** · UI 引用 data-* · 开源已本地核对

---

## 1. 范围与验收底线

| 优先级 | 内容 | 验收 |
| --- | --- | --- |
| **P0** | Word/Excel/PDF/md·txt·csv + MediaSet/DocIntel 最小闭环 | 格式可解析入库可预览 |
| **P1** | JDBC **MySQL 必做**；其余 PG/SQLServer/SaaS **滚动尽量多做** | MySQL Sync 可用；插件扩展点就绪 |
| **不强制** | 官方级 200+ Connector | 不作为门槛 |

**补强必做：** 小文件 &lt;128KB 短路 · DocIntel DLQ · MediaReference · Schedule · 边缘 Agent。

---

## 2. 架构

```text
data-connection-service
├── Connector Plugin Host     # 注册/凭证槽/健康
├── Sync / Schedule           # 批量·流式·Cron·上游触发
├── Edge Agent                # 客户侧出站拉任务（≠ AIP Agent）
pipeline-service
├── DAG Orchestrator
├── Transform + Use LLM 节点
├── DocIntel + DLQ
lakehouse
├── Dataset (Iceberg) + Query
└── MediaSet Object Store
```

工程：`services/data-connection/` · `services/pipeline/` · Lakehouse 共享存储。

## 3. Connector 插件化

### 3.1 自有所需功能（先于开源）

| 功能项 | 我们要什么（产品/工程语义） | 验收要点 |
| --- | --- | --- |
| Connector Host | 自有注册表：安装/配置/discover/sync/health/卸载 | 新增插件不改 Host 核心 |
| 配置与密钥 | 连接级 configSchema；密钥只存 Vault/KMS **ref** | 明文拒绝 |
| Sync 契约 | 批量 / 流式 / Cron / 上游触发；状态可恢复 | MySQL + 文件 P0 可跑通 |
| 边缘 Agent | 客户侧出站拉任务、回报（≠ AIP Agent） | UI=`data-connection-agents` |
| Schema 发现 | 表/字段/类型映射进 Dataset 或路由 MediaSet | discover 可预览 |
| 滚动交付 | 不强制 200+；维护 §3.3 清单 | 双周更新状态 |

```text
manifest: id, version, kind(source|destination), configSchema, capabilities
lifecycle: install → configure → discover-schema → sync → health → uninstall
secrets: 按连接分槽；只存 Vault/KMS ref（T09）
UI: source-new / source-detail / sync 配置端面
```

### 3.2 开源参考（已核对）

| 仓 | 本地路径 | 检查结论 | 抄什么 | 不抄什么 |
| --- | --- | --- | --- | --- |
| **Meltano** | `A1_ETL/meltano`（`src/` · `pyproject.toml`） | Singer/ELT 插件协议与状态机成熟 | **插件协议 · 调度/状态** | 整站 UI；Airbyte 主仓 |
| **PyAirbyte** | `A1_ETL/pyairbyte`（包名 `airbyte`） | `get_source` / Declarative YAML / Docker 执行 | Python 侧轻量拉数、Shopify 等示例路径 | 当 AOS 连接器产品壳 |
| **airbyte-python-cdk** | `A1_ETL/airbyte-python-cdk`（`airbyte_cdk/`） | CDK 为 Connector 开发底座 | **自研马帮/ERP Connector 时抄 CDK 模式** | 依赖官方 200+ 目录当交付物 |
| **Debezium** | `A3_CDC/debezium` | CDC 事件与位点 | 流式/CDC 模式 | 强绑 Kafka Connect 产品名 |
| **Iceberg** | `A4_Lakehouse/iceberg` | 表格式/事务 | Dataset 表格式 | 把某个云实现写死 |
| **DuckDB** | `A4_Lakehouse/duckdb` | 本地/嵌入查询 | 开发与小规模查询 | 唯一生产仓 |

> **不拉主仓：** `airbytehq/airbyte` Monorepo 明示排除（见 `clone_airbyte_refs.ps1`）。需要官方 Connector 实现时，优先 **CDK + 单连接器移植**，或 Meltano tap。

### 3.3 连接器滚动清单（工程维护 · 已定）

| 状态 | 插件 ID | 说明 |
| --- | --- | --- |
| **必做·验收** | `file-local` · `file-object-store` · `jdbc-mysql` | P0 文件 + MySQL |
| **鼓励·排期** | `jdbc-postgres` · `jdbc-sqlserver` · `saas-shopify`（PyAirbyte 示例路径） | 按客户 |
| **待客户** | SAP 等 | 有参考再开 |
| **维护方式** | 本表为真源；发版纪要更新「已交付日期」；看板标签=`connector-rollout` | 产品/研发双周同步 |

## 4. 存储路由与非结构化

### 4.0 自有所需功能（先于开源）

| 功能项 | 我们要什么 | 验收要点 |
| --- | --- | --- |
| 存储路由 | Dataset / MediaSet Document|Spreadsheet / Stream 决策 | `<128KB` 短路可选 |
| MediaReference | Dataset 列→原件指针；预览缩略图 | dataset 页可点开 |
| DocIntel + DLQ | OCR/LLM 抽取失败进死信；可重试/跳过 | 单文件失败不卡整批 |
| 文件解析插件 | md/txt/csv · Office · PDF 文本层 · 扫描件 OCR | 插件可替换 |
| 对象存储 | MediaSet 原件落对象仓（S3 兼容） | 私有化可装 |
| Lakehouse 表 | Dataset 用 Iceberg（或等价）事务表格式 | 可 Preview / Lineage |

### 4.1 路由决策（产品 05 v1.4）

| 目标 | 条件 | UI |
| --- | --- | --- |
| Dataset | 表/半结构化；或 **&lt;128KB 且无需原件预览（短路）** | [`sync-routing.html`](../foundry/html/sync-routing.html) |
| MediaSet Document | PDF/图/音视频等需原件 | [`media-sets.html`](../foundry/html/media-sets.html) |
| MediaSet Spreadsheet | XLSX 等 | 同上 |
| Stream | 时序/CDC | sync 流式 |

### 4.2 MediaReference

Dataset 列 → MediaSet 文件指针；预览列缩略图见 [`dataset.html`](../foundry/html/dataset.html)。

### 4.3 DocIntel + DLQ

OCR/LLM 抽取失败 → **死信队列**；支持重试/跳过；失败原因进 [`lineage.html`](../foundry/html/lineage.html) / [`health.html`](../foundry/html/health.html)。

**UI：** [`pipeline-doc-intel.html`](../foundry/html/pipeline-doc-intel.html)

### 4.4 文件解析器插件（已决）

| 格式 | 插件 | 策略 |
| --- | --- | --- |
| md/txt/csv | `parser-text` | 直读 |
| doc/docx | `parser-office-word` | 抽文本 + 可选原件 MediaSet |
| xls/xlsx | `parser-office-sheet` | 表→Dataset 或 Spreadsheet MediaSet |
| pdf（文本层） | `parser-pdf-text` | 抽文本 |
| pdf（扫描件） | `parser-pdf-ocr` | **默认 PaddleOCR**（中文场景）；英文可切 Tesseract 插件 |

契约自有；OCR 实现可替换，**不**把某一 OCR 产品当 AOS 品牌。

#### 4.4.1 开源参考（OCR / 对象仓 · 本地缺口）

| 能力 | 候选 | 本地仓 | 建议 |
| --- | --- | --- | --- |
| OCR | **PaddleOCR** vs Tesseract | ✅ `refs/ocr/PaddleOCR`；✅ `refs/tesseract` | **默认 PaddleOCR**；下一程：`parser-pdf-ocr` **独立进程**；Tesseract 作英文/轻量插件 |
| 对象仓 | **MinIO** vs SeaweedFS / 客户 S3 | ✅ minio + minio-py；✅ `refs/seaweedfs` | Dev 参考 MinIO；大规模备选 SeaweedFS（Apache）；**AGPL → 客户先装**（[24 §3.2](24-AOS客户侧前置组件安装SOP.md)）；AOS 仅 `S3Adapter` |
| MCP 附录 | fastmcp-airbyte | ❌ 待 `-Tier P2` | 可选；不阻塞 L1 |

### 4.5 MCP 供数（可选附录 · 已定口径）

| 项 | 结论 |
| --- | --- |
| 定位 | 研发/Agent 侧可选通道，**不是** L1 主路径 |
| 参考 | `fastmcp-airbyte`（需补拉 `clone_airbyte_refs.ps1 -Tier P1`）；模式参考即可 |
| 产品规则 | MCP 只读；写回仍 Action；正式供数优先 Dataset/Object |
