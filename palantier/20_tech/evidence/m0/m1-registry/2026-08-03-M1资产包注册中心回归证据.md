## 3. 关键安全复验

| 门 | 结果 |
|---|---|
| 跨 publisher / body-query 伪造 scope | 拒绝；publisher scope 只取已验证 Principal |
| 生产 trust root 缺失/错误/未知/过期/撤销 | validate/publish 失败关闭；只读 GET 保持可用 |
| maker-checker | 创建者不能发布；批准主体重启回读后仍成立 |
| evidence update vs publish | 统一 advisory/row lock 顺序；竞态不能穿越原子门 |
| 并发 publish | 只有一次成功状态迁移，另一请求稳定 conflict |
| 目录换链与路径穿越 | allowlist root 外读取失败关闭 |
| 公共 GET 脱敏 | 不返回 metadata、artifactRef、actor、reason 或 evidenceSnapshot |
| 审计快照防伪 | 正确 snapshot + 任意伪造 revision 在 SQL INSERT 当场 `CheckViolation`；回滚后版本仍为 draft 且可正常回读 |
| DB/Python canonical | Unicode、emoji、转义、嵌套、极小浮点、负零、高精度浮点和超大整数样本字节/hash 完全一致 |
| 存量 signature evidence | draft/validated 迁移为 canonical envelope hash + profile；有 normalized 数据时 downgrade 失败关闭 |
| 敏感信息扫描 | 2398 files；critical=0；warning=133（按既有策略不阻断，未输出命中正文） |
