## 3. 关键审查与修复

| 风险 | 关闭方式 |
|---|---|
| 同 publisher/id/version 重复候选导致 snapshot 歧义 | DTO 拒绝重复坐标，排序和 hash 只接受唯一候选集合 |
| manifest 派生索引可被客户端伪造 | dependencies/conflicts/capabilities/permissions/migration/contributions 必须与签名 manifest 精确一致 |
| publisher 缺省造成跨发布者歧义 | 依赖缺省只继承声明者；顶层请求必须显式 publisher |
| diff 看似存在但集合数学不精确 | 固定为 target-baseline、baseline-target、intersection；owner coordinate 不丢失 |
| lock 损坏错误泄漏内部信息 | `LOCK_INTEGRITY_CORRUPT` 使用固定安全消息且不返回底层 details |
| overlayRevision 契约漂移 | 统一为 1～160 字符、trim 后非空且无 NUL 的规范化文本 |
| rolled_back/active 指针可能指向错误历史 | active 必须等于 previous active（null-safe）且不得等于本次 current revision |
| 公共 API 面膨胀 | 包级只导出五个冻结 DTO，并由防膨胀测试锁定 |

独立 Worker 终审与总控复查均未发现残余 P0/P1 阻断。
