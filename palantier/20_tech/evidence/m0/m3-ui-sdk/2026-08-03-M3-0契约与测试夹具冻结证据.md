## 5. 一致性与风险

- 新增代码只消费当前 M2-B API/DTO，没有修改服务端 schema、route、权限、CAS、receipt、evidence 或状态机。
- Registry 路由 OpenAPI 只能表达动态 object，无法自动生成字段完备的 TS 类型；本波使用 Store/API 真实公共投影 fixture 和严格 parser。后端合法新增字段时前端会失败关闭，需要显式同步契约。
- TypeScript `Sha256` 模板类型只能表达 `sha256:` 前缀，64 位小写十六进制仍由后端和后续 runtime adapter 校验。
- Registry `contributions` 当前诚实保留为 object array，渲染贡献明细前需基于真实 discriminated union 继续收紧。
- 首次从仓库根目录直接运行 Vitest 未加载 Web jsdom 配置而出现环境性失败；从 `apps/web` 按项目真实方式重跑后 1795/1795 GREEN，该次误运行不构成代码回归。
