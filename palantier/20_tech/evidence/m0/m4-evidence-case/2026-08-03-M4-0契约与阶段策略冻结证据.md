## 3. 冻结事实

- Stage Policy 版本唯一为 `aos.integration-stage/v1`。
- 阶段固定为 planned 至 production_active 的 8 级最高连续门，缺前门不得跳级。
- 14 类 Evidence 使用判别式 strict claims；禁止自由 metadata、Secret、PII、primitive coercion 和客户端 stage/cutoff/metrics 注入。
- Policy 可直接消费已验证的 canonical Evidence DTO，不维护第二套公共 Evidence 契约。
- current/reference 使用判别联合；reference 的 owner、Installation、Overlay、Composition/Lock 均为 `null`，统计为 `null`。
- 列表统计为 6 项，详情指标为 4 项；无测量是 `null`，有效测量为零是 `0`。
- blocker 为服务端结构化投影；timeline oldStage 可空但只有 created 可从空进入 planned。
- Snapshot body 严格为空；响应固定 Policy、cutoff、nextProjectionAt、8 gates、blocker refs 与 ETag。
- Case create 只允许 installationId、overlayRevision、displayName。
- M4 新增稳定错误：`EVIDENCE_REFERENCE_INVALID` 422、`EVIDENCE_INTEGRITY_CORRUPT` 500。
- create 需要 `integration-case-maker`，snapshot 需要 `integration-case-projector`；普通 admin 不隐式获得写角色，admin 也不绕过 marking。
