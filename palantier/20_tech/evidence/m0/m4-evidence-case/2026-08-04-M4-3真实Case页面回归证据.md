## 3. 契约验证

- 页面不计算 Stage、hash、统计或权限，只展示 SDK 已校验的服务端事实。
- current/reference 切换清空筛选和旧选择；租户变化触发新 request key。
- 列表、详情、时间线旧响应不能覆盖新 scope/Case；三路错误互不污染。
- 刷新网络/服务错误保留最后一次服务端事实并明确显示 stale；401/403/404 清除旧事实。
- reference 不展示 owner、Installation、Overlay、Composition、Lock 或 blocker owner，且 stats 必须为 null。
- 运行路径不使用 fixture 兜底，不含创建 Case 或 Snapshot mutation。
