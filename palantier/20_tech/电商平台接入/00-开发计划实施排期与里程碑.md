## 8. 风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| 开发者账号审核延迟 | 阻塞平台接入 | 中 | 提前 2 周注册；先用沙箱环境开发 |
| 抖音解密资质未获批 | G8 阻塞 | 高 | 抖店云 Cloud Agent 方案兜底；先跳过加密字段 |
| Shopify App 审核延迟 | 阻塞 Shopify | 低 | 使用 Custom App（不需审核） |
| Amazon SP-API 审核延迟 | 阻塞 Amazon | 中 | 提前注册 Developer Profile；使用 Sandbox |
| REST Connector 工期超期 | 级联阻塞所有 REST 平台 | 中 | 优先实现最小可用版（仅 GET + 分页），POST/Webhook 后迭代 |
| 抖音接口计费超预算 | 成本风险 | 中 | 设置每日告警阈值；throttle 策略降频 |

## 9. 验收标准

每个平台接入完成的**Definition of Done**：

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | OAuth 授权 | 商家可在 AOS UI 中完成平台授权，Token 自动刷新 |
| 2 | 商品同步 | 全量商品拉取 + 增量同步，Workshop 可查看 |
| 3 | 订单同步 | 全量订单 + 增量同步，Workshop 可查看 |
| 4 | 跨平台聚合 | 跨平台 GMV 看板 + 统一订单列表 |
| 5 | 售后同步 | 退款/售后单同步（如有） |
| 6 | 物流同步 | 发货信息 + 物流轨迹（如有） |
| 7 | 平台特有功能 | 抖音达人/佣金、Amazon FBA、Shopify 多仓库存等 |
| 8 | 文档完成 | platform_mapping.json + Connector 配置 + 验收报告 |
