## 2. 平台技术画像对比

### 2.1 API 协议与认证

| 维度 | 微商城 | 淘宝/天猫 | 拼多多 | 京东 | 抖音 | Shopify | Amazon |
|------|--------|----------|--------|------|------|---------|--------|
| **协议** | JDBC | REST | REST | REST | REST | **GraphQL** | REST |
| **签名** | DB密码 | HMAC-SHA256 | **MD5** | HMAC-SHA256 | HMAC-SHA256 | Bearer Token | **AWS4** |
| **认证** | 直连 | OAuth2 | OAuth2 | OAuth2 | OAuth2 | OAuth2 | **LWAAuth+STS** |
| **Token有效期** | — | 24h | 24h | 24h | **15天** | 永久 | **1h** |
| **网关** | MySQL | gw.api.taobao | open-api.pdd | api.jd.com | op.jinritemai | {shop}.myshopify | sellingpartnerapi |

### 2.2 数据获取机制

| 维度 | 微商城 | 淘宝/天猫 | 拼多多 | 京东 | 抖音 | Shopify | Amazon |
|------|--------|----------|--------|------|------|---------|--------|
| **全量** | SQL | 分页 | 分页 | 分页 | 分页 | **Bulk Op** | **Reports** |
| **增量** | SQL diff | 无原生 | **有(15min)** | 有(en.search) | **RDS推送** | **Webhook** | **Notifications** |
| **实时** | SQL | trace.search | ordertrace | Waybill2C | logistics/track | — | — |
| **推荐同步策略** | SQL增量 | 定时分页 | 增量轮询 | 增量轮询 | RDS+轮询 | **Webhook优先** | **Reports+Notify** |

### 2.3 业务模型差异

| 维度 | 微商城 | 淘宝/天猫 | 拼多多 | 京东 | 抖音 | Shopify | Amazon |

## 3. 公共阻塞项

> **所有 REST 电商平台（除微商城外）均阻塞于以下通用平台能力：**

| 编号 | 缺口 | 影响范围 | 优先级 | 关联 220plan |
|------|------|---------|--------|-------------|
| **G1** | **REST API Connector** | 淘宝/拼多多/京东/抖音/Amazon | 🔴 阻塞 | W2+ #G1 |
| **G2** | **OAuth 2.0 Token Manager** | 淘宝/拼多多/京东/抖音/Shopify/Amazon | 🔴 阻塞 | W2+ #G2 |
| G3 | HMAC-SHA256 签名插件 | 淘宝/京东/抖音 | 🟡 阻塞 | 可插拔架构 |
| G4 | MD5 签名插件 | 拼多多 | 🟡 阻塞 | 可插拔架构 |
| G5 | AWS4-HMAC-SHA256 签名插件 | Amazon | 🟡 阻塞 | 可插拔架构 |
| G6 | GraphQL Connector 类型 | Shopify | 🟡 阻塞 | 新 Connector 类型 |
| G7 | Webhook Receiver 端点 | Shopify | 🟡 阻塞 | 新事件入口 |
| G8 | 敏感数据解密插件 | 抖音 | 🔴 阻塞 | 安全合规模块 |
| G9 | 接口计费控制器 | 抖音 | 🟡 阻塞 | 成本监控 |
| G10 | 报表下载+解析 Pipeline | Amazon | 🟡 阻塞 | 新 Pipeline 类型 |

### 解锁路径

```text
G1 REST Connector + G2 OAuth Manager
  │  ← 一经验收，同时解锁 5 个平台
  ▼
淘宝/拼多多 ──→ G3 HMAC + G4 MD5 签名插件 ──→ ✅ 解锁
京东 ─────────→ G3 HMAC 签名插件 ──→ ✅ 解锁
抖音 ─────────→ G3 HMAC + G8 解密 + G9 计费 ──→ ✅ 解锁
Amazon ───────→ G5 AWS4 + G10 报表Pipeline ──→ ✅ 解锁
Shopify ──────→ G6 GraphQL + G7 Webhook ──→ ✅ 解锁
```

### 推荐实施顺序

| 阶段 | 平台 | 理由 |
|------|------|------|
| **Phase 1** | 淘宝/天猫 | 复杂度中等、文档最全、国内最主流 |
| **Phase 1** | 拼多多 | 与淘宝共用 REST+OAuth，增量开发成本低 |
| **Phase 2** | 京东 | POP/自营双模式，但 Connector 架构可复用 |
| **Phase 2** | Shopify | GraphQL 差异大，但 Webhook 机制优秀 |
| **Phase 3** | 抖音 | 最复杂（加密+计费+达人），最后接入 |
| **Phase 3** | Amazon | 最复杂（AWS4+多区域），最后接入 |
