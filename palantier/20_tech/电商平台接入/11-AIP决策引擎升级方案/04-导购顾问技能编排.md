## 一、导购顾问定位

### 1.1 职责边界

**导购顾问管"卖什么"** — 产品推荐、肤质匹配、搭配方案、对比分析。

| 职责 | 不做什么 |
|------|---------|
| ✅ 需求诊断：肤质测试、需求问卷、痛点识别 | ❌ 写文案脚本（内容官的职责） |
| ✅ 产品推荐：个性化推荐、关联推荐、新品推荐 | ❌ 客户运营/触达（私域管家的职责） |
| ✅ 成分分析：成分安全、功效匹配、过敏原检测 | ❌ 做活动策划（活动策划师的职责） |
| ✅ 对比分析：产品对比、优缺点分析、选择建议 | ❌ 数据分析（数据参谋的职责） |
| ✅ 搭配方案：早C晚A、护肤步骤、套装组合 | ❌ 售后问题（客服专员的职责） |
| ✅ 促单话术：异议处理、下单引导、赠品推荐 | ❌ 医疗诊断（免责，仅护肤建议） |

### 1.2 核心洞察

> 电商导购现状：客服兼职导购，靠培训手册记忆，推荐不精准，转化率低。
> **导购顾问不是"机器人客服"，是"懂产品的美容顾问"** — 懂成分、懂肤质、懂搭配，像朋友一样给建议。

### 1.3 适用场景

| 场景 | 触发方式 | 导购顾问角色 |
|------|---------|-------------|
| 新客首次咨询 | 客户主动提问 | 需求诊断 + 入门款推荐 |
| 老客复购推荐 | 客户回访/主动触达 | 进阶款推荐 + 搭配方案 |
| 产品详情页咨询 | 浏览产品时提问 | 成分解读 + 适配性分析 |
| 产品对比 | 客户拿不定主意 | 多产品对比 + 选择建议 |
| 护肤方案定制 | 客户要全套方案 | 完整护肤流程 + 产品组合 |
| 异议处理 | 客户犹豫不下单 | 痛点回应 + 信任建立 + 促单 |

## 二、技能链总览

导购顾问包含 6 个技能，按咨询流程：

```
技能1：需求诊断  →  技能2：产品检索  →  技能3：成分分析
                                            │
                                 ┌──────────┘
                                 ▼
                           技能4：产品对比
                                 │
                                 ▼
                           技能5：搭配方案
                                 │
                                 ▼
                           技能6：异议处理与促单
```

| 技能 | 触发条件 | 核心动作 | 风险等级 | 需要审批 |
|------|---------|---------|---------|---------|
| 1.需求诊断 | 对话开始时 | 提问+肤质分析+需求提炼 | low | ❌ 自动执行 |
| 2.产品检索 | 需求明确后 | 多维度筛选+排序+推荐 | low | ❌ 自动推荐，客户自选 |
| 3.成分分析 | 产品详情/客户询问 | 成分解读+安全检测+功效评估 | medium | ✅ 医疗相关建议需免责 |
| 4.产品对比 | 客户对比2+产品 | 多维度对比+优劣势+推荐 | low | ❌ 自动输出 |
| 5.搭配方案 | 客户要全套/进阶 | 护肤流程+产品组合+使用顺序 | medium | ✅ 敏感肌方案需特别提醒 |
| 6.异议处理与促单 | 客户犹豫/有顾虑 | 痛点回应+信任建立+促单话术 | medium | ✅ 承诺类话术需合规审查 |

## 三、技能1：需求诊断

### 3.1 场景

客户来咨询，但不知道自己需要什么。导购顾问通过提问和分析，精准定位客户需求。

### 3.2 Plan Mode 设计

```
用户输入："我想买护肤品，有什么推荐吗？"
        │
        ▼
┌──────────────────────────────────────────┐
│ Clarification Gate（核心）                │
│                                          │
│ 第一轮：基础信息                           │
│ Q1: 你的肤质是？（干/油/混/敏感/中性）     │
│ Q2: 年龄区间？（18-25/26-35/36-45/45+）   │
│ Q3: 主要想解决什么问题？（多选）            │
│     补水 / 美白 / 抗衰 / 祛痘 / 敏感修护    │
│                                          │
│ 第二轮（根据回答深入）：                    │
│ Q4: 之前用过什么产品？（可选）             │
│ Q5: 预算范围？（可选）                     │
│ Q6: 有没有过敏史？（重要）                 │
└──────────────┬───────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────┐
│ Plan Generation — 生成执行计划            │
│                                          │
│ Step 1: 提取客户需求（结构化）            │
│   action_type: llm_call                   │
│   model: private-medium                   │
│   task: "需求结构化提取"                   │
│   risk: low                               │
│                                          │
│ Step 2: 读取客户历史（如果是老客）         │
│   action_type: ontology_query             │
│   query: Customer OT + Order OT           │
│   risk: low                               │
│                                          │
│ Step 3: 生成肌肤画像（SkinProfile）       │
│   action_type: tool_call                  │
│   tool: skin_profile.generate             │
│   risk: medium                            │
│                                          │
│ Step 4: 输出需求摘要 + 推荐方向            │
│   action_type: tool_call                  │
│   tool: artifact.create                   │
│   risk: low                               │
└──────────────────────────────────────────┘
```

### 3.3 输出结构

```typescript
interface CustomerNeedsDiagnosis {
  // 基础信息
  skinType: 'dry' | 'oily' | 'combination' | 'sensitive' | 'normal' | 'unknown';
  ageRange: string;
  budgetRange?: [number, number];

  // 核心需求
  primaryConcerns: string[];       // 主要诉求（最多3个）
  secondaryConcerns: string[];     // 次要诉求

  // 肌肤画像
  skinProfile: {
    hydration: 'low' | 'medium' | 'high';
    oiliness: 'low' | 'medium' | 'high';
    sensitivity: 'low' | 'medium' | 'high';
    agingSigns: 'none' | 'mild' | 'moderate' | 'severe';
    pigmentation: 'none' | 'mild' | 'moderate';
  };

  // 过敏原/禁忌
  allergies: string[];             // 已知过敏原
  contraindications: string[];     // 禁忌成分

  // 推荐方向
  recommendedDirections: {
    category: string;              // 推荐品类
    reason: string;                // 推荐理由
    priority: number;              // 优先级
  }[];

  // 置信度
  confidence: 'high' | 'medium' | 'low';
  additionalQuestions: string[];   // 需要进一步确认的问题
}
```

### 3.4 权限门控

| 操作 | 风险等级 | 门控 |
|------|---------|------|
| 需求诊断 | low | 自动执行 |
| 读取客户历史 | low | 自动读取（需客户授权） |
| 生成肌肤画像 | medium | 标注「仅供参考，非医疗诊断」 |

### 3.5 Reflection 自审规则

```python
REFLECTION_RULES = {
    "needs_diagnosis": [
        {
            "name": "medical_disclaimer_check",
            "condition": "has_medical_disclaimer(output)",
            "on_fail": "add_disclaimer"
        },
        {
            "name": "not_enough_info_check",
            "condition": "confidence != 'low' or has_additional_questions",
            "on_fail": "ask_more_questions"
        },
        {
            "name": "allergy_emphasis_check",
            "condition": "if_allergies_then_emphasize(allergies, output)",
            "on_fail": "add_allergy_warning"
        }
    ]
}
```

### 3.6 记忆依赖

| 记忆层 | 用途 | 具体内容 |
|--------|------|---------|
| **Semantic** | 行业知识 | 肤质分类体系、成分功效知识库、问答模板 |
| **Episodic** | 历史经验 | 常见咨询模式、高转化问答对、异议处理话术 |
| **Working** | 当前任务 | 客户回答、需求提取、肌肤画像 |

### 3.7 验收标准

- [ ] 模糊提问 → 引导式提问 ≤ 3 轮即可明确需求
- [ ] 输出结构化的需求摘要和推荐方向
- [ ] 有明确的「非医疗诊断」免责声明
- [ ] 已知过敏的客户有重点提醒
- [ ] 老客能自动读取历史购买记录

## 四、技能2：产品检索与推荐

### 4.1 场景

需求明确后，从产品库中检索匹配的产品，按推荐度排序，给出 Top N 推荐。

### 4.2 Plan Mode 设计

```
用户输入："我是干皮，想要补水的精华"
        │
        ▼
┌──────────────────────────────────────────┐
│ Plan Generation — 生成执行计划            │
│                                          │
│ Step 1: 需求解析（从技能1输出/用户输入）    │
│   action_type: llm_call                   │
│   model: private-medium                   │
│   task: "需求→检索条件"                    │
│   risk: low                               │
│                                          │
│ Step 2: 产品检索（多维度筛选）             │
│   action_type: ontology_query             │
│   query: Product OT                       │
│   filters: {                              │
│     category: "serum",                    │
│     skin_type: "dry",                     │
│     benefits: ["hydration"],              │
│     exclude_allergens: true               │
│   }                                        │
│   risk: low                               │
│                                          │
│ Step 3: 产品评分与排序                     │
│   action_type: tool_call                  │
│   tool: product_recommender.score         │
│   factors: [                              │
│     "功效匹配度(35%)",                     │
│     "肤质适配度(25%)",                     │
│     "客户好评率(15%)",                     │
│     "性价比(15%)",                         │
│     "复购率(10%)"                          │
│   ]                                        │
│   risk: low                               │
│                                          │
│ Step 4: 生成推荐理由（个性化）             │
│   action_type: llm_call                   │
│   model: private-medium                   │
│   prompt: "为每个推荐产品生成个性化推荐理由" │
│   risk: low                               │
│                                          │
│ Step 5: 输出 Top 5 推荐                  │
│   action_type: tool_call                  │
│   tool: artifact.create                   │
│   risk: low                               │
└──────────────────────────────────────────┘
```

### 4.3 输出结构

```typescript
interface ProductRecommendations {
  query: string;               // 原始查询
  searchCriteria: Record<string, any>;  // 检索条件

  // 推荐列表
  products: {
    rank: number;
    productId: string;
    productName: string;
    category: string;
    price: number;
    imageUrl: string;

    // 评分
    totalScore: number;       // 0-100
    scoreBreakdown: {
      efficacyMatch: number;
      skinFit: number;
      reviews: number;
      value: number;
      repurchase: number;
    };

    // 推荐理由
    recommendationReason: string;  // 个性化理由
    keyBenefits: string[];         // 核心卖点（针对客户需求）
    suitableFor: string;           // 适合人群
    whyRecommended: string;        // 为什么推荐给 TA

    // 注意事项
    caveats?: string[];            // 注意事项/使用提醒
    patchTestRequired: boolean;    // 是否需要测敏
  }[];

  // 推荐说明
  explanation: string;
  totalProductsFound: number;
  filteredOutCount: number;
  filterReasons: string[];         // 被过滤掉的原因（如「含酒精，敏感肌不推荐」）
}
```

### 4.4 权限门控

| 操作 | 风险等级 | 门控 |
|------|---------|------|
| 产品检索 | low | 自动执行 |
| 生成推荐理由 | low | 自动生成 |
| 推荐结果 | low | 标注「AI推荐，仅供参考」 |

### 4.5 记忆依赖

| 记忆层 | 用途 | 具体内容 |
|--------|------|---------|
| **Semantic** | 行业知识 | 产品知识库、成分功效库、肤质-产品映射 |
| **Episodic** | 历史经验 | 各肤质爆款、高转化产品、常见搭配、客户反馈 |
| **Working** | 当前任务 | 检索条件、产品列表、评分结果 |

### 4.6 验收标准

- [ ] 输入肤质+需求，能输出 Top 5 推荐
- [ ] 每个产品有评分、推荐理由、核心卖点
- [ ] 过敏成分自动过滤
- [ ] 推荐理由个性化（不是模板化）
- [ ] 有「仅供参考」提示

## 五、技能3：成分分析

### 5.1 场景

客户想了解某个产品的成分，或者想知道某成分是否安全、是否适合自己。

### 5.2 Plan Mode 设计

```
用户输入："帮我看看这款面霜的成分怎么样"
        │
        ▼
┌──────────────────────────────────────────┐
│ Plan Generation — 生成执行计划            │
│                                          │
│ Step 1: 读取产品成分数据                   │
│   action_type: ontology_query             │
│   query: Product.ingredients              │
│   risk: low                               │
│                                          │
│ Step 2: 成分分类与解析                    │
│   action_type: tool_call                  │
│   tool: ingredient_analyzer.classify      │
│   categories: [                           │
│     "保湿剂", "乳化剂", "防腐剂",          │
│     "活性成分", "香精", "风险成分"         │
│   ]                                        │
│   risk: low                               │
│                                          │
│ Step 3: 安全性评估                        │
│   action_type: tool_call                  │
│   tool: ingredient_analyzer.safety        │
│   data_source: "ewg + cosdna + 内部知识库" │
│   risk: medium                            │
│                                          │
│ Step 4: 功效分析                          │
│   action_type: tool_call                  │
│   tool: ingredient_analyzer.efficacy      │
│   risk: low                               │
│                                          │
│ Step 5: 适配性评估（针对客户肤质）         │
│   action_type: tool_call + llm_call       │
│   tool: ingredient_analyzer.fit_assessment
│   risk: medium                            │
│                                          │
│ Step 6: 生成易懂的成分解读报告             │
│   action_type: llm_call                   │
│   model: private-medium                   │
│   prompt: "用通俗的语言解读成分，专业但易懂" │
│   risk: low                               │
│                                          │
│ Step 7: 自检验证（合规性）                │
│   action_type: skill_call                 │
│   skill: ingredient_compliance_check      │
│   risk: high                              │
│                                          │
│ Step 8: 写入 Artifact                    │
│   action_type: tool_call                  │
│   risk: low                               │
└──────────────────────────────────────────┘
```

### 5.3 输出结构

```typescript
interface IngredientAnalysis {
  productId: string;
  productName: string;

  // 成分总览
  overview: {
    totalIngredients: number;
    activeIngredients: string[];     // 核心活性成分
    keyBenefits: string[];           // 主要功效
    safetyRating: 'excellent' | 'good' | 'moderate' | 'low' | 'high_risk';
    irritantRisk: 'low' | 'medium' | 'high';
  };

  // 成分分类详解
  categories: {
    category: string;
    ingredients: {
      name: string;
      concentration?: 'high' | 'medium' | 'low';  // 浓度推测（按成分表排序）
      function: string;
      safetyScore: number;       // 0-10
      benefit: string;
      concern?: string;          // 可能的顾虑
    }[];
  }[];

  // 亮点成分
  starIngredients: {
    name: string;
    whyItMatters: string;
    evidence: string;            // 功效证据
  }[];

  // 风险提示
  risks: {
    level: 'none' | 'mild' | 'moderate' | 'severe';
    items: {
      ingredient: string;
      risk: string;
      severity: 'low' | 'medium' | 'high';
      recommendation: string;
    }[];
  };

  // 适配性评估
  fitAssessment: {
    skinType: string;
    suitability: 'excellent' | 'good' | 'moderate' | 'not_recommended';
    reasons: string[];
    suggestions: string[];
  };

  // 常见问题
  faqs: {
    question: string;
    answer: string;
  }[];

  // 免责声明
  disclaimer: string;

  sources: string[];             // 数据来源
}
```

| 操作 | 风险等级 | 门控 |
|------|---------|------|
| 成分分析 | medium | 自动执行，必须附免责声明 |
| 安全性评估 | high | 数据来源标注，不做医疗判断 |
| 适配性建议 | medium | 标注「建议先测敏」 |

### 5.6 记忆依赖

| 记忆层 | 用途 | 具体内容 |
|--------|------|---------|

- [ ] 敏感肌有「建议测敏」提示

## 六、技能4：产品对比

### 6.1 场景

客户在两个或多个产品之间纠结，需要帮客户对比分析，给出选择建议。

### 6.2 Plan Mode 设计

```
用户输入："A精华和B精华哪个好？"
        │
        ▼
┌──────────────────────────────────────────┐
│ Plan Generation — 生成执行计划            │
│                                          │
│ Step 1: 读取两款产品的完整数据             │
│   action_type: ontology_query             │
│   query: Product OT (A + B)               │
│   risk: low                               │
│                                          │
│ Step 2: 多维度对比                        │
```

## 八、技能6：异议处理与促单

### 8.1 场景

客户有顾虑、犹豫不下单，导购顾问针对性回应，建立信任，促进下单。

### 8.2 常见异议类型

| 异议类型 | 典型话术 | 处理方向 |
|---------|---------|---------|
| 价格类 | "太贵了"、"能不能便宜点" | 价值塑造、性价比分析、分期付款 |
| 效果类 | "真的有用吗"、"没效果怎么办" | 成分证据、用户评价、售后保障 |
| 安全类 | "会不会过敏"、"成分安全吗" | 成分分析、测敏建议、售后政策 |
| 对比类 | "和XX比怎么样" | 客观对比、差异化优势、适用场景 |
| 决策类 | "我再想想"、"再看看" | 痛点强化、稀缺性、赠品激励 |
| 信任类 | "没听过这个牌子"、"靠谱吗" | 品牌背书、资质证明、客户评价 |
