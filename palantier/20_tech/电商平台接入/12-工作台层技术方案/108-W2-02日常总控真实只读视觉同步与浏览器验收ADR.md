## 1. 问题与裁决

W2-02 已有 Task/latest Run、Step、Checkpoint 的 canonical GET-only 页面，但运行时仍是通用卡片布局，与正式视觉稿的“指标带—指令带—角色/任务/复盘主区—共享能力带”信息架构不一致。菜单、功能与视觉不能分离交付；一旦页面进入实现，就必须在真实浏览器中按视觉基线验收。

本子波只同步**已具备权威来源的只读信息**。视觉稿中的 GMV、订单、达人、价格、内容、活动、六数字同事在线状态、职责分配、复盘结论、共享 Agent 可用性与任务下达能力，目前没有 W2-02 response authority，禁止从静态稿复制示例值或由前端推断。

裁决：保留视觉稿的信息层级和空间关系；有 canonical 数据的区域显示真实值，没有 authority 的区域在原位置显示明确阻断态。不得添加可用的命令输入、下达按钮、乐观状态、本地缓存或伪造经营数字。

## 4. 测试与浏览器验收门

1. 专项组件测试：真实计数、四段视觉 landmark、原始 blocker、无 command input/submit、无虚构经营文案。
2. 累计 Workshop/Web 回归、TypeScript、生产构建、`git diff --check`。
3. 内置浏览器以 `org-org/dev-project` 验收 `/workshop/cockpit`：1280×900、1440×900、1920×900，无水平溢出；唯一 H1；真实 Task/Run 数；阻断带与 blocker 可见；命令输入/可用写按钮为 0；控制台 error 为 0。
4. 403、empty、stale、failed 仍由统一状态边界失败关闭；不得把错误或未知显示为空集合。
5. 浏览器数据只允许本地只读启动，`AOS_DB_MIGRATION_MODE=disabled`、`AOS_QYH_CRON_ENABLED=false`；不启动迁移/Cron，不写真实业务数据。

## 5. 风险与回滚

- 风险：把静态视觉示例误认为运行事实。缓解：所有可见数字只能由现有 response 派生，阻断区域不列示例角色、Agent、GMV 或复盘结果。
- 风险：三栏在小视口溢出。缓解：1920 保持视觉稿层次，1440/1280 收敛栏宽，小屏按单列降级；浏览器记录 `clientWidth/scrollWidth`。
- 风险：视觉重组破坏 stale/并发保护。缓解：不改 request/store 逻辑，保留 request id、409 preserved content 与 Run detail 原实现及测试。
- 回滚：只回退本子波三份运行时文件和证据提交，不改变 API、数据库或静态视觉稿。
