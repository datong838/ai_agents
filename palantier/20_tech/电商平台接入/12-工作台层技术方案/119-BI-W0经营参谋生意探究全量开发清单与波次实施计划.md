## 1. 计划结论

本新增能力按“先补齐既有经营事实权威，再建设生意探究公共合同，最后接通工作台”的顺序实施，共 **12 个宏观波次（BI-W0～BI-W11，其中 BI-W0 分 A/B 两个评审门）、93 项可审计任务**。开发不能从页面开始，也不能把浏览器观察、源库 SQL、AIP TaskRun 或 Workshop 投影变成店铺经营事实的第二真源。

```text
当前强制前置链
Data D0 → W2-01A → W3-12A → W2-01B → W3-12B
                                  │
                                  └──── 生意探究可用经营事实基线

新增能力主链
BI-W0A 现场冻结
  → BI-W0B 精确合同与施工包
  → BI-W1 共享语义合同
  → BI-W2 数据需求权威
  → BI-W3 观察、映射与语义水合
  → BI-W4 Case/Run 领域权威
  → BI-W5 AIP 分析编排
  → BI-W6 Receipt-first 跨层编排
  → BI-W7 Workshop 只读工作区
  → BI-W8 命令、计划、Handoff 与恢复
  → BI-W9 三类平台 AdapterPack
  → BI-W10 真实只读试点
  → BI-W11 累计验收与发布决定
```

当前唯一开发主线为 `aos-platform/m1`，由同一开发者串行维护四层代码。对象 Authority 的所有权边界仍保持不变；“单人开发”只消除等待其他开发者的组织依赖，不允许绕过租户、安全、迁移、真实外部副作用或发布门。迁移 Lease、OpenAPI/Bundle 注册、authority CAS 和跨层累计验收必须串行。

所有 exact ref 固定为 `resourceType/resourceId/revision/contentHash`，跨层恢复再增加 `receiptId`；`contentHash` 使用带 `sha256:` 前缀的 64 位小写十六进制。共享枚举冻结为：

| 轴 | 枚举 |
|---|---|
| Case lifecycle | `DRAFT / ACTIVE / ARCHIVED / CLOSED` |
| Run lifecycle | `PREPARING / WAITING_DATA / PORTRAIT / DIAGNOSIS / SOLUTION_DESIGN / REVIEW / COMPLETED / FAILED` |
| Run control | `RUNNING / PAUSED / BLOCKED / STALE / UNKNOWN / RECONCILING / CANCELLED` |
| Requirement | `REQUESTED / ACCEPTED / PLANNED / FULFILLED / REJECTED / CANCELLED / UNKNOWN` |
| Observation | `DRAFT / READY / RUNNING / PAUSED / BLOCKED / UNKNOWN / RECONCILING / COMPLETED / CANCELLED` |
| Review | `PENDING / ACCEPTED / RETURNED / MORE_EVIDENCE_REQUIRED` |
| Handoff | `PREPARED / ISSUED / ACCEPTED / REJECTED / MORE_REQUIRED / EXPIRED` |

Run lifecycle 与 control 是两个独立字段；禁止把 `BLOCKED` 填入 lifecycle 或用 `COMPLETED` 覆盖 UNKNOWN。首版不允许跨渠道 Case，服务端固定返回 `CROSS_CHANNEL_COMPARISON_NOT_SUPPORTED`。

### 7.4 Receipt-first Saga 与恢复

跨层只传 exact refs、commandId、idempotency hash 和 Receipt，不跨库事务：

```text
L1 Run PREPARING + Outbox
→ AIP CompilationReceipt
→ L1 CAS bind TaskRun/Plan/Skill/Logic refs
→ AIP DataRequirement command
→ Data FulfillmentReceipt
→ AIP checkpoint resume
→ candidate artifact
→ L1 ArtifactPublicationReceipt
```
