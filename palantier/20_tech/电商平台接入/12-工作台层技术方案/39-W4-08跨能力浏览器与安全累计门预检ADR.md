## 1. 结论

W4-08 不是第八套业务 authority，而是 W4-01～W4-07 的累计验收门。2026-08-25 按 `AOS-000233` 重新核验后，七项前置交付均已形成独立代码提交、专项测试、内置浏览器证据和 Delivery Receipt；旧文档中“七项均未实现”的判断已经失效。

本波不为了“累计”再造第四套 Store、聚合 DTO 或假聚合页。实现策略是：先用机器可重复的交付证据核验锁定七项精确提交和安全声明，再执行后端/前端累计回归，最后在同一内置浏览器任务中依次复核 Evidence/Eval/Review、Knowledge/Memory、SavedExploration 与三 authority Job 投影的可见状态和失败关闭。只有测试暴露实际产品缺口时才允许最小修复。

## 2. 唯一累计旅程

至少选择一个已安装 Workshop Module 和一个真实业务 subject，在同一 TenantScope、Principal 与 purpose 下完成：

```text
subject context
  → server-built EvidenceBundle
  → Evidence Citation L1/L2/L3 authorized disclosure
  → exact EvalContract run
  → ReviewIssue / ReturnDecision / new attempt / rerun
  → KnowledgeQuery or governed MemoryCandidate
  → SavedExploration exact save/share/readback
  → refresh/deep-link recovery and readable Receipt/Lineage
```

统一的是页面上下文、exact refs、只读投影和可审计导航，不是把 Evidence、Eval、Review、Memory、Research 或 SavedExploration 合并成一个可写 Store。

## 3. 安全与故障矩阵

| 场景 | 必须结果 |
|---|---|
| 跨租户或 subject 越权 | 服务端失败关闭，返回零受保护元数据与正文 |
| Principal marking 不足 | Bundle 摘要、Citation 和 Saved view 均不得由前端遮盖替代授权 |
| Evidence/source 撤销或 hash 漂移 | 旧 Bundle/合同/视图明确 stale 或 blocked，不改写历史 |
| Eval publication/release gate 撤销 | exact Eval 与下游 frozen preview 传递失效 |
| Review 返工 | 更高 attempt 可执行，受影响下游失效，旧产物与评价保留 |
| Knowledge provider unavailable | 503/blocked，可解释且不生成无引用兜底文本 |
| Saved view 分享过期或撤销 | 旧 opaque ref 立即失败关闭，不依赖浏览器缓存 |
| Research/Query unknown | 先按 exact job ref reconcile，禁止盲目重提或显示完成 |
| 刷新、后退、深链 | 服务端按 scoped refs 恢复；localStorage 不成为 authority |

安全检查必须同时验证最小披露、purpose、marking、license、redaction、expiry、revoke、CAS、幂等、RLS/FORCE RLS、Receipt 和 Lineage。历史 Citation/Receipt 只证明当时发生过披露，不是持续访问令牌。

## 4. 浏览器验收证据要求

1. 只在 W4-01～W4-07 逐项 GREEN 后启动；本次前置条件由七份 Delivery Receipt 与对应 Git 提交独立核验。
2. 使用正式 HTTP 与 Canonical SDK。真实 `org-org/dev-project` 有权威行时以真实只读回读为正向证据；本地确定性 fixture 只用于 UI 状态、刷新/深链与失败关闭验收，必须明确标注，不能冒充生产运营事实。
3. 记录路由、用户可见状态、关键 exact refs、服务端 Receipt/Event 和最终回读；截图不得包含 Secret、Cookie、完整 PII 或未授权 Evidence 正文。
4. 覆盖 loading、empty、partial/degraded、blocked、stale、revoked、expired、unknown、failed 和 recovered；任何未知执行结果都不能显示为成功。
5. 正向真实租户仅允许 `org-org/dev-project`；`dev-org/dev-project` 只作隔离 canary，不得当作真实完成证据。
6. 浏览器刷新与深链必须恢复同一 authority 状态，禁止依赖前端残留对象拼回生命周期。
