## 1. 决策

W1-09 的代码与控制面已 GREEN，但 W8-08 是 release 级生命周期累计门，不能由 W1-09 单独签发。当前 W1-10 及 W2-10～W7-11 未 GREEN，真实 Registry 仍有冲突，且没有 real-effect 授权/Lease；因此本轮只冻结验收合同，不执行 publish、install、upgrade、rollback、uninstall、真实路由切换或退役。

## 2. 五种独立语义

1. install：创建新 Installation 与不可变 revision/event/evidence 链，不覆盖旧 Installation。
2. upgrade：创建新 replacement Installation，immutable lock 固定一个 exact predecessor coordinate；激活后每个排他 Module/route/slot 只有一个 effective leaf。
3. rollback：通过完整 replacement graph 恢复 exact predecessor；新旧 Installation 与全部事件均保留。
4. uninstall：append-only terminal transition，使目标 Installation 离开 effective catalog；同一 Installation 不原地恢复，恢复能力需新建并重新评审 Installation。
5. route retirement：观察期后的显式 release decision，不由 active、redirect、版本年龄或前端隐藏自动触发。

W0 早期“复用同一 Installation 的 previous_active_revision”假设已由 W1-E 实现裁决取代；不得再次作为执行依据。

## 3. 唯一生命周期

`publish immutable Bundle → exact Resolver diff → create/submit/approve → dry apply/apply/verify → activate replacement → catalog read-switch → legacy redirect observation → explicit retirement`。

完整图先解析唯一 effective leaf，再应用 leaf marking visibility；否则不可见的新 leaf 会让旧 predecessor 错误回流。unknown schema、hash drift、missing/revoked artifact、stale lock、broken predecessor、fork、cycle、sibling activation 或 route/slot collision 均失败关闭，不能按时间挑“最新”。

所有命令使用 Principal TenantScope、ETag/expected revision、Idempotency-Key、maker-checker、确定锁序和 append-only Receipt。正向只认 `org-org/dev-project`；`dev-org/dev-project` 只作零数据隔离 canary。

## 4. 退役门

旧 route 退役前必须同时满足：source→target capability/permission parity 100%、canonical route 正向 browser GREEN、零新 authoring、流量完成批准观察窗口、saved links/通知/文档/集成迁移清单闭合、rollback drill 可恢复 predecessor 与入口行为、release owner 签发 retirement Receipt。任一项 unknown 均保持 redirect，不删除历史 route ref。

## 5. 验收矩阵

- clean install 从无 active 到八 exact Module 投影；
- A→B→C upgrade，每步唯一 leaf，C→B→A 逐级 rollback；
- uninstall 当前 leaf 后目录消失、历史仍可读、同记录重新 active 失败；
- create/verify/activate/rollback/uninstall 并发冲突在确定锁序与 CAS 下收敛；
- hash、marking、graph、tenant、late response、restart 与 stale ref 全部负向；
- legacy 深链只在 replacement exact lock active 时 redirect，rollback 后恢复正确入口；
- retirement 缺 parity、观察、saved-link 或 rollback 任一证据时失败关闭。

EvidencePack 固定 Bundle/Composition/Installation/Module exact refs、命令 Receipt、前后 Catalog、数据库不可变历史计数、浏览器 DOM/network/console、双租户、并发/重启与 rollback drill。

## 6. 当前阻断
