## 使用的 Rules

| Rule | 应用 |
|------|------|
| 先方案后编码 | 本文档为方案层，编码前需用户确认 |
| 最小更改 | 复用现有 OrderManagementPage + CanvasPage 基础设施 |
| 不影响现有功能 | 新增页面不修改现有工作台页面 |
| 跨平台通用 | 定义共性，差异下放各平台目录 |

## 一、工作台层在六层架构中的定位

```
Layer 2 · 工作台层（Workshop）
═══════════════════════════════════════
面向运营者的统一工作界面
├─ 数据看板（订单/商品/客户/库存）
├─ 任务驱动工作台（任务列表 + 执行详情 + Artifact 产出）
├─ 内容日历（排期 + 发布 + 素材）
├─ 活动策划（方案 + 效果预估 + 复盘）
└─ 数据参谋（BI 驾驶舱 + 异常告警 + 归因分析）

差异层（各平台自有目录下定义）
├── 02-淘宝接入/工作台细分.md
├── 03-天猫接入/工作台细分.md
├── 04-京东接入/工作台细分.md
├── 05-拼多多接入/工作台细分.md
├── 06-抖音接入/工作台细分.md
├── 07-快手接入/工作台细分.md
├── 08-Shopify接入/工作台细分.md
├── 09-Amazon接入/工作台细分.md
└── 10-微商城接入/工作台细分.md（客情维护平台归属此处）
```

**核心原则**：工作台层在电商平台接入目录中属于**通用层**，各平台可复用 80% 的组件，20% 的差异在各平台自有目录下定义。

## 二、9 个平台的当前工作台状态

### 2.1 已有页面（全平台通用）

| 页面 | 路由 | 状态 | 说明 |
|------|------|------|------|
| OrderManagementPage | `/workshop/orders` | A 档 | 真实 API，全平台通用 |
| WorkshopListPage | `/workshop` | B 档 | 工作台列表 |
| WorkshopCreatePage | `/workshop/create` | B 档 | 创建画布 |
| CanvasPage | `/workshop/canvas` | D 档 | 画布编辑器（2037 行） |
| VariablesPage | `/workshop/variables` | C 档 | 纯 Mock |
| EventsPage | `/workshop/events` | B 档 | GET 有 API，POST 未持久化 |

### 2.2 缺失工作台（按平台分类）

| 平台 | 缺失工作台 | 对接数字同事 | 关键差异 |
|------|-----------|-------------|---------|
| **微商城（私域）** | 客情维护平台、内容日历 | 私域管家、内容官 | 企微触达、私域标签 |
| **淘宝/天猫** | 公域运营工作台、活动策划 | 导购顾问、活动策划师 | 直通车、万相台、淘客 |
| **京东** | 公域运营工作台、活动策划 | 导购顾问、活动策划师 | 京准通、京东快车 |
| **拼多多** | 公域运营工作台、活动策划 | 导购顾问、活动策划师 | 多多进宝、秒杀资源位 |
| **抖音** | 公域运营工作台、内容日历 | 导购顾问、内容官 | 达人带货、直播排期 |
| **快手** | 公域运营工作台、内容日历 | 导购顾问、内容官 | 磁力金牛、直播切片 |
| **Shopify** | 跨境运营工作台 | 导购顾问、数据参谋 | 多币种、跨境物流 |
| **Amazon** | 跨境运营工作台 | 导购顾问、数据参谋 | FBA、A+页面、Review管理 |

### 2.3 共性工作台类型

虽然各平台业务形态不同，但工作台层可以抽象出 5 种**共性工作台**：

| 共性工作台 | 适用平台 | 核心能力 | 对接数字同事 |
|-----------|---------|---------|-------------|
| **客户关系工作台** | 全平台（私域强/公域弱） | 客户 360、分层、触达管理 | 私域管家、导购顾问 |
| **内容日历工作台** | 抖音/快手/微商城 | 内容排期、多平台发布、素材库 | 内容官 |
| **活动策划工作台** | 淘宝/天猫/京东/拼多多/微商城 | 活动方案、效果预估、复盘 | 活动策划师 |
| **数据参谋驾驶舱** | 全平台 | BI 看板、异常告警、归因分析 | 数据参谋 |
| **订单履约工作台** | 全平台 | 订单处理、物流跟踪、售后管理 | 客服专员 |

### 3.3 技术决策：不走画布编辑

详见 [05-客情维护平台设计方案.md](05-客情维护平台设计方案.md) §1.5。

**结论**：客户关系工作台采用固定三栏布局，不复用 CanvasPage 的拖拽系统，但复用其视觉组件（BpCard、BpTabs、折叠面板等）。

### 3.4 各平台细分差异

| 差异维度 | 私域（微商城） | 公域（淘宝/天猫/京东） | 跨境（Shopify/Amazon） |
|---------|--------------|---------------------|---------------------|
| **客户定义** | 微信好友 + 会员 | 平台会员 + 粉丝 | 邮箱订阅者 + 买家 |
| **触达渠道** | 企微消息、朋友圈、社群 | 平台站内信、短信 | 邮件、WhatsApp、Facebook |
| **标签体系** | 肤质/消费力/互动频次 | 消费层级/品类偏好/RFM | 地域/语言/币种 |
| **分层模型** | 高价值/潜力/沉默/流失 | RFM 模型 + 平台标签 | LTV + 复购周期 |
| **AI 洞察** | 私域管家：搭配推荐、复购提醒 | 导购顾问：优惠推荐、活动通知 | 导购顾问：跨境推荐、尺码建议 |
| **权限门控** | 话术确认（30 字限制） | 优惠券发放（金额上限） | 邮件发送（GDPR 合规） |

**细分差异写入位置**：各平台自有接入方案目录下的 `工作台细分.md`

### 7.2 技术路线：固定布局 + 组件复用

**所有新增工作台均不走画布编辑**，采用固定布局：
- 客户关系工作台：三栏布局（任务列表 / 任务详情 / Artifact）
- 内容日历工作台：日历视图 + 右侧详情
- 活动策划工作台：左侧列表 + 右侧详情
- 数据参谋驾驶舱：网格布局（指标卡 + 图表 + AI 洞察）

**复用 CanvasPage 基础设施**：BpCard、BpTabs、折叠面板、Widget 注册思路。
