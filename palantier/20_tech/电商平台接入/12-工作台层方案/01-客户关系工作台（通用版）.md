## 四、各平台细分差异矩阵

### 4.1 三大类平台差异

| 差异维度 | 私域（微商城） | 公域（淘宝/天猫/京东/拼多多） | 跨境（Shopify/Amazon） |
|---------|-------------|------------------------|---------------------|
| **客户定义** | 企微好友/社群成员 | 平台会员/粉丝 | 邮件订阅者/买家 |
| **触达渠道** | 企微消息+朋友圈+社群 | 平台站内信+短信+客服 | 邮件+WhatsApp+Facebook |
| **标签体系** | 自定义标签 | 平台官方标签+自定义 | 行为标签+购买标签 |
| **分层模型** | RFM + 互动频次 | RFM + 平台活跃度 | RFM + 邮件打开率 |
| **AI 洞察** | 搭配推荐+复购提醒 | 流失预警+优惠券推荐 | 复购预测+弃购挽回 |
| **权限门控** | 话术确认（≤30字） | 优惠券发放（金额上限） | 邮件发送（GDPR合规） |

### 4.2 9 平台具体差异

| 平台 | 客户定义 | 特色触达渠道 | 特色工作台微件 |
|------|---------|------------|-------------|
| 微商城 | 企微好友 | 企微消息+朋友圈 | 客情维护平台（05 已实现） |
| 淘宝 | 淘宝会员 | 站内信+短信+旺旺 | 会员运营工作台+直通车 |
| 天猫 | 天猫会员 | 站内信+短信+客服 | 会员运营工作台+聚划算 |
| 京东 | 京东会员 | 站内信+短信+京麦 | 会员运营工作台+京准通 |
| 拼多多 | 拼单用户 | 站内信+短信 | 拼单用户工作台+多多进宝 |
| 抖音 | 抖音粉丝 | 私信+直播间互动 | 粉丝运营工作台+巨量算数 |
| 快手 | 快手粉丝 | 私信+直播间互动 | 粉丝运营工作台+磁力金牛 |
| Shopify | 邮件订阅者 | Email+SMS+WhatsApp | 邮件营销工作台+Shopify Analytics |
| Amazon | Amazon买家 | Email+Buyer-Seller Messaging | 买家关怀工作台+FBA管理 |

各平台的差异在**各自接入方案目录**下的 `工作台细分.md` 中定义。通用版定义 80% 共性，各平台细化 20% 差异。

## 五、与数字同事的集成

### 5.1 集成路径

```
私域管家/导购顾问（AIP 后端）
    │
    ├─ 创建 Task（通过技能执行）
    │   POST /v1/aip/skills/{skill_name}/execute
    │
    ├─ 工作台前端展示 Task
    │   GET /v1/aip/tasks?agent=private_butler
    │
    ├─ 用户审批 Plan
    │   GET /v1/aip/tasks/{id}/plan/approve
    │
    └─ 用户查看 Artifact
        GET /v1/aip/tasks/{id}/artifacts
```

### 5.2 私域管家技能 → 新建任务下拉

| 私域管家技能 | 新建任务选项 |
|------------|------------|
| S1 客户沉淀 | 客户沉淀（导入企微） |
| S2 客户打标 | 客户打标（批量标签） |
| S3 客户分层 | 客户分层+破冰 |
| S4 跟进排期 | 跟进排期 |
| S5 主动提醒 | 主动提醒 |

### 5.3 导购顾问技能 → 新建任务下拉

| 导购顾问技能 | 新建任务选项 |
|------------|------------|
| S1 成分分析 | 产品成分分析 |
| S2 肤质匹配 | 肤质匹配推荐 |
| S3 产品推荐 | 产品推荐话术生成 |
| S4 搭配建议 | 搭配组合推荐 |
| S5 禁忌检查 | 成分禁忌检查 |
| S6 个性化推荐 | 个性化推荐 |

### 5.4 AI 洞察反哺

AI 洞察面板中的每条洞察可一键生成新任务，形成闭环：
```
AI洞察 → [生成触达任务] → 新 Task 出现在任务列表 → 执行 → 产出新Artifact → 新AI洞察
```

## 六、API 对接

### 6.1 接口清单

| API | 方法 | 用途 |
|-----|------|------|
| `/v1/aip/tasks` | GET | 获取任务列表（按 agent 过滤） |
| `/v1/aip/tasks/{id}` | GET | 获取任务详情 |
| `/v1/aip/tasks/{id}/plan` | GET | 获取 Plan |
| `/v1/aip/tasks/{id}/plan/approve` | POST | 审批 Plan |
| `/v1/aip/tasks/{id}/plan/steps/{n}/skip` | POST | 跳过某步 |
| `/v1/aip/tasks/{id}/artifacts` | GET | 获取 Artifact |
| `/v1/aip/skills/{name}/execute` | POST | 执行技能（新建任务） |
| `/v1/objects/Customer` | GET | 获取客户列表（复用现有 API） |

### 6.2 新建任务流程

```
用户点击 [新建任务▼]
    → 选择技能（如"客户分层+破冰"）
    → POST /v1/aip/skills/customer_onboarding/execute
    → 后端创建 Task + 生成 Plan
    → 返回 task_id
    → 前端自动选中该 Task
    → 展示 Plan Mode 面板
    → 用户 [批准计划]
    → TAOR 循环开始执行
```
