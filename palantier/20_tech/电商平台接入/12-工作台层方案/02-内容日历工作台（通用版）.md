> 状态：**设计方案 v1.0** — 通用层框架 + 核心功能详细设计
> 定位：面向内容官（数字同事）的多平台内容排期与发布管理工作台
> 关联：`00-总览-从OrderManagement到数字同事工作台.md` §四 · `../11-AIP决策引擎升级方案/05-内容官技能编排.md`（已编写）

## 一、定位

内容日历工作台是**通用层**工作台，定义跨平台内容排期的共性框架。各平台细分差异在各自接入方案目录下定义。

| 属性 | 说明 |
|------|------|
| **通用层定义** | 内容排期、素材管理、发布审批、效果追踪 |
| **对接数字同事** | 内容官（Content Officer） |
| **不走画布编辑** | 采用日历视图 + 右侧详情固定布局 |
| **复用组件** | BpCard、BpTabs、ContentCalendarWidget |

## 三、核心功能详细设计

### 3.1 内容排期

#### 3.1.1 视图切换
- **周视图**：7天横向排布，每天一个格子，显示该日所有内容条目
- **月视图**：整月日历，有内容的日期高亮显示，hover 显示简略信息
- **今日按钮**：快速回到今日所在周/月
- **切换动画**：视图切换时采用淡入淡出，300ms

#### 3.1.2 内容条目卡片
- **显示信息**：内容类型图标（直播/短视频/图文/活动）、标题、时间、平台标识
- **状态色带**：
  - 草稿（灰色）→ 待审（黄色）→ 已通过（绿色）→ 已发布（蓝色）→ 已取消（红色）
- **拖拽调整**：支持在同周内拖拽调整日期，跨周拖拽需确认

#### 3.1.3 新建内容入口
- 点击日历空白格 → 弹出新建面板，预填日期
- 点击顶部「新建内容」按钮 → 弹出新建面板，日期为空
- 新建面板字段：内容类型、平台、标题、计划时间、关联活动（可选）

### 3.2 素材管理

#### 3.2.1 素材库结构
```
素材库
├── 视频（按平台分类：抖音/快手/微商城）
├── 图片（按用途分类：封面/正文/头像）
├── 文案（按类型分类：脚本/话术/标题）
└── 模板（AI 生成模板 + 人工上传模板）
```

#### 3.2.2 素材与内容关联
- 一个内容条目可关联多个素材（1 主视频 + N 封面 + 1 文案）
- 素材支持「复用」：同一素材可被多个内容条目引用
- 素材变更时，引用该素材的「草稿」状态内容自动更新；「已通过」状态内容提示确认

#### 3.2.3 素材审批流
- 草稿 → 运营上传/AI 生成 → 提交审核 → 运营负责人审批 → 已通过
- 审批拒绝时需填写原因，退回草稿状态

### 3.3 AI 生成（内容官协作）

#### 3.3.1 脚本生成流程
```
[运营] 选择内容条目 → 点击「生成脚本」
  ↓
[系统] 创建 Task → 调用内容官 Skill
  ↓
[内容官] Plan Mode：
  Step 1: 分析产品信息（从本体层读取 Product OT）
  Step 2: 分析目标人群（从本体层读取 Customer OT）
  Step 3: 生成 3 版脚本（不同风格）
  Step 4: 自检（敏感词/长度/品牌调性）
  ↓
[系统] Diff 视图展示 3 版脚本
  ↓
[运营] 选择一版 → 可编辑 → 确认采用
  ↓
[系统] 脚本写入内容条目 Artifact，状态更新为「草稿」
```

#### 3.3.2 封面图生成
- 输入：产品图 + 文案关键词
- 输出：3 张封面图（不同排版风格）
- 采用 Diff 视图展示，运营选择后可微调（裁剪/加文字/调滤镜）

#### 3.3.3 标题优化
- 输入：原始标题
- 输出：5 个优化标题（含热度预估）
- 热度预估基于历史内容数据训练（同类型内容点击率排序）

### 3.4 发布审批

#### 3.4.1 发布前检查清单
| 检查项 | 自动/人工 | 失败处理 |
|-------|----------|---------|
| 素材完整性 | 自动 | 禁止提交，提示缺失项 |
| 敏感词检测 | 自动 | 高亮敏感词，要求修改 |
| 品牌调性检查 | AI 自动 | 提示风险，人工确认可跳过 |
| 排期冲突检测 | 自动 | 同一平台同一时段冲突时警告 |
| 运营负责人审批 | 人工 | 审批通过才可发布 |

#### 3.4.2 Diff 视图
- 任何由内容官生成的内容（脚本/标题/封面），运营修改后需展示 Diff
- Diff 视图采用左右对比：左侧（AI 生成版）→ 右侧（运营修改版）
- 运营可「一键恢复」到 AI 生成版

### 3.5 效果追踪

#### 3.5.1 数据回传
- 发布后自动创建「效果追踪任务」，定时拉取平台数据
- 回传指标：播放量、点赞、评论、分享、转化率、GMV
- 数据更新频率：发布后 1h/6h/24h/72h/7d 各更新一次

#### 3.5.2 内容 ROI 分析
```
内容 ROI = 内容带来的 GMV / (内容制作成本 + 投放成本)

成本构成：
- 人力成本：运营工时 × 时薪（配置项）
- AI 成本：Token 消耗 × 单价
- 投放成本：Dou+/随心推/朋友圈广告等（从平台 API 读取）
```

#### 3.5.3 内容表现评级
| 评级 | ROI 标准 | 系统动作 |
|-----|---------|---------|
| S | ROI > 5 | 自动提取成功经验 → 写入 Episodic Memory |
| A | ROI 2-5 | 标记为优质内容 → 可作为模板复用 |
| B | ROI 1-2 | 正常记录 |
| C | ROI < 1 | 自动分析原因 → 生成优化建议 |

## 四、数据模型

### 4.1 ContentItem（内容条目）

```typescript
interface ContentItem {
  id: string;                    // UUID
  title: string;                 // 内容标题
  type: ContentType;             // 内容类型
  platform: Platform;            // 目标平台
  status: ContentStatus;         // 状态
  scheduledAt: string;           // 计划发布时间 (ISO 8601)
  publishedAt?: string;          // 实际发布时间

  // 关联
  activityId?: string;           // 关联活动 ID
  productIds: string[];          // 关联产品 IDs
  materialIds: string[];         // 关联素材 IDs

  // AI 产出
  script?: string;               // 脚本/文案内容
  titleOptions?: string[];       // AI 生成的标题选项
  selectedTitleIndex?: number;   // 运营选择的标题索引

  // 效果数据（发布后填充）
  metrics?: ContentMetrics;

  // 元数据
  createdAt: string;
  updatedAt: string;
  createdBy: string;             // 运营者 ID
  approvedBy?: string;           // 审批者 ID
}

type ContentType = 'live' | 'short_video' | 'image_text' | 'activity';
type Platform = 'douyin' | 'kuaishou' | 'wechat_moments' | 'wechat_group';
type ContentStatus = 'draft' | 'pending_review' | 'approved' | 'published' | 'cancelled';

interface ContentMetrics {
  views: number;
  likes: number;
  comments: number;
  shares: number;
  conversions: number;
  gmv: number;
  roi: number;
  updatedAt: string;
}
```

### 4.2 Material（素材）

```typescript
interface Material {
  id: string;
  name: string;
  type: MaterialType;            // video | image | text | template
  platform: Platform[];          // 适用平台（可多选）
  url: string;                   // 存储地址（OSS URL）
  thumbnailUrl?: string;         // 缩略图
  size: number;                  // 文件大小（bytes）
  duration?: number;             // 视频时长（秒）

  // 使用统计
  usageCount: number;            // 被引用次数
  lastUsedAt?: string;

  // 审批
  status: MaterialStatus;
  reviewedBy?: string;
  reviewNote?: string;

  createdAt: string;
  createdBy: string;
}

type MaterialType = 'video' | 'image' | 'text' | 'template';
type MaterialStatus = 'draft' | 'pending_review' | 'approved' | 'rejected';
```

### 4.3 ContentTask（内容生成任务）

```typescript
interface ContentTask {
  id: string;
  contentItemId: string;         // 关联内容条目
  type: 'script_generation' | 'cover_generation' | 'title_optimization';

  // TAOR 循环状态
  status: TaskStatus;
  plan?: ExecutionPlan;          // Plan Mode 方案
  steps: TaskStep[];             // 执行步骤
  artifacts: Artifact[];         // 产出物

  // 结果
  result?: {
    options: any[];              // 多选项（如 3 版脚本）
    selectedIndex?: number;      // 运营选择的索引
  };

  createdAt: string;
  completedAt?: string;
}
```

### 6.2 Permission Gate 设计

| 动作 | 风险等级 | 门控策略 |
|-----|---------|---------|
| 生成脚本 | 低 | 自动执行，无需确认 |
| 修改已通过脚本 | 中 | Diff 视图展示变更，确认后执行 |
| 发布内容 | 高 | 必须运营负责人审批 |
| 删除已发布内容 | 高 | 二次确认 + 记录原因 |
| 批量排期（>10条） | 中 | 确认总览后执行 |

## 九、各平台细分差异

| 差异维度 | 抖音/快手 | 微商城 |
|---------|----------|--------|
| **内容形态** | 短视频、直播 | 朋友圈图文、社群图文 |

| **效果指标** | 播放量、点赞、带货转化 | 阅读、点赞、评论、转化 |
