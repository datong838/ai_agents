## 一、定位

订单管理操作台是 5 类共性工作台之一，对接**客服专员**数字同事。核心场景：订单查询、售后处理（退款/退货/换货）、物流跟踪、客诉处理。

```
订单管理操作台（通用版，本文档）
    │
    ├─ 微商城 → 订单管理（微商城实例）
    ├─ 淘宝/天猫 → 淘宝订单 + 天猫订单
    ├─ 京东 → 京东订单
    ├─ 拼多多 → 拼多多订单
    ├─ 抖音 → 抖音小店订单
    ├─ 快手 → 快手小店订单
    ├─ Shopify → Shopify订单
    └─ Amazon → FBA订单
```

**对接数字同事**：客服专员

## 四、客服专员技能集成

### 4.1 技能 → 处理类型映射

| 客服专员技能 | 新建处理选项 | 门控级别 |
|------------|------------|---------|
| S1 订单查询 | 订单搜索 | 无门控 |
| S2 售后处理 | 退款/退货/换货 | 金额门控 |
| S3 客诉处理 | 客诉处理 | 需审批 |
| S4 安抚话术 | 话术生成 | 无门控 |
| S5 跟进排期 | 自动跟进 | 无门控 |
| S6 评价管理 | 评价回复 | 无门控 |

### 4.2 自动化处理流程

```
客户发起退款
    │
    ├─ 客服专员自动分析（TAOR Think）
    │   ├─ 查询订单信息
    │   ├─ 查询客户历史退款率
    │   ├─ 检索售后政策（Semantic）
    │   └─ 生成处理建议
    │
    ├─ 风控评估（TAOR Act）
    │   ├─ 退款率 < 10% → 低风险 → 可自动处理
    │   ├─ 退款率 10-20% → 中风险 → 需主管确认
    │   └─ 退款率 > 20% → 高风险 → 需主管+财务双审
    │
    ├─ Verification Loop（TAOR Verify）
    │   ├─ 退款金额 ≤ 订单总额 ✅
    │   ├─ 退款原因在允许列表内 ✅
    │   └─ 金额超阈值 → 需审批 ⚠
    │
    └─ 处理执行（TAOR Observe）
        ├─ 记录 Episodic Memory
        └─ 生成跟进话术
```

## 五、各平台差异

### 5.1 订单管理 9 平台差异

| 平台 | 订单来源 | 特色售后流程 | 特色 API |
|------|---------|------------|---------|
| 微商城 | 自有商城 | 7天无理由 + 过敏全额退 | Trade API |
| 淘宝 | 淘宝订单 | 淘宝退款流程 + 运费险 | 淘宝开放平台 |
| 天猫 | 天猫订单 | 天猫退款 + 极速退款 | 天猫开放平台 |
| 京东 | 京东订单 | 京东售后 + 上门取件 | 京东开放平台 |
| 拼多多 | 拼多多订单 | 拼多多退款 + 仅退款 | 拼多多开放平台 |
| 抖音 | 抖音小店订单 | 抖音售后 + 直播专属退 | 抖音电商开放平台 |
| 快手 | 快手小店订单 | 快手售后 + 直播专属退 | 快手电商开放平台 |
| Shopify | Shopify订单 | Shopify退款 + RMA | Shopify Admin API |
| Amazon | FBA订单 | Amazon A-to-Z 保障 + FBA退货 | Amazon SP-API |

### 5.2 权限门控差异

| 平台 | 特殊门控 |
|------|---------|
| 通用 | 退款金额阈值审批 |
| Amazon | A-to-Z 索赔需主管审批 |
| Shopify | 跨境退款需汇率确认 |
| 抖音/快手 | 直播订单退款需主播确认 |
