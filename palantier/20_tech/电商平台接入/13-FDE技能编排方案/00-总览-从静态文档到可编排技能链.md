## 一、问题诊断

### 1.1 当前 FDE 流程的静态性

`../电商领域数字同事初探.md` §九 定义了 6 步 FDE 数据接入流程：

```
Step 1 对话理解 → Step 2 认证配置 → Step 3 API 探索 →
Step 4 字段映射 → Step 5 同步配置 → Step 6 测试验证
```

**问题**：这是静态文档描述，不是可编排的技能链：
1. 无法自动执行 — 需要 FDE 工程师手动按步骤操作
2. 无 Plan Mode — 没有"先出方案再确认"环节
3. 无 Checkpoint — 中途断了无法恢复
4. 无 Self-correction — 映射失败不会自动调整
5. 无记忆复用 — 换个平台要重新来一遍

### 1.2 目标：将 6 步静态流程升级为可编排技能链

| 维度 | 当前（静态文档） | 升级后（技能链） |
|------|---------------|----------------|
| 执行方式 | 人工按步骤操作 | TAOR 循环自动执行 |
| 方案确认 | 无 | Plan Mode 生成方案 → 用户确认 |
| 失败恢复 | 从头开始 | Checkpoint 回滚到失败步 |
| 经验积累 | 无 | Episodic Memory 记录映射经验 |
| 跨平台复用 | 每个平台重新写 | 80% 技能通用 + 20% 平台适配 |


### 2.2 每个技能的 TAOR 循环

每个技能都遵循 Think → Act → Reflect → Observe 循环：

| 技能 | Think（理解） | Act（执行） | Reflect（自审） | Observe（观察） |
|------|-------------|-----------|---------------|---------------|
| 1.对话理解 | 分析用户意图 | 调用 LLM 提取参数 | 检查必填参数 | 存入 Working Memory |
| 2.认证配置 | 选择认证方式 | 配置 OAuth/签名 | 测试连通性 | 记录 Token 状态 |
| 3.API探索 | 拉取 API Schema | LLM 理解接口 | 检查必填接口 | 存入 Episodic Memory |
| 4.字段映射 | 生成映射建议 | 执行 OKF 映射 | 检查覆盖率 | 记录映射经验 |
| 5.同步配置 | 选择同步策略 | 配置 Pipeline | 验证配置 | 记录配置模板 |
| 6.测试验证 | 拉取测试数据 | 执行端到端验证 | 检查数据质量 | 记录验证结果 |

## 五、记忆与经验复用

### 5.1 跨平台映射经验复用

```
平台A接入完成 → 记录映射经验到 Episodic Memory
    ↓
平台B接入时 → 从 Episodic Memory 检索相似经验
    ↓
映射置信度提升 20-30%（Self-correction Loop）
```

### 5.2 记忆存储设计

| 记忆层 | 存储内容 | 检索方式 | 跨平台复用 |
|--------|---------|---------|-----------|
| Semantic | 平台API文档、字段规范 | RAG 语义搜索 | ✅ 跨平台 |
| Episodic | 历史接入会话、映射经验 | 时间索引 + 平台标签 | ✅ 同类平台 |
| Working | 当前接入任务的上下文 | 指针引用 | ❌ 单任务 |

## 六、Checkpoint 与回滚

### 6.1 检查点策略

每个技能完成后保存 Checkpoint：

```
技能1完成 → CP1（对话理解结果）
技能2完成 → CP2（认证配置）
技能3完成 → CP3（API Schema）
技能4完成 → CP4（字段映射方案）
技能5完成 → CP5（同步配置）
技能6完成 → CP6（测试验证报告）
```

### 6.2 回滚场景

| 场景 | 回滚到 | 操作 |
|------|--------|------|
| 字段映射覆盖率不足 | CP3 | 重新探索API，补充字段 |
| 同步配置失败 | CP4 | 重新生成映射方案 |
| 测试验证数据质量差 | CP5 | 调整同步策略 |
| 认证Token过期 | CP2 | 重新配置认证 |

## 八、验收标准

- [ ] 输入"接入淘宝天猫"+ 参数 → Plan Mode 生成6步执行计划
- [ ] 用户确认后 → TAOR 循环自动执行6个技能
- [ ] 每步保存 Checkpoint，支持回滚
- [ ] 字段映射置信度 < 0.7 时标记"待确认"并暂停
- [ ] 认证配置需人工确认（权限防线 Layer 6）
- [ ] 接入完成后生成验证报告
- [ ] 换平台时从 Episodic Memory 检索映射经验
