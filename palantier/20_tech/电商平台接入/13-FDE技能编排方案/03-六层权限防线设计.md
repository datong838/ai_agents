## 一、设计原则

### 1.1 复用而非重复

AIP 层已定义完整的六层权限防线（详见 `../11-AIP决策引擎升级方案/03-六层权限防线设计.md`）：

```
Layer 1: 白名单
Layer 2: 自动模式分类器
Layer 3: 协调者门控
Layer 4: 安全分类器
Layer 5: Guardrail 运行时拦截
Layer 6: 交互式用户确认
```

FDE **不重新实现**这些防线，而是：
1. 在 AIP 层注册 FDE 专属的白名单规则
2. 注册 FDE Action Type 的风险矩阵
3. 为 FDE Action 配置 Guardrail 规则

### 1.2 FDE 特有的权限关注点

| 关注点 | 涉及技能 | 风险 |
|-------|---------|------|
| API credentials 泄露 | 技能2 认证配置 | 高 — 包含 app_secret 等敏感信息 |
| 平台 API 调用频率超限 | 技能3 API 探索 | 中 — 可能触发风控 |
| 字段映射错误导致数据污染 | 技能4 字段映射 | 高 — 影响 Ontology 数据质量 |
| Pipeline 配置错误导致数据丢失 | 技能5 同步配置 | 高 — 影响生产数据 |
| 同步任务误删已有数据 | 技能5/6 | 严重 — 不可恢复 |

### 2.2 风险等级判定规则

```python
def evaluate_fde_risk(action_type: str, params: dict, context: dict) -> str:
    """评估 FDE Action 的风险等级。"""
    base_risk = FDE_ACTION_RISK_MATRIX.get(action_type, {}).get("risk_level", "medium")

    # 动态升级规则
    if action_type == "ConfigureAuth":
        # 生产环境 + credentials → 升级为 critical
        if context.get("environment") == "production":
            return "critical"

    if action_type == "RunFirstSync":
        # 首次同步 + 数据量大 → 升级为 critical
        if params.get("estimated_records", 0) > 1_000_000:
            return "critical"

    if action_type == "MaterializeOntology":
        # 物化 + Ontology 已有数据 → 升级为 critical
        if context.get("ontology_has_existing_data"):
            return "critical"

    return base_risk
```

### 3.2 白名单边界（极简原则）

参考 Claude Blog 的"判断力 > 规则"原则，FDE 白名单只配核心规则：

```python
# 不做：穷举所有可能的白名单规则（过度约束）
# BAD:
# FDE_WHITELIST_RULES = [
#     {"action_type": "RunTestData", "object_type": "orders", ...},
#     {"action_type": "RunTestData", "object_type": "products", ...},
#     {"action_type": "RunTestData", "object_type": "customers", ...},
#     # ... 几十条
# ]

# 做：少量核心规则 + 判断边界
# GOOD: 只配 4 条核心白名单（见上），其余交给分类器判断
```

### 5.3 credentials 脱敏策略

```python
class CredentialsRedactor:
    """credentials 字段脱敏。"""

    SENSITIVE_FIELDS = [
        "app_secret", "client_secret", "api_secret",
        "password", "access_key", "secret_key",
        "token", "refresh_token",
    ]

    @classmethod
    def redact(cls, credentials: dict) -> dict:
        """脱敏 credentials，仅保留前4位 + ***。"""
        redacted = {}
        for key, value in credentials.items():
            if key in cls.SENSITIVE_FIELDS and isinstance(value, str):
                redacted[key] = f"{value[:4]}***" if len(value) > 4 else "***"
            else:
                redacted[key] = value
        return redacted


# 示例
redacted = CredentialsRedactor.redact({
    "app_key": "12345678",
    "app_secret": "abcdef1234567890",
})
# → {"app_key": "12345678", "app_secret": "abcd***"}
```

## 七、FDE 用户确认场景（Layer 6）

### 7.1 必须人工确认的场景

| 场景 | 触发条件 | Diff 视图内容 |
|------|---------|-------------|
| 配置认证 | ConfigureAuth + 非开发环境 | credentials 脱敏后的配置 |
| 首次同步 | RunFirstSync | 同步策略 + 预估数据量 |
| 物化 Ontology | MaterializeOntology + OT 已有数据 | 受影响的 OT 列表 + 数据量对比 |
| 删除 Pipeline | DeletePipeline | 待删除的 Pipeline 配置 |
| 删除映射规则 | DeleteMappingRules | 待删除的规则列表 |
| 字段映射低置信度 | RunFieldMapping + confidence < 0.7 | 待确认的映射规则 Diff |
| 回滚操作 | rollback to CPx | 待清理的资源列表 |

### 7.2 Diff 视图渲染

```python
# aip_fde_diff_renderer.py（新增模块）

class FDEDiffRenderer:
    """FDE 专属 Diff 视图渲染器。"""

    def render_auth_diff(self, action: ActionRequest) -> str:
        """渲染认证配置 Diff。"""
        credentials = action.params.get("credentials", {})
        redacted = CredentialsRedactor.redact(credentials)

        return f"""
## 认证配置变更

| 字段 | 旧值 | 新值 |
|------|------|------|
| platform | - | {action.params['platform']} |
| auth_type | - | {action.params['auth_type']} |
| app_key | - | {redacted.get('app_key', '-')} |
| app_secret | - | {redacted.get('app_secret', '-')} |

**风险等级**：高
**原因**：配置生产环境认证，涉及敏感信息
**操作**：将写入加密存储，不可回滚（仅可标记失效）

请确认以上配置是否正确。
"""

    def render_mapping_diff(self, action: ActionRequest, old_rules: list) -> str:
        """渲染字段映射 Diff。"""
        new_rules = action.params.get("mapping_rules", [])

        diff_lines = ["## 字段映射变更\n"]
        for new_rule in new_rules:
            old = next((r for r in old_rules if r["source"] == new_rule["source"]), None)
            if old:
                if old["target"] != new_rule["target"]:
                    diff_lines.append(f"- {new_rule['source']}: {old['target']} → {new_rule['target']}")
                if old.get("transform") != new_rule.get("transform"):
                    diff_lines.append(f"- {new_rule['source']}.transform: {old.get('transform', '-')} → {new_rule.get('transform', '-')}")
            else:
                diff_lines.append(f"+ {new_rule['source']} → {new_rule['target']} (新增)")

        diff_lines.append(f"\n**覆盖率**：{action.params.get('coverage', 0):.2%}")
        diff_lines.append(f"**平均置信度**：{action.params.get('avg_confidence', 0):.2%}")

        if action.params.get("avg_confidence", 1) < 0.7:
            diff_lines.append("\n⚠️ **置信度低于阈值，请重点审查以下规则**：")
            for rule in action.params.get("pending_review", []):
                diff_lines.append(f"  - {rule['source']} → {rule['target']} (置信度 {rule['confidence']:.2f})")

        return "\n".join(diff_lines)
```

            context={"environment": "dev", "project_id": "dev-org"}
        )

        result = await permission_gate.check(action, task=mock_task)

        assert result.allowed == True
        assert result.layer == "whitelist"

    async def test_sql_injection_in_mapping_blocked(self, permission_gate):
        """字段映射中的 SQL 注入被阻断。"""
        action = ActionRequest(
            action_type="RunFieldMapping",
            params={
                "mapping_rules": [
                    {"source": "tid", "target": "order_id; DROP TABLE orders", "transform": "string"}
                ]
            }
        )

        result = await permission_gate.check(action, task=mock_task)

        assert result.allowed == False
        assert result.layer == "security_scanner"
        assert "SQL 注入" in result.reason
