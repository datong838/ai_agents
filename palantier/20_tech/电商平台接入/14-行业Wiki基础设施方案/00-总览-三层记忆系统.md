## 一、当前状态

### 1.1 现有 Wiki 能力

系统已有 `ontology_wiki_engine.py`，支持：
- Wiki 与 Ontology 对象双向绑定
- Wiki 编辑 → Draft → 审批 → 写回
- Wiki 版本管理 + 分支 diff/merge

**但缺少**：
1. **RAG 检索能力** — Wiki 只能按 ID 查，不能语义搜索
2. **Episodic 记忆** — 无历史会话存储和检索
3. **Working 记忆管理** — 无上下文压缩和指针策略
4. **七条知识管道** — 无自学习/网络爬取/竞品分析等管道
5. **知识治理** — 无可信度分级和写入门控

### 1.2 目标

将现有 Wiki 从"静态文档库"升级为"三层记忆系统"：

| 层级 | 当前 | 升级后 |
|------|------|--------|
| Semantic（长期语义） | Wiki CRUD only | + RAG 检索 + 向量索引 |
| Episodic（情景记忆） | 无 | + 会话历史 + 时间索引 |
| Working（工作记忆） | 无 | + 上下文压缩 + 指针策略 |

## 二、三层记忆架构

```
┌─────────────────────────────────────────────────────────────┐
│                    三层记忆系统                                │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Semantic Layer（长期语义记忆）                       │   │
│  │  存储：行业知识、平台规则、话术模板、成分库             │   │
│  │  检索：RAG 语义搜索 + 向量索引                         │   │
│  │  来源：七条知识管道                                    │   │
│  │  治理：可信度分级 + 写入门控 + 时效管理                 │   │
│  │  实现：PostgreSQL (结构化) + Milvus/Qdrant (向量)      │   │
│  └──────────────────────┬──────────────────────────────┘   │
│                         │                                   │
│  ┌──────────────────────▼──────────────────────────────┐   │
│  │  Episodic Layer（情景记忆）                           │   │
│  │  存储：历史会话、执行记录、映射经验、成功/失败案例       │   │
│  │  检索：时间索引 + 平台标签 + 任务类型                   │   │
│  │  特点：会过期（TTL 90天），重要经验自动提升到 Semantic   │   │
│  │  实现：Redis (热数据) + PostgreSQL (冷数据)            │   │
│  └──────────────────────┬──────────────────────────────┘   │
│                         │                                   │
│  ┌──────────────────────▼──────────────────────────────┐   │
│  │  Working Layer（工作记忆）                             │   │
│  │  存储：当前任务上下文、中间变量、执行状态                 │   │

│  │  实现：内存（快速访问）+ Redis（持久化检查点）            │   │
│  └─────────────────────────────────────────────────────┘   │
```

```python
class KnowledgeEntry(BaseModel):
    """Semantic 层知识条目。"""
    id: str = Field(default_factory=lambda: "wiki-" + uuid.uuid4().hex[:8])
    title: str
    content: str  # 知识正文
    category: str  # platform_rule | ingredient | script_template | industry_trend | competitor | customer_behavior
    tags: list[str] = []

    # 可信度分级
    confidence_level: str = "L3"  # L1权威 | L2专业 | L3经验 | L4推测
    source: str = ""  # 知识来源管道
    source_url: str = ""

    # 时效性
    effective_from: float = Field(default_factory=lambda: time.time())
    effective_until: float | None = None  # None = 长期有效
    review_cycle_days: int = 30  # 复查周期

    # 向量
    embedding: list[float] = []  # 向量嵌入
    embedding_model: str = ""

    # 版本
    version: int = 1
    created_by: str = ""
    created_at: float = Field(default_factory=lambda: time.time())
    updated_at: float = Field(default_factory=lambda: time.time())
```

### 3.2 RAG 检索

```python
class SemanticMemory:
    """Semantic 层：RAG 检索 + 向量索引。"""

    def __init__(self, vector_store: VectorStore, db_store: DbStore):
        self._vector = vector_store  # Milvus / Qdrant
        self._db = db_store  # PostgreSQL

    async def store(self, entry: KnowledgeEntry) -> str:
        """存储知识条目。"""
        # 1. 生成向量嵌入
        embedding = await self._embed(entry.title + " " + entry.content)
        entry.embedding = embedding

        # 2. 写入结构化存储
        await self._db.insert(entry)

        # 3. 写入向量索引
        await self._vector.upsert(entry.id, embedding, {
            "category": entry.category,
            "confidence_level": entry.confidence_level,
            "tags": entry.tags
        })

        return entry.id

    async def retrieve(self, query: str, top_k: int = 5, filters: dict = None) -> list[KnowledgeEntry]:
        """RAG 语义检索。"""
        # 1. 生成查询向量
        query_embedding = await self._embed(query)

        # 2. 向量搜索
        results = await self._vector.search(
            query_embedding,
            top_k=top_k,
            filters=filters  # 如 {"category": "ingredient"}
        )

        # 3. 加载完整知识条目
        entries = []
        for hit in results:
            entry = await self._db.get(hit.id)
            if entry and self._is_valid(entry):  # 检查时效性
                entry.relevance_score = hit.score
                entries.append(entry)

        return entries

    def _is_valid(self, entry: KnowledgeEntry) -> bool:
        """检查知识是否在有效期内。"""
        now = time.time()
        if entry.effective_until and now > entry.effective_until:
            return False
        return True
```

### 3.4 知识治理 — 三层过滤

```python
class KnowledgeGovernance:
    """知识治理：可信度分级 + 写入门控 + 时效管理。"""

    # 第一层：可信度分级
    CONFIDENCE_LEVELS = {
        "L1": {"name": "权威", "sources": ["官方文档", "法规", "API规范"], "auto_use": True},
        "L2": {"name": "专业", "sources": ["第三方数据库", "行业报告"], "auto_use": True, "cite_source": True},
        "L3": {"name": "经验", "sources": ["自学习", "运营复盘"], "auto_use": False, "need_confidence": True},
        "L4": {"name": "推测", "sources": ["网络爬取碎片"], "auto_use": False, "need_verification": True},
    }

    # 第二层：写入门控
    WRITE_GATES = {
        "L1": "no_gate",          # 无门控，自动入库
        "L2": "no_gate",          # 无门控，自动入库
        "L3": "review_required",  # 写入草稿区，人工审核后转正
        "L4": "review_required",  # 写入草稿区，人工审核后转正
    }

    async def write(self, entry: KnowledgeEntry) -> WriteResult:
        """带门控的写入。"""
        gate = self.WRITE_GATES.get(entry.confidence_level, "review_required")

        if gate == "no_gate":
            # 直接写入 Semantic 层
            entry_id = await self._semantic.store(entry)
            return WriteResult(status="stored", entry_id=entry_id)
        else:
            # 写入草稿区，等待审核
            entry_id = await self._draft_store.store(entry)
            return WriteResult(status="pending_review", entry_id=entry_id)

    # 第三层：时效管理
    async def check_expiry(self) -> int:
        """检查过期知识。"""
        expired = await self._semantic.find_expired()
        for entry in expired:
            entry.effective_until = time.time()
            await self._semantic.update(entry)
        return len(expired)
```

## 四、Episodic Layer 详细设计

```python
class EpisodicMemory:
    """Episodic 层：情景记忆 — 历史会话和执行记录。"""

    async def store(self, episode: Episode) -> str:
        """存储一个情景记忆（一次任务执行、一次客户互动等）。"""
        episode.id = "epi-" + uuid.uuid4().hex[:8]
        episode.created_at = time.time()

        # 存入 Redis（热数据，90天TTL）
        await self._redis.setex(
            f"episodic:{episode.id}",
            90 * 24 * 3600,  # 90天TTL
            episode.model_dump_json()
        )

        # 重要经验同步到 PostgreSQL（冷数据，永久保存）
        if episode.importance >= 0.7:
            await self._pg.insert(episode)

        return episode.id

    async def retrieve(self, query: str, top_k: int = 3) -> list[Episode]:
        """检索相似的历史情景。"""
        # 按时间索引 + 平台标签 + 任务类型检索
        results = await self._redis.search(
            f"episodic:*",
            filters={"task_type": query.get("task_type"), "platform": query.get("platform")},
            limit=top_k
        )
        return [Episode(**r) for r in results]


class Episode(BaseModel):
    """情景记忆条目。"""
    id: str = ""
    task_type: str  # data_ingestion | customer_outreach | content_generation
    platform: str = ""  # taobao | niushop | douyin ...
    summary: str  # 情景摘要
    success: bool  # 是否成功
    duration_seconds: int  # 耗时
    tokens_used: int  # token消耗
    key_decisions: list[str] = []  # 关键决策
    lessons_learned: str = ""  # 经验教训
    importance: float = 0.5  # 重要性（0-1，决定是否永久保存）
    created_at: float = 0
```

## 五、Working Layer 详细设计

```python
class WorkingMemory:
    """Working 层：当前任务的工作记忆。

    参考 Claude Code 的指针策略：
    超出 token 限制时用指针代替内容。
    """

    MAX_CONTEXT_TOKENS = 8000  # 上下文 token 上限

    def __init__(self):
        self._context: dict[str, Any] = {}
        self._pointers: dict[str, str] = {}  # key → 外部引用ID
        self._token_count = 0

    def set(self, key: str, value: Any) -> None:
        """设置上下文变量。"""
        token_estimate = self._estimate_tokens(value)

        # 如果加入后超限，用指针代替
        if self._token_count + token_estimate > self.MAX_CONTEXT_TOKENS:
            # 存到外部，只保留指针
            ref_id = self._store_external(key, value)
            self._pointers[key] = ref_id
            self._context[key] = f"[POINTER: {ref_id}]"  # 指针代替内容
        else:
            self._context[key] = value
            self._token_count += token_estimate

    def get(self, key: str) -> Any:
        """获取上下文变量。如果是指针，按需加载。"""
        value = self._context.get(key)
        if isinstance(value, str) and value.startswith("[POINTER:"):
            # 指针引用 — 按需加载
            ref_id = value.replace("[POINTER: ", "").replace("]", "")
            return self._load_external(ref_id)
        return value

    def compress(self) -> None:
        """上下文压缩 — 参考 Claude Code 八段式压缩算法。"""
        # 1. 保留最近3步的完整上下文
        # 2. 较早的步骤压缩为摘要
        # 3. 更早的转为指针
        pass

    def promote_to_episodic(self) -> str:
        """任务结束后，将重要内容提升到 Episodic 层。"""
        important = {
            k: v for k, v in self._context.items()
            if k.startswith("step_") and "reflection" in k
        }
        if important:
            episode = Episode(
                task_type=self._context.get("task_type", "unknown"),
                summary=self._context.get("task_summary", ""),
                success=self._context.get("task_success", False),
                key_decisions=[k for k in important.keys()],
            )
            return self._episodic.store(episode)
        return ""
```

## 六、记忆系统在 TAOR 循环中的使用

```python
# 在 TAORLoopController 中集成三层记忆

class TAORLoopController:
    def __init__(self, memory: MemorySystem):
        self._memory = memory  # 三层记忆统一接口

    async def _think(self, task: Task, step: TaskStep) -> ThinkResult:
        # 从 Semantic 层检索行业知识
        semantic_hits = await self._memory.semantic.retrieve(
            query=f"task_type={task.type} step={step.action_type}",
            top_k=3
        )

        # 从 Episodic 层检索历史经验
        episodic_hits = await self._memory.episodic.retrieve(
            query={"task_type": task.type, "platform": task.context.get("platform")},
            top_k=2
        )

        # 从 Working 层获取当前上下文
        working_context = self._memory.working.get_all()

        # 构造 Think Prompt（包含三层记忆内容）
        prompt = self._build_think_prompt(
            task, step, semantic_hits, episodic_hits, working_context
        )

        # 执行结果存入 Working Memory
        self._memory.working.set(f"step_{step.id}_think", think_result)

    async def _observe(self, task: Task, step: TaskStep, act_result: ActResult):
        # 执行结果存入 Working Memory
        self._memory.working.set(f"step_{step.id}_output", act_result.output)

        # 如果上下文超限，自动压缩
        if self._memory.working.is_over_limit():
            self._memory.working.compress()

    async def _on_task_complete(self, task: Task):
        # 重要经验从 Working → Episodic
        await self._memory.working.promote_to_episodic()

        # 成功经验从 Episodic → Semantic（管道2：自学习）
        if task.success:
            await self._memory.pipeline.pipe2_self_learning(task.result)
```

## 九、Progressive Disclosure — 渐进式披露策略

> **来源**：Claude Blog — [The new rules of context engineering for Claude 5 generation models](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)
> **更新时间**：2026-07-28

### 9.1 核心原则

Claude 5 代模型发布后，Anthropic 发现**按需加载上下文**比一次性塞满效果更好：

> "Claude Code now has very competent at using progressive disclosure — loading the right context at the right times."

**六条新旧规则对照**：

| 旧规则 | 新规则 | 对三层记忆的影响 |
|--------|--------|----------------|
| 给 Claude 规则 | 让 Claude 用判断力 | Semantic 层知识不要给硬规则，给"判断边界" |
| 给 Claude 示例 | 设计接口 | 工具参数设计（propsSchema）比示例重要 |
| 全部放前面 | 渐进式披露 | Working 层只加载当前步骤需要的记忆 |
| 重复强调 | 工具描述写清楚 | 不要在 Prompt 里反复提工具 |
| 记忆存 CLAUDE.md | 自动记忆 | Episodic 层自动判断什么值得存 |
| 简单规格 | 丰富引用 | 用 Diff/Artifact 代替纯 Markdown |

### 9.2 三层记忆的渐进式加载

```python
# aip_memory.py — 渐进式披露策略

class MemorySystem:
    """三层记忆系统 — 渐进式披露实现。"""

    async def load_for_step(self, task: Task, step: TaskStep) -> dict:
        """按当前步骤的需要，渐进式加载记忆。

        策略：
        1. Working 层：始终加载（当前任务上下文）
        2. Semantic 层：按步骤类型按需检索（不预加载）
        3. Episodic 层：按相似度按需检索（不预加载）
        """
        context = {}

        # ── 始终加载 Working Memory（当前任务上下文，已压缩）──
        context["working"] = self._working.get_all()

        # ── 按步骤类型决定是否加载 Semantic ──
        if step.action_type in ("llm_call", "branch"):
            # LLM 调用需要行业知识
            context["semantic"] = await self._semantic.retrieve(
                query=f"{task.type} + {step.action_type}",
                top_k=3  # 只加载最相关的3条，不贪多
            )
        # ontology_query / tool_call 不需要加载 Semantic

        # ── 按步骤类型决定是否加载 Episodic ──
        if step.action_type in ("llm_call", "action_writeback"):
            # LLM 调用和写回操作需要历史经验
            context["episodic"] = await self._episodic.retrieve(
                query={"task_type": task.type, "platform": task.context.get("platform")},
                top_k=2  # 只加载最相关的2条
            )

        return context
```

### 9.3 自动记忆机制

参考 Claude Code 的自动记忆：

> "Claude now automatically saves memories that are relevant to the work and to you."

```python
class AutoMemory:
    """自动记忆 — 系统自动判断什么值得存。

    参考 Claude Code 的 auto-memory 机制：
    不需要用户主动 # 存记忆，系统自动判断并存储。
    """

    async def auto_save(self, task: Task, step_result: ActResult):
        """任务执行后自动判断是否值得存记忆。"""

        # 判断标准1：任务成功 + 有可复用经验
        if task.success and step_result.reusability_score > 0.7:
            await self._episodic.store(Episode(
                task_type=task.type,
                summary=step_result.summary,
                success=True,
                importance=step_result.reusability_score
            ))

        # 判断标准2：任务失败 + 有教训
        if not task.success and step_result.has_lesson:
            await self._episodic.store(Episode(
                task_type=task.type,
                summary=step_result.summary,
                success=False,
                lessons_learned=step_result.lesson,
                importance=0.8  # 失败教训优先级高
            ))

        # 判断标准3：高频模式 → 提升到 Semantic
        patterns = await self._detect_patterns(task.type)
        for pattern in patterns:
            if pattern.frequency > 5:  # 出现5次以上的模式
                await self._semantic.store(KnowledgeEntry(
                    title=f"模式: {pattern.name}",
                    content=pattern.description,
                    confidence_level="L3",
                    source="auto_pattern_detection"
                ))
```

### 9.4 System Prompt 极简原则

Anthropic 删掉了 80% 的 Claude Code 系统提示词：

> "We removed over 80% of Claude Code's system prompt for more advanced models with no measurable loss on our coding evaluations."

**对三层记忆的修正**：

| 原设计 | 修正后 |
|--------|--------|
| Semantic 层存大量规则 | 只存"判断边界" + 行业知识，不存硬规则 |
| Working 层加载全量上下文 | 按步骤类型渐进式加载（§9.2） |
| Episodic 层被动检索 | 主动检测模式 + 自动提升到 Semantic |
| 用户手动存记忆 | 系统自动判断什么值得存（§9.3） |
