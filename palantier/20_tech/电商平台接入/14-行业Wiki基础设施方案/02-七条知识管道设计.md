## 一、管道全景

### 1.1 七条管道总览

| 管道 | 名称 | 触发时机 | 数据流向 | 可信度 | 优先级 |
|------|------|---------|---------|--------|--------|
| 管道1 | 种子知识导入 | 冷启动手动 | 文档 → Semantic | L1 | P0 |
| 管道2 | 运营实践自学习 | 每次任务结束自动 | TaskResult → Semantic | L3 | P2 |
| 管道3 | 网络学习 | 定时（每日） | 网页 → Semantic | L4 | P2 |
| 管道4 | 竞品分析 | 定时（每周） | 竞品数据 → Semantic | L4 | P3 |
| 管道5 | 专业知识库 | 定时（每周） | CosDNA/NMPA → Semantic | L2 | P0 |
| 管道6 | 客户数据反哺 | 事件驱动（订单/评价） | 客户行为 → Semantic | L3 | P1 |
| 管道7 | 人工经验注入 | 手动 | 运营经验 → Semantic | L2 | P0 |

### 1.2 管道与三层记忆的数据流

```
┌─────────────────────────────────────────────────────────────┐
│                    Semantic Layer（长期）                     │
│   ← 管道1 种子     ← 管道2 自学习   ← 管道3 网络              │
│   ← 管道4 竞品     ← 管道5 专业库  ← 管道6 客户反哺           │
│   ← 管道7 人工                                                    │
│                                  ▲                              │
│                  03-治理写入门控（L3/L4 需审核）                │
│                                  ▲                              │
│   管道2 ← TAOR on_task_complete                                 │
│   管道6 ← 订单/评价事件                                           │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 与 01 文档的契约

所有管道写入 Semantic 层**统一走 `SemanticLayer.store()`**，由 03-治理决定是否直接入库或进 Draft 审核。管道不直接操作 PostgreSQL/pgvector。

## 三、管道2 — 运营实践自学习

### 3.1 触发时机

被 `MemorySystem.on_task_complete()` 调用（见 01 文档 §8.4），每次任务结束后自动执行。

### 3.2 学习逻辑

```python
class Pipe2SelfLearning:
    """管道2：运营实践自学习。

    参考 Claude Code Self-correction Loop：
    - 成功 → 记录"这个做法成功"→ confidence_score +
    - 失败 → 记录"这个做法失败"→ 标记 lessons_learned
    """

    async def on_task_complete(self, task: Task, result: TaskResult) -> None:
        if result.success and result.reusability_score > 0.6:
            await self._record_success(task, result)
        elif not result.success and result.has_lesson:
            await self._record_failure(task, result)

    async def _record_success(self, task: Task, result: TaskResult) -> str:
        """记录成功经验。"""
        entry = KnowledgeEntry(
            title=f"成功经验: {task.type} - {task.agent}",
            content=self._summarize_success(task, result),
            category=self._infer_category(task),
            confidence_level="L3",  # 经验级
            confidence_score=0.6,
            source="pipe2_self_learning",
            owner_agents=[task.agent],
            platform_scope=[task.context.get("platform", "")] if task.context.get("platform") else [],
            tags=[task.type, "success"],
        )
        return await self._governance.write(entry)  # L3 需 Draft 审核

    async def _record_failure(self, task: Task, result: TaskResult) -> str:
        """记录失败教训（优先级更高）。"""
        entry = KnowledgeEntry(
            title=f"失败教训: {task.type} - {task.agent}",
            content=f"失败原因: {result.error}\n教训: {result.lesson}",
            category=self._infer_category(task),
            confidence_level="L3",
            confidence_score=0.3,  # 失败的置信度低
            source="pipe2_self_learning",
            owner_agents=[task.agent],
            tags=[task.type, "failure", "warning"],
        )
        return await self._governance.write(entry)
```

### 3.3 置信度调整

```python
    async def adjust_confidence(self, entry_id: str, feedback: Literal["positive", "negative"]):
        """上游反馈调整置信度。"""
        delta = 0.05 if feedback == "positive" else -0.1
        entry = await self._semantic.get(entry_id)
        entry.confidence_score = max(0, min(1, entry.confidence_score + delta))
        if feedback == "positive":
            entry.positive_feedback += 1
        else:
            entry.negative_feedback += 1
        await self._semantic.update(entry_id,
            confidence_score=entry.confidence_score,
            positive_feedback=entry.positive_feedback,
            negative_feedback=entry.negative_feedback)
```

class Pipe3WebLearning:
    """管道3：网络学习（定时爬取）。"""

    SCHEDULE = "0 2 * * *"  # 每日 02:00

    TARGETS = [
        {"url": "https://rule.taobao.com/", "category": "platform_rule", "platform": "taobao"},
        {"url": "https://rule.tmall.com/", "category": "platform_rule", "platform": "tmall"},
        {"url": "https://ecom.douyin.com/rules", "category": "platform_rule", "platform": "douyin"},
    ]

    async def run(self) -> int:
        """定时爬取 + LLM 摘要入库。"""
        count = 0
        for target in self.TARGETS:
            # 1. 爬取（使用 Kitewright 浏览器自动化）
            raw_content = await self._crawl(target["url"])

            # 2. LLM 摘要 + 结构化
            structured = await self._llm_extract(raw_content, target)

            # 3. 入库
            for item in structured:
                entry = KnowledgeEntry(
                    title=item["title"],
                    content=item["content"],
                    category=target["category"],
                    confidence_level="L4",  # 网络爬取碎片，需验证
                    source="pipe3_web",
                    source_url=target["url"],
                    platform_scope=[target["platform"]],
                    effective_until=time.time() + 30 * 86400,  # 30 天有效
                    review_cycle_days=15,
                )
                await self._governance.write(entry)  # L4 需 Draft 审核
                count += 1
        return count

class Pipe4CompetitorAnalysis:
    """管道4：竞品分析。"""

    SCHEDULE = "0 8 * * 1"  # 每周一 08:00

    async def run(self, competitor_shop_ids: list[str]) -> int:
        """抓取竞品数据，对比自身，生成洞察。"""
        count = 0

                    effective_until=time.time() + 7 * 86400,  # 7 天有效

                count += 1
        return count

## 七、管道6 — 客户数据反哺

### 7.1 触发时机

### 7.2 实现

```python
class Pipe6CustomerFeedback:
    """管道6：客户数据反哺（最有价值）。"""

    async def on_order_created(self, order: dict) -> None:
        """订单创建 → 购买关联分析。"""
        associations = self._analyze_associations([order])
        for assoc in associations:
            entry = KnowledgeEntry(
                title=f"购买关联: {assoc['product_a']} → {assoc['product_b']}",
                content=f"买{assoc['product_a']}的人{assoc['probability']:.0%}也买了{assoc['product_b']}",
                category="customer_behavior",
                confidence_level="L3",
                source="pipe6_customer",
                tags=["association_rule"],
                owner_agents=["shopping_advisor", "private_butler"],
            )
            await self._governance.write(entry)

    async def on_review_submitted(self, review: dict) -> None:
        """评价提交 → 产品优化方向。"""
        if review.get("rating", 5) <= 2:
            # 差评 → 风险预警
            entry = KnowledgeEntry(
                title=f"差评风险: {review['product_name']}",
                content=f"差评原因: {review.get('content', '')}",
                category="customer_behavior",
                confidence_level="L3",
                source="pipe6_customer",
                tags=["negative_review", "risk"],
                owner_agents=["service_agent", "data_advisor"],
            )
            await self._governance.write(entry)

    async def on_refund_created(self, refund: dict) -> None:
        """退换货 → 风险预警。"""
        entry = KnowledgeEntry(
            title=f"退换货风险: {refund['product_name']} - {refund['reason']}",
            content=f"退货原因: {refund['reason']}\n频次: {refund.get('count', 1)}",
            category="customer_behavior",
            confidence_level="L3",
            source="pipe6_customer",
            tags=["refund", "risk"],
            owner_agents=["service_agent", "data_advisor"],
        )
        await self._governance.write(entry)

    def _analyze_associations(self, orders: list[dict]) -> list[dict]:
        """购买关联分析（Apriori 简化版）。"""
        # 统计共现频率
        pair_counts = {}
        for order in orders:
            items = order.get("items", [])
            for i, a in enumerate(items):
                for b in items[i+1:]:
                    key = tuple(sorted([a["sku"], b["sku"]]))
                    pair_counts[key] = pair_counts.get(key, 0) + 1

        # 转换为关联规则
        associations = []
        for (a, b), count in pair_counts.items():
            if count >= 3:  # 最小支持度
                associations.append({
                    "product_a": a,
                    "product_b": b,
                    "probability": min(0.95, count / 10),
                })
        return associations
```

## 十二、关键设计决策

| # | 决策 | Why | 影响 |
|---|------|-----|------|
| 1 | 所有管道写入走 `SemanticLayer.store()` + 治理门控 | 统一写入路径，不绕过治理 | 管道不直接操作存储 |
| 2 | 管道2（自学习）失败教训 importance 高于成功经验 | 失败教训更稀缺更有价值 | 失败教训优先提升 |
| 3 | 管道3/4 爬取内容 L4 级需 Draft 审核 | 网络信息可信度低，防噪声 | 爬取知识不直接污染 Semantic |
| 4 | 管道5 CosDNA 成分 owner_agents 限定导购+内容官 | 成分知识只对这两个数字同事有用 | 检索时按 owner 过滤，减少噪声 |
| 5 | 管道6 购买关联最小支持度=3 | 低于 3 次的关联可能是偶然 | 保证关联规则可靠性 |
| 6 | 管道调度三种模式（cron/event/manual） | 种子/人工=手动，自学习/客户=事件，网络/竞品/专业库=定时 | 覆盖所有触发场景 |
| 7 | 管道3 爬取使用 Kitewright（Rust MCP Server） | 已有基础设施，不引入新依赖 | 复用现有浏览器自动化 |
