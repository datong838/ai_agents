# 228-AIP 助手、分析师与通用工作台实施方案

> 状态：**待评审 · 不授权编码**
> 对应阶段：AIP-8。

## 1. 产品定位

- AIP 助手：面向当前 Selection/Task/页面上下文的权限感知入口。
- AIP 分析师：基于 Ontology/OKF/Wiki canonical read model 的只读分析环境。
- 通用工作台：任务驱动的人机协作壳，承载六数字同事的计划、产物、审批和复盘，不复制平台专项逻辑。

## 2. 当前缺口

- Analyst 后端只查询 Northampton `shops`、`inventory`、`sales` 内存表，未知表返回 fallback。
- Assist 建议问题与平台样例脱离当前栖月汇任务，权限证据不可见。
- Studio 无真实 Agent 时只能显示空列表，新建入口禁用。
- 1280px 下双层左侧导航挤占近半屏，主内容被裁切。
- 12-* 中部分“已完成”是设计口径，必须以当前真实 API 与页面回读重判。

## 3. 查询主链

```text
User question / saved query
 -> resolve org/project/actor/selection
 -> query plan (ObjectSet/OKF/Wiki/metric)
 -> permission + marking
 -> execute read-only canonical adapters
 -> result + source/freshness/lineage
 -> chart/table/map/report artifact
```

禁止直接执行任意 SQL；首期提供受控 semantic query/metric query。导出必须带数据截止时间、源、过滤器和脱敏说明。

## 4. 通用工作台布局

- 全局导航可折叠；AIP 子导航默认窄栏，编辑/分析区支持 Focus Mode。
- 顶部：Task、组织/工作区、Selection、数据截止时间、运行/审批状态。
- 左：任务/对象/查询列表，可收起。
- 中：表格、图表、图谱、文档等主工作区，占主要宽度。
- 右：Agent 建议、证据、Wiki、审批和谱系，可抽屉化。
- 底部：运行时间线、失败、重试、成本和回执。

## 5. 首批通用页面

1. 数据参谋驾驶舱：数据健康、异常、任务和报告。
2. 客户关系工作台：CustomerLite、互动、跟进草稿。
3. 内容日历工作台：ContentDraft、MediaJob、审核状态。
4. 活动策划工作台：ActivityPlan revision、方案对比、Draft。
5. 日常任务总控：六同事 Task Kanban、Handoff、复盘与 MemoryCandidate。

页面消费通用 API，微商城只在后续 InstanceOverlay 增加字段、视图和 Adapter 状态。

## 7. 验收

- `org-org/dev-project` 查询只展示真实 Object/OKF/Wiki 数据；无数据时为空。
- 页面不再出现 Northampton、Walter and Sons 等内置业务样例。
- 查询和导出能追溯 source/freshness/selection/actor。
- 1280、1440、1920 三档视口主工作区不被导航裁切，核心编辑器有 Focus Mode。
- 所有主按钮产生可见状态变化或明确禁用原因，无静默 no-op。
