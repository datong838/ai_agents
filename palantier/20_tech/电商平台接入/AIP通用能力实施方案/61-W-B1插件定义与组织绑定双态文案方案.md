## 3. UI 规则（最小）

1. 页头增加一句：组织绑定与定义八维是两层，勿混读。  
2. 每卡两枚徽章：`组织绑定：未绑定|已启用|…` 与 `定义就绪：…`。  
3. 原因区两段：`组织绑定侧` / `定义层`；仅未绑定时出现「去目录绑定」。  
4. 已有组织绑定时，**禁止**主状态写「未绑定」。  
5. 不引入方案编号作主文案（军规 52）。
