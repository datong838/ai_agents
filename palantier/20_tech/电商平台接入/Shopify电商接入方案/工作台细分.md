### 1.2 Shopify 七大特色能力

| # | 特色能力 | 对工作台的要求 | 对接工具/API |
|---|---------|--------------|------------|
| 1 | **Shopify Analytics** | 数据参谋对接：订单/客户/流量/转化率/ROAS | Shopify Admin REST API → Analytics endpoint |
| 2 | **Klaviyo 邮件营销** | 客户关系=邮件营销工作台：模板+流程+弃购挽回 | Klaviyo API（Campaigns/Flows/Metrics） |
| 3 | **弃购挽回（Abandoned Checkout）** | 特色微件：弃购率 · 挽回邮件 · 挽回金额 | Shopify Admin API → AbandonedCheckout |
| 4 | **主题定制 + APP 生态** | 内容日历：博客 + 主题改版 + Landing Page | Shopify Storefront API · Theme API |
| 5 | **PayPal + Stripe 跨境支付** | 订单管理：多币种退款 · 汇率确认 · 跨境手续费 | Stripe API · PayPal API |
| 6 | **黑五/网一/圣诞大促** | 活动策划：限时闪购 + Bundle + 折扣码管理 | Shopify Admin API → PriceRule / DiscountCode |
| 7 | **独立站 SEO** | 内容日历 + 活动策划：SEO 面板 · Meta 信息 · Schema | SEO 工具集成（Yoast SEO 等 APP） |

### 1.3 Shopify 客户 vs 传统电商客户

| 维度 | Shopify 客户（独立站） | 传统平台电商（淘宝/京东） |
|------|---------------------|------------------------|
| **客户身份** | 邮件订阅者 · 邮箱买家 | 平台会员 · 平台账号 |
| **触达方式** | Email + SMS + WhatsApp + Facebook Messenger | 站内信 + 旺旺/京麦 + 短信 |
| **流量来源** | Google SEO + 社媒 + 广告投放 + 邮件 | 平台搜索 + 推荐流 + 活动 |
| **标签体系** | 行为标签（浏览/加购/弃购）+ LTV + 地域 | RFM + 平台层级（V1-V6） |
| **合规要求** | GDPR（欧盟）· CCPA（加州）· CASL（加拿大） | 平台规则 + 国内电商法 |
| **货币/语言** | 多币种显示 + 多语言 UI | 单一币种（¥）+ 中文 |

#### 3.1.2 核心能力与通用版差异

| 差异维度 | 通用版（客户关系） | Shopify 邮件营销版 |
|---------|-----------------|------------------|
| **客户定义** | 全平台通用（企微/平台会员/邮箱） | 邮件订阅者 + Shopify Customer OT |
| **触达渠道** | 按平台差异化配置 | **Email + SMS + WhatsApp + Facebook Messenger** 四通道 |
| **标签体系** | RFM + 平台标签 | **行为标签**（浏览/加购/弃购/购买频次）+ LTV + 地域/语言 |
| **分层模型** | VIP/高价值/潜力/沉默 | **邮件活跃度分层**：Engaged / At Risk / Churned + RFM |
| **新建任务类型** | 客户沉淀/分层/跟进/推荐 | **6 类营销自动化**：弃购挽回/新品推送/欢迎序列/复购激活/Win-back/节日问候 |
| **权限门控** | 话术长度/敏感词 | **GDPR 合规**：退订链接 · 双重确认 · 数据擦除请求 · 国别合规 |
| **特色微件** | AI 洞察 + 客户画像 | **Klaviyo 集成**：邮件模板库 + Flow 自动化 + Metrics 看板 |
| **AI 洞察方向** | 搭配推荐 + 复购提醒 | **营销优化**：主题行 A/B + 发送时间优化 + 弃购挽回时机 + 受众扩容 |

#### 3.1.4 GDPR 合规模块

| 合规项 | 检查内容 | 门控动作 |
|--------|---------|---------|
| 退订链接 | 每封邮件底部含 unsubscribe 链接 + List-Unsubscribe header | **未通过→禁止发送** |
| 双重确认 | EU 地区用户需 double opt-in 才能发送营销邮件 | 仅发送给已确认用户 |
| 数据擦除 | 用户可请求数据删除（Right to Erasure） | 7 天内从 Klaviyo + Shopify 清除 |
| 国别合规 | UK GDPR / German UWG / French CNIL / CASL（加拿大） | 按邮箱后缀/IP 匹配国别规则 |
| 敏感信息 | 邮件中不暴露完整支付信息 + 地址（仅展示 billing first name + city） | Diff 视图自动标注敏感字段 |
