> **版本**：v1.0 · 2026-07-23
> **参照**：`../000-电商平台接入总方案.md` Stage 1-6 框架
> **定位**：Phase 1 第三个接入平台，验证 **POP/自营双 API 模式** + **HMAC-SHA256 签名**
> **依赖**：G1（REST API Connector）+ G6（HMAC-SHA256 签名）
> **核心挑战**：POP（第三方商家）和自营 VC（Vendor Center）使用**不同 API 子集**，需模型分层

## Stage 1 · 数据接入（Data Connection）

### 1.1 连接器配置

| 项 | POP 开放平台 | 自营 VC |
|----|-------------|---------|
| 连接器类型 | REST API Connector | REST API Connector（另一配置） |
| 网关地址 | `https://api.jd.com/routerjson` | `https://api.jd.com/routerjson`（VC 接口） |
| API 前缀 | `jingdong.ware.*` / `jingdong.pop.order.*` | `jingdong.vc.*` / `jingdong.b2b.*` |
| 认证方式 | OAuth 2.0 → `access_token` | OAuth 2.0（VC 专用授权） |
| 签名算法 | **MD5**（app_secret + params → MD5 → 大写） | 同左 |
| 速率限制 | 按 `app_key` 粒度限流，各接口独立 | 同左 |
| 分页方式 | `page` + `page_size` | 同左 |

### 1.2 POP vs 自营核心差异

| 维度 | POP（第三方商家） | 自营 VC（Vendor Center） |
|------|------------------|------------------------|
| 商品发布 | `jingdong.ware.write.*`（JSON 提交） | `jingdong.vc.item.*`（VC 商品提报） |
| 库存管理 | 商家自主管理 | **京东仓内库存 + 采购单驱动** |
| 订单履约 | 商家发货（SOP/SOPL/LBP 模式） | **京东仓发货 + 采购单流转** |
| 结算 | 商家自主结算 | **采销结算**（账期制） |
| 定价权 | 商家自主定价 | **京东统一定价 + 采购价** |
| 物流 | 可选京东物流/第三方 | **京东仓配一体**（JDL） |
| 售后 | `jingdong.pop.afs.*` | VC 售后通道 |

**AOS 策略**：同一 Source 连接器，根据 API 响应中的 `pop_type` 字段区分 POP/自营数据，路由到不同 Dataset。

### 1.4 探索源（API 目录）

| API 分类 | POP 核心 API | VC 核心 API |
|----------|-------------|------------|
| **订单** | `jingdong.pop.order.list` / `jingdong.pop.order.get` | `jingdong.b2b.order.list` |
| 商品 | `jingdong.ware.list` / `jingdong.ware.get` | `jingdong.vc.item.*` |
| 售后 | `jingdong.pop.afs.list`（售后服务单） | `jingdong.vc.afterservicelist` |

| 采购 | — | `jingdong.vc.po.*`（采购单） |

## Stage 2 · 数据同步（Sync）

### 2.1 同步策略

| 数据域 | API | 事务类型 | 增量方式 | 调度 |
|--------|-----|----------|----------|------|
| **POP 订单** | `jingdong.pop.order.list` | APPEND | `start_date` + `end_date` | 每 15 分钟 |
| **VC 采购单** | `jingdong.vc.po.list` | APPEND | `start_modified` | 每 30 分钟 |
| POP 商品 | `jingdong.ware.list` | SNAPSHOT | 全量 | 每 6 小时 |
| VC 商品 | `jingdong.vc.item.*` | SNAPSHOT | 全量 | 每 6 小时 |
| POP 售后 | `jingdong.pop.afs.list` | APPEND | `start_modified` | 每 30 分钟 |
| 库存 | `jingdong.pop.stock.get` | SNAPSHOT | 全量 | 每 1 小时 |

### 2.2 POP 订单 SOP/SOPL/LBP 模式

京东 POP 有三种发货模式，影响订单字段和物流流程：

| 模式 | 全称 | 含义 | 影响 |
|------|------|------|------|
| **SOP** | Sale On POP | 商家自主发货（类似淘宝） | 订单直接到商家，商家选物流 |
| **SOPL** | Sale On POP Logistics | 商家发货但用京东物流 | 订单到商家，但使用 JDL 配送 |
| **LBP** | Logistics By POP | 京东物流全链路 | 类似 FBA，京东仓发货 |

## Stage 3 · 管道清洗（Pipeline Builder）

### 3.1 POP/自营数据合并

```sql
-- POP 订单 + VC 采购单合并为统一订单 Dataset
Union:
  SELECT order_id, 'POP' as channel, order_status, order_amount, ...
  FROM pop_orders_sync

  UNION ALL

  SELECT po_id as order_id, 'VC' as channel, po_status as order_status, po_amount as order_amount, ...
  FROM vc_purchase_orders_sync

-- 输出：unified_orders（含 channel 字段区分 POP/VC）
```

### 3.2 状态枚举映射

```sql
-- POP 订单状态
CASE order_status
  WHEN 'WAIT_SELLER_STOCK_OUT' THEN 'paid'         -- 待发货
  WHEN 'WAIT_GOODS_RECEIVE_CONFIRM' THEN 'shipped'  -- 待收货
  WHEN 'WAIT_SELLER_DELIVERY' THEN 'shipping'       -- 发货中
  WHEN 'FINISHED_L' THEN 'completed'                -- 完成
  WHEN 'TRADE_CANCELED' THEN 'canceled'             -- 取消
  WHEN 'LOCKED' THEN 'locked'                       -- 锁定
  ELSE 'unknown'
END AS status_enum

-- VC 采购单状态（完全不同的状态机）
CASE po_status
  WHEN 'WAIT_CONFIRM' THEN 'pending_confirm'        -- 待确认
  WHEN 'CONFIRMED' THEN 'confirmed'                 -- 已确认
  WHEN 'WAIT_DELIVER' THEN 'wait_deliver'           -- 待入库
  WHEN 'FINISHED' THEN 'completed'                  -- 已完成
  WHEN 'CANCELED' THEN 'canceled'                   -- 已取消
  ELSE 'unknown'
END AS vc_status_enum
```

## Stage 4 · OKF 映射（Funnel）

### 4.1 OT 映射表（POP/VC 分层）

| JD 对象 | 统一 OT | 主键 | 来源 |
|---------|---------|------|------|
| POP Order | **Order** | `order_id` | `jingdong.pop.order.get` |
| VC PurchaseOrder | **Order**（`channel=VC`） | `po_id` | `jingdong.vc.po.list` |
| Ware | **Product** | `ware_id` | `jingdong.ware.get` |
| VC Item | **Product**（`channel=VC`） | `vc_item_id` | `jingdong.vc.item.*` |
| AFS | **AfterSales** | `afs_id` | `jingdong.pop.afs.list` |
| Stock | **Inventory** | `sku_id` | `jingdong.pop.stock.get` |

### 4.2 Funnel 状态机

```
POP: WAIT_SELLER_STOCK_OUT → WAIT_GOODS_RECEIVE_CONFIRM → FINISHED_L
VC:  WAIT_CONFIRM → CONFIRMED → WAIT_DELIVER → FINISHED
     ↘ CANCELED
```
