### 1.2 天猫 vs 淘宝差异矩阵

| 差异维度 | 天猫（品牌官方旗舰店） | 淘宝（C 店/企业店） |
|---------|---------------------|------------------|
| **店铺类型** | 品牌旗舰店/专卖店/专营店 | 个人 C 店/企业店 |
| **入驻门槛** | 品牌资质 + 10 万保证金 | 身份证/营业执照 + 1000 元 |
| **客户关系** | 🎖️ 品牌会员体系（等级/成长值/积分） | 淘宝会员 + 店铺粉丝 |
| **核心活动** | 聚划算/百亿补贴/618/双11/品类日 | 天天特卖/淘宝直播/淘金币 |
| **内容阵地** | 微淘 + 逛逛 + A+ 品牌内容 | 淘宝直播 + 猜你喜欢 |
| **投放工具** | 🎯 万象台品牌版 + 品牌专区 | 直通车 + 万象台标准版 |
| **数据能力** | 🏦 品牌数据银行（AIPL/FAST/GROW） | 生意参谋标准版 |
| **用户权益** | 88VIP 95 折 + 极速退款 + 运费险 | 淘宝金币 + 退货保障 |
| **物流模式** | 菜鸟仓配 + 天猫超市当日达 | 商家自发/菜鸟驿站 |
| **信任背书** | 正品保障 + 假一赔四 | 消保保证金 |
| **AI 运营重点** | 品牌人群资产运营 + 会员生命周期 | 单品引流 + 转化率优化 |
| **对接数字同事** | 品牌运营官 + 会员运营专员 | 导购顾问 + 活动策划师 |

#### 3.1.2 天猫品牌会员核心数据结构

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| `member_id` | string | 天猫品牌会员 ID | 天猫开放平台 |
| `level` | enum | 普通/白银/黄金/铂金/钻石 | 品牌会员体系 API |
| `growth_value` | int | 成长值（决定等级） | 成长值明细 API |
| `points` | int | 可用积分 | 积分账户 API |
| `points_expire` | date | 最近积分到期日 | 积分明细 API |
| `total_spent` | decimal | 累计消费金额 | 交易订单 API |
| `last_active` | datetime | 最后活跃时间 | 会员行为 API |
| `tags` | string[] | 会员标签（肤质/品类偏好等） | 品牌数据银行 |
| `member_union` | object | 品牌会员通关联（线下/其他平台） | 会员通 API |
| `exclusive_price` | decimal | 会员专享价（按等级） | 优惠工具 API |

#### 3.1.3 会员运营专员技能 → 新建任务下拉

| 技能 | 任务说明 | 触发场景 |
|------|---------|---------|
| 会员分层 + 权益配置 | 按等级配置专享价/积分倍率 | 会员日/大促前 |
| 积分到期提醒 | 向 7 天内积分到期用户发送提醒 | 每周一自动 |
| 等级保级提醒 | 向临近保级期用户推送消费任务 | 每月 25 日 |
| 会员日触达 | 会员日专属优惠 + 定向推送 | 每月 8 日/18 日/28 日 |
| 流失会员挽留 | 30 天无动作会员的专属挽留方案 | 数据参谋预警触发 |
| 新会员礼包 | 新注册会员的首购礼包配置 | 实时触发 |
| 会员通打通 | 线下/天猫会员数据同步 | 每日凌晨批量 |
