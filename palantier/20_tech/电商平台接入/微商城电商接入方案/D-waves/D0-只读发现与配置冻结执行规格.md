## 3. 功能需求（FR，RFC 2119）

### FR-D0-1（MUST）源端结构冻结
脚本 `qyh_discover_readonly.py` MUST 经 SSH 隧道只读连接 `niushop_b2c_v5`，对 7 个核心 OT 的源表冻结：
- 表结构（列名/类型/可空/默认值/字符集）
- 索引（主键/唯一键/普通索引）
- 状态字段枚举值与分布（不含明细，只做 `GROUP BY` 聚合计数）
- `modify_time` / `create_time` 的时间范围与空值占比（用于增量游标可行性判断）

### FR-D0-2（MUST）PII 字段分类冻结
脚本 MUST 对 7 表涉及的字段按 PII 等级分类，输出分类清单（不输出值）：
- `PII_DIRECT`：姓名、手机号、身份证、详细地址、银行卡号、OpenID、unionid
- `PII_QUASI`：邮箱、省市区、昵称、头像 URL
- `NON_PII`：商品名、订单号、金额、状态码、时间戳

分类清单 MUST 落到 [frozen/01-schema-fingerprint.md](../frozen/01-schema-fingerprint.md)，脚本不得打印 PII_DIRECT 字段的任何值。

### FR-D0-3（MUST）7 Pipeline 规格冻结
基于上位方案第 5 节的骨架，冻结 P01~P07 每条 Pipeline 的：
- 源表 + 主键 + 增量游标字段
- 租户过滤条件（`site_id=1`）
- 目标 OT 映射
- 唯一键命名空间（`niushop:1:{pk}`）
- 时间转换规则（Unix 秒 → UTC，0 → null）

落到 [frozen/02-pipeline-manifest.yaml](../frozen/02-pipeline-manifest.yaml)（**规格文档，非 bundle 资产**——因为 BundleExports 契约不支持 pipeline 字段）。

### FR-D0-4（MUST）OpenAPI 写请求体冻结
对微商城后台可能用到的写接口（商品上下架、库存调整等），冻结请求体 schema 校验规则到 [frozen/03-openapi-write-contract.md](../frozen/03-openapi-write-contract.md)。**D0 只校验 schema，不发写请求**。

### FR-D0-5（MUST）差异清单闭环
脚本 MUST 输出 [frozen/04-discovery-report.md](../frozen/04-discovery-report.md)，列出：
- 上位方案第 5 节规格与真实 schema 的差异
- 类型不匹配、缺失索引、空值风险
- 每条差异的处置决定（修正规格 / 登记为风险 / 标 D1 处理）

### FR-D0-6（MUST）只读与脱敏强制约束
- 连接级 `SET SESSION TRANSACTION READ ONLY`
- 全局 `LIMIT 100` 行采样上限（结构发现不需要全量）
- PII_DIRECT 字段查询只做 `COUNT`/`GROUP BY`，禁止 `SELECT *`
- 单查询超时 30s，总脚本超时 600s
- 隧道断开时 fail-closed，不重试连真实库

## 5. 验收标准（AC，Given/When/Then，每条追溯 FR）

### AC-D0-1（← FR-D0-1）源端结构冻结
- **Given** recommend_ro 有 7 表 SELECT 权限
- **When** 运行 `python scripts/qyh_discover_readonly.py --dry-run`
- **Then** 产出 frozen/01-schema-fingerprint.md，7 表的列/索引/枚举聚合全部存在

### AC-D0-2（← FR-D0-2）PII 不出库
- **Given** 脚本已运行
- **When** 对 frozen/01-schema-fingerprint.md 做正则扫描（1[3-9]\d{9}、\d{15,18}、62\d{14,17}）
- **Then** PII_DIRECT pattern 命中数 = 0

### AC-D0-3（← FR-D0-3）7 Pipeline 规格完整
- **Given** frozen/02-pipeline-manifest.yaml
- **When** 用 yaml schema 校验器检查
- **Then** P01~P07 每条含 source_table/pk/cursor/site_filter/target_ot/unique_key/time_rule 六个必填键

### AC-D0-4（← FR-D0-4）OpenAPI 写契约只校验不发写
- **Given** frozen/03-openapi-write-contract.md
- **When** 检查脚本行为
- **Then** 全程无 POST/PUT/PATCH/DELETE 到 yanpanji.com 或 127.0.0.1 微商城后台

### AC-D0-5（← FR-D0-5）差异清单闭环
- **Given** frozen/04-discovery-report.md
- **When** 检查每条差异
- **Then** 每条都有 disposition 字段（spec-fix / risk-logged / d1-defer），无空值

### AC-D0-6（← FR-D0-6）只读事务负向测试
- **Given** 脚本已连接 recommend_ro
- **When** 尝试 `CREATE TABLE _t(x int)`
- **Then** 被 MariaDB 拒绝（权限不足）

### AC-D0-7 专项测试通过
- **Given** tests/microshop/test_d0_discovery_readonly.py
- **When** pytest 运行
- **Then** 全部 passed，覆盖：连接只读、PII 脱敏、产物 schema、差异闭环、超时 fail-closed
