## Stage 1 · 数据接入（Data Connection）

### 1.1 连接器配置

| 项 | 配置 |
|----|------|
| 连接器类型 | **REST API Connector**（抖店开放平台模板） |
| 网关地址 | `https://openapi-fxg.jinritemai.com` |
| 认证方式 | **OAuth 2.0**（店铺授权码）→ `access_token` |
| 签名算法 | **HMAC-SHA256**（`app_secret` + `param_json` → SHA256） |
| 数据格式 | JSON |
| 速率限制 | 按接口分级（详见 1.4） |
| 特殊 | **100 次取整计费**（非 API 调用次数，而是返回的数据条数 ÷ 100 向上取整） |

### 1.2 抖音签名流程

```
1. 构造 param_json（业务参数 JSON 字符串）
2. 构造签名字符串：app_secret + method + timestamp + app_key + param_json + sign_method
3. HMAC-SHA256(app_secret, 签名字符串) → 十六进制小写 → sign 参数
4. POST 到 https://openapi-fxg.jinritemai.com
```

### 1.3 抖店云部署（G8）

```
传统方式：AOS → 抖店 API（公网）→ 计费 0.18 元/百次
抖店云方式：AOS Agent 部署在抖店云内网 → API 费用降低 90%（0.018 元/百次）

架构：
  抖店云内网
  ┌────────────────────────────┐
  │  AOS Agent (抖店云版)        │
  │  ├── REST API Connector     │
  │  ├── HMAC-SHA256 签名模块    │
  │  └── PII 脱敏管道 (G9)       │
  │          ↓ 内网调用           │
  │  抖店开放平台 API (内网直连)   │
  └────────────────────────────┘
           ↓ 加密隧道
  AOS Platform（Foundry 主集群）
```

### 1.4 计费模型

抖音 API 按返回数据量计费（非调用次数）：

| 计费方式 | 说明 |
|----------|------|
| **100 次取整** | 返回 1 条 = 100 次计费；返回 101 条 = 200 次计费 |
| 抖店云优惠 | **0.018 元/百次**（公网 0.18 元/百次，降低 90%） |
| 免费额度 | 每日有一定的免费额度 |

**影响**：同步策略需要**最大化每页数据量**，减少 API 调用次数。

### 1.5 探索源（API 目录）

| API 分类 | 核心 API | 用途 |
|----------|---------|------|
| **商品** | `/product/list` | 商品列表 |
| | `/product/detail` | 商品详情 |
| **订单** | `/order/searchList` | 订单列表 |
| | `/order/orderDetail` | 订单详情 |
| **解密** | `/order/encryptedInfo` | **订单解密**（手机号/地址加密存储） |
| **物流** | `/logistics/companyList` | 物流公司 |
| | `/logistics/add` | 发货 |
| **售后** | `/afterSale/list` | 售后列表 |
| | `/afterSale/detail` | 售后详情 |
| **精选联盟** | `/alliance/*` | 达人选品/佣金 |
| | `/buyin/*` | 百应买货 |
| **内容** | `/product/qualification/list` | 商品资质 |

### 1.6 PII 解密（G9）

抖音对用户隐私数据**强制加密**：

```
订单中的 receiver_name / receiver_phone / receiver_address 均为加密密文
解密流程：
  1. 调用 /order/encryptedInfo 获取加密数据
  2. 使用商家解密密钥解密
  3. 解密后在 AOS PII 脱敏管道中立即标记（Marking: pii）
  4. 仅授权用户可查看明文
```

## Stage 2 · 数据同步（Sync）

### 2.1 同步策略（抖店云优化版）

| 数据域 | API | 事务类型 | 增量方式 | 调度 | 计费优化 |
|--------|-----|----------|----------|------|----------|
| **订单** | `/order/searchList` | APPEND | `update_time` 增量 | 每 15 分钟 | `page_size=100` 最大化 |
| 订单解密 | `/order/encryptedInfo` | APPEND | 关联订单 | 每 30 分钟 | **仅解密新增订单** |
| 商品 | `/product/list` | SNAPSHOT | 全量 | 每 6 小时 | |
| 售后 | `/afterSale/list` | APPEND | `update_time` | 每 30 分钟 | |
| 达人 | `/alliance/materialList` | APPEND | 分页 | 每 1 小时 | |
| 物流 | 按订单号查询 | APPEND | 关联订单 | 每 30 分钟 | |

### 2.2 订单解密同步链路

```
Step 1: /order/searchList → 获取订单基本信息（不含地址/手机号）
Step 2: /order/encryptedInfo → 获取加密的 receiver_name/phone/address
Step 3: 解密 → PII 脱敏管道（G9）→ 标记 Marking: pii
Step 4: 写入 curated_orders Dataset（手机号/地址仅授权可见）
```

## Stage 3 · 管道清洗（Pipeline Builder）

### 3.1 抖音特色：内容+电商双域处理

```
电商域数据：
  /product/* + /order/* + /afterSale/* + /logistics/*
  → 标准 8 域映射（与淘宝/拼多多类似）

内容域数据（抖音独有）：
  /video/* + /live/* + /window/*
  → 新增 Content OT + 达人关联
```

### 3.2 达人佣金计算（Expression + Aggregate）

```sql
-- 精选联盟佣金计算
Expression:
  CASE commission_type
    WHEN 'RATIO' THEN goods_price * commission_rate / 100  -- 比例佣金
    WHEN 'FIXED' THEN commission_amount                     -- 固定佣金
  END AS commission_value

Aggregate GROUP BY creator_id:
  COUNT(DISTINCT order_id)     → total_orders      -- 带货单数
  SUM(commission_value)         → total_commission  -- 总佣金
  SUM(order_amount)             → gmv              -- 带 GMV
  AVG(commission_rate)          → avg_rate          -- 平均佣金率
```

### 3.3 PII 脱敏管道

```sql
-- 抖音订单解密后的 PII 脱敏
Expression:
  CASE WHEN is_authorized = true THEN receiver_phone
       ELSE CONCAT(LEFT(receiver_phone,3), '****', RIGHT(receiver_phone,4))
  END AS phone_masked

Expression:
  CASE WHEN is_authorized = true THEN receiver_address
       ELSE CONCAT(LEFT(receiver_address,6), '****')
  END AS address_masked
```

## Stage 4 · OKF 映射（Funnel）

### 4.1 OT 映射表（含抖音独有 OT）

| 抖店对象 | 统一 OT | 主键 | 关键映射 |
|----------|---------|------|----------|
| `TradeOrder` | **Order** | `shop_order_id` | pay_amount→amount, order_status→status_enum |
| `Product` | **Product** | `product_id` | name→title, price→price |
| `Sku` | **ProductVariant** | `sku_id` | spec→variant_name |
| `ShopUser` | **Customer** | `open_id` | nick_name→name（**匿名 ID**，非手机号） |
| `AfterSale` | **AfterSales** | `aftersale_id` | refund_amount→amount |
| `Creator`（**新**） | **Creator** | `open_id` | nick_name→name, follower_count→followers |
| `AllianceMaterial`（**新**） | **PromotionItem** | `product_id+creator_id` | commission_rate, cos_ratio |
| `LiveRoom`（**新**） | **LiveRoom** | `room_id` | title, watch_count, gmv |

### 4.2 Funnel 状态机

```
订单：created → paid → shipped → delivered → completed
                                         ↘ after_sale → refunded

直播：开播 → 直播中 → 结束
  └── GMV 实时统计
```
