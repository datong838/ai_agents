## 一、平台定位与特色

### 1.1 平台定位

**抖音 = 兴趣电商 + 内容驱动 + 短视频/直播带货**。与传统货架电商（淘宝/京东）不同，抖音的核心转化路径是"**内容种草 → 兴趣激发 → 即时购买**"，而非"搜索 → 比价 → 下单"。

```
抖音电商核心飞轮
═══════════════════════════════════════════════════
  ┌─────────────┐     内容种草     ┌─────────────┐
  │  短视频/直播  │ ──────────────→ │  兴趣激发    │
  └──────┬──────┘                  └──────┬──────┘
         │                                │
    优质内容↑                        即时购买↓
         │                                │
  ┌──────┴──────┐                  ┌──────┴──────┐
  │  粉丝沉淀    │ ←────────────── │  GMV 转化    │
  └─────────────┘     复购关注     └─────────────┘
```
