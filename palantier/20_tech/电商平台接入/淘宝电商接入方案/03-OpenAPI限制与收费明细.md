## 1. OpenAPI 限制全景

### 1.1 限制分层

```
┌─────────────────────────────────────────────────────┐
│                  TOP OpenAPI 四层限制                  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Layer 1 · 应用类型限制                               │
│  ├─ 个人开发者：≤10 次/分钟，仅基础查询                 │
│  ├─ 自用型：500 QPS，大部分 API（仅自有店铺）            │
│  ├─ 定制型：500 QPS，需逐个申请权限包                   │
│  └─ 工具型：500 QPS，需上架审核                         │
│                                                     │
│  Layer 2 · 权限包限制                                 │
│  ├─ 公开（6 接口）：AppKey 即可                        │
│  ├─ 商家授权（22 接口）：OAuth 2.0 SessionKey          │
│  ├─ 企业账号（1 接口）：审批 3-7 工作日 ⚠️              │
│  ├─ 增值权限（1 接口）：需购买 CRM 年费 💰              │
│  └─ 天猫专属（6 接口）：天猫店铺授权 1-3 天              │
│                                                     │
│  Layer 3 · 调用配额限制                                │
│  ├─ QPS 瞬时限流：500/秒（企业），超限可退避重试          │
│  └─ 日调用总量：按 API 分类配额，超限直接拒绝 ❌          │
│                                                     │
│  Layer 4 · 沙箱环境限制                                │
│  ├─ QPS 降为 50/秒                                   │
│  ├─ 数据量极少（几条测试数据）                           │
│  └─ 20/37 接口不可用（覆盖率 46%）                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 1.2 应用类型选择决策

| 应用类型 | 认证要求 | QPS 上限 | API 可用范围 | 适用场景 | AOS 推荐 |
|---------|---------|---------|-------------|---------|---------|
| 个人开发者 | 实名认证（身份证 + 人脸） | ≤10 次/分钟 | 仅基础商品查询 | 开发调试 | ❌ 不可用于生产 |
| **自用型** | 企业认证 | 500 次/秒 | 大部分 API（仅接入自有店铺） | AOS 接入自有店铺 | ✅ **首选** |
| 定制型 | 企业认证 + 上架审核 | 500 次/秒 | 需逐个申请权限包 | 给特定商家使用 | 后续扩展 |
| 工具型 | 企业认证 + 服务市场审核 | 500 次/秒 | 需审核 | 多商家 SaaS | 远期 |

**决策结论**：AOS 首期选择**自用型应用**（企业认证），仅接入自有店铺数据。若后续需给其他商家使用，须重新注册为定制型/工具型应用并重新申请权限包。

## 3. 日调用配额

### 3.1 两层限制

| 限制类型 | 说明 | 超限行为 | 可否重试 |
|---------|------|---------|---------|
| **QPS 限制**（500 次/秒） | 瞬时速率 | 返回 `isp.traffic-limit` | ✅ 指数退避重试 |
| **日调用配额** | 每日总量，按 API 分类配额 | 返回 `isp.ratelimit-exceed` | ❌ 直接拒绝，次日恢复 |

### 3.2 全量拉取预算估算（万级 SKU 店铺）

| 数据域 | API 调用次数估算 | 日配额是否够 | 策略 |
|--------|---------------|-----------|------|
| 商品全量 | ~50 次（200 条/页 × 50 页） | ✅ 够 | 单次全量可完成 |
| 订单全量（30 天） | ~300 次（100 条/页 × 300 页） | ✅ 够 | 按时间窗口分批 |
| 订单详情（fullinfo） | ~3000 次（每单 1 次） | ✅ 够但需企业权限 | ⚠️ 阻塞在权限审批 |
| 会员全量 | ~100 次（100 条/页 × 100 页） | ✅ 够但需 CRM 增值包 | ⚠️ 阻塞在付费 |

### 3.3 分批拉取策略

| 数据域 | 数据量级 | 单次返回 | 分批策略 | 断点续传字段 |
|--------|---------|---------|---------|------------|
| 商品 | 万级 SKU | 200 条/页 | `page_no` 分页，每批 200 条，间隔 200ms | `last_page_no` |
| 订单 | 千-万级/日 | 100 条/页 | 时间窗口分批（每 15 分钟增量，每批 1 小时数据） | `last_modified` |
| 会员 | 千-万级 | 100 条/页 | 每 1 小时全量分页 | `last_page_no` |
| 物流轨迹 | 实时 | 单条 | On-Demand 调用（不落 Dataset） | — |

## 4. 沙箱能力边界

### 4.1 沙箱 vs 生产对比

| 能力 | 沙箱环境 | 生产环境 |
|------|---------|---------|
| QPS | 50 次/秒 | 500 次/秒 |
| 数据量 | 极少（几条测试数据） | 全量 |
| OAuth 连通性 | ✅ 可验证 | ✅ |
| 签名正确性 | ✅ 可验证 | ✅ |
| `taobao.item.get` | ✅ 可用 | ✅ |
| `taobao.items.onsale.get` | ✅ 可用（数据少） | ✅ |
| `taobao.trades.sold.get` | ✅ 可用（数据少） | ✅ |
| `taobao.trade.fullinfo.get` | ❌ **不可用** | 需企业权限 |
| `taobao.crm.members.get` | ❌ **不可用** | 需增值包 |
| `tmall.item.schema.*` | ❌ **不可用** | 需天猫授权 |

### 4.2 沙箱覆盖率明细

| API 分类 | 沙箱可用 | 不可用 | 不可用接口编号 |
|---------|---------|--------|-------------|
| 商品读 | 5 | 0 | — |
| 商品写 | 0 | 3 | #8 #9 #10 |
| 订单读 | 4 | 1 | #13 |
| 订单写 | 0 | 1 | #15 |
| 物流读 | 3 | 0 | — |
| 物流写 | 0 | 2 | #19 #20 |
| 会员 | 0 | 1 | #22 |

## 5. 收费明细策略

### 5.1 收费体系总览

| 收费项 | 是否收费 | 说明 | 价格 | AOS 是否需要 |
|--------|---------|------|------|-------------|
| 注册开发者账号 | **免费** | 实名认证即可 | ¥0 | ✅ 需要 |
| 创建自用型应用 | **免费** | 企业认证后创建 | ¥0 | ✅ 需要 |
| 基础 API 调用（36/37 接口） | **免费** | 有 QPS + 日配额限制 | ¥0 | ✅ 需要 |
| CRM 增值权限包 | **付费** | `crm.members.get` 所需 | 年费（需联系阿里商务，未公开标价） | ❌ Phase 1 不需要 |
| 聚石塔（电商云） | **付费** | 阿里云电商云工作平台 | 按资源使用量计费 | ❌ 非必须，AOS 自有部署 |
| 上架服务市场 | **佣金** | 作为 ISV 上架服务市场分发 | 按交易额抽佣 | ❌ 后期考虑 |
| 企业认证 | **免费** | 需企业营业执照 | ¥0 | ✅ 需要 |
| OAuth 2.0 Token 管理 | **免费** | Token 自动续期 | ¥0 | ✅ 需要 |

### 5.2 关键结论

> **AOS 首期方案（自用型应用 + 基础 API）= 完全免费**

| 阶段 | 使用范围 | 费用 | 说明 |
|------|---------|------|------|
| **Phase 1** | 自用型应用 + 36 个免费 API | **¥0** | 商品/订单/物流/店铺/评价/类目 全覆盖 |
| **Phase 2** | 补齐 CRM 会员域 | **年费**（需联系商务） | 仅 `crm.members.get` 1 个接口 |
| **后期** | 上架服务市场给其他商家 | **佣金** | 按交易额抽佣，模式变更 |
| **可选** | 聚石塔部署 | **按量计费** | 非必须，AOS 可自有部署 |

### 5.3 收费影响分析

```
AOS 接入成本 = 注册费(¥0) + 应用创建费(¥0) + API 调用费(¥0) + 权限包费(¥0)
            = ¥0

后续扩展成本 = CRM 增值包(年费?) + 聚石塔(按量?) + 服务市场佣金(抽佣%)
            = 待商务洽谈确认
```

**风险提示**：
- CRM 增值包年费**未公开标价**，需联系阿里商务单独洽谈
- 聚石塔费用取决于服务器规格，非必须
- 服务市场佣金比例取决于应用类型和合作模式
- **以上价格信息基于公开资料推演，实际以阿里商务报价为准**
