# 淘宝/天猫 · 端到端接入详解

> **版本**：v1.0 · 2026-07-23
> **参照**：`000-电商平台接入总方案.md` Stage 1-6 框架
> **定位**：国内 REST API 接入的**首个适配平台**（Phase 1），验证 REST API Connector + HMAC 签名能力
> **依赖**：G1（REST API Connector）+ G6（HMAC-SHA256 签名）

## Stage 1 · 数据接入（Data Connection）

### 1.1 连接器配置

| 项 | 配置 |
|----|------|
| 连接器类型 | **REST API Connector**（AOS 新增类型） |
| 网关地址 | `https://gw.api.taobao.com/router/rest` |
| 认证方式 | **OAuth 2.0** → `app_key` + `access_token`（SessionKey） |
| 签名算法 | **HMAC-SHA256**（参数首字母排序 + 拼接 secret → MD5 → 大写 32 位） |
| 数据格式 | JSON（`format=json`） |
| 速率限制 | 500 QPS（需报备），沙箱 50 QPS |
| 分页方式 | `page_no` + `page_size`（默认 40 页） |
| 时间戳要求 | `timestamp` 与服务器差值 ≤ 5 分钟 |

### 1.2 TOP API 签名流程

```
1. 收集所有请求参数（method, app_key, session, timestamp, format, v, sign_method, ...业务参数）
2. 参数名首字母升序排列
3. 拼接：key1value1key2value2...keyNvalueN
4. 前后追加 app_secret：secret + 拼接串 + secret
5. MD5 → 大写 32 位 → sign 参数
6. POST 到 gw.api.taobao.com/router/rest
```

### 1.3 Source 创建

```
Step 1 · 选择类型：REST API（自定义连接器 → 淘宝 TOP 模板）
Step 2 · 连接方式：直连（API 网关）
Step 3 · 命名：prod-rest-taobaotmall
Step 4 · 配置：
  App Key: ****
  App Secret: ****
  Access Token: ****（OAuth 授权码）
  网关: https://gw.api.taobao.com/router/rest
  API 版本: 2.0
```

### 1.4 淘宝 vs 天猫 API 差异

| 功能 | 淘宝 C 店 | 天猫品牌店 | 合并策略 |
|------|----------|-----------|----------|
| 商品发布 | `taobao.item.add`（field-level） | `tmall.item.schema.add`（XML 规范） | 读操作共用，写回后置 |
| 商品查询 | `taobao.item.get` | **共用** | ✅ |
| 订单查询 | `taobao.trades.sold.get` | **共用** | ✅ |
| 物流 | `taobao.logistics.*` | **共用**（菜鸟统一） | ✅ |

**结论**：读操作（同步到 AOS）完全一致，差异仅在商品写回（后置）。

|----------|---------|------|

## Stage 2 · 数据同步（Sync）

### 2.1 同步策略

| 数据域 | API | 事务类型 | 增量方式 | 调度 |
|--------|-----|----------|----------|------|
| **订单** | `taobao.trades.sold.get` | APPEND | `start_create` + `end_create` 时间窗 | **每 15 分钟** |
| 商品 | `taobao.items.onsale.get` | SNAPSHOT | 全量覆盖 | 每 6 小时 |
| 会员 | `taobao.crm.users.get` | APPEND | `page_no` 分页全量 | 每 1 小时 |
| 物流 | `taobao.logistics.trace.search` | APPEND | 按订单号查询 | 每 30 分钟 |
| 退款 | `taobao.refunds.receive.get` | APPEND | `start_modified` | 每 30 分钟 |

### 2.2 订单同步 SQL 等效查询

```
API: taobao.trades.sold.get
参数:
  status: TRADE_NO_CREATE_PAY（未付款）
  start_create: 2026-07-23 00:00:00
  end_create:   2026-07-23 14:30:00
  page_no: 1
  page_size: 100
  use_has_next: true
  fields: tid,status,payment,post_fee,buyer_nick,created,pay_time,
          end_time,modified,shipping_type,receiver_name,receiver_mobile,
          orders.title,orders.num,orders.price,orders.sku_id,...
```

### 2.3 限流与分页处理

- **分页**：`use_has_next=true` + `has_next` 字段判断是否有下一页
- **限流**：500 QPS → AOS Connector 内置令牌桶限流
- **重试**：`error_code=isp.traffic-limit` → 指数退避重试
- **沙箱**：TOP 沙箱限制（数据量少、QPS 低），仅用于连通性验证

## Stage 3 · 管道清洗（Pipeline Builder）

### 3.1 TOP 返回 JSON → Dataset 列映射

| TOP 字段 | Dataset 列 | Cast | 说明 |
|----------|-----------|------|------|
| `tid` | `order_id` | STRING | 交易编号 |
| `payment` | `amount` | DECIMAL(12,2) | 实付金额 |
| `post_fee` | `shipping_fee` | DECIMAL(12,2) | 运费 |
| `status` | `status` | ENUM | TRADE_FINISHED→completed 等 |
| `created` | `created_at` | DATETIME | 下单时间 |
| `pay_time` | `paid_at` | DATETIME | 支付时间 |
| `buyer_nick` | `buyer_nick` | STRING | 买家昵称（匿名） |
| `orders[].num` | `item_count` | INTEGER | 商品总件数 |
| `receiver_city` | `city` | STRING | 收货城市 |

### 3.2 状态枚举映射（Expression 组件）

```
CASE status
  WHEN 'TRADE_NO_CREATE_PAY' THEN 'pending'      -- 待付款
  WHEN 'WAIT_SELLER_SEND_GOODS' THEN 'paid'      -- 待发货
  WHEN 'SELLER_CONSIGNED_PART' THEN 'partial_ship' -- 部分发货
  WHEN 'WAIT_BUYER_CONFIRM_GOODS' THEN 'shipped'  -- 待确认收货
  WHEN 'TRADE_BUYER_SIGNED' THEN 'delivered'      -- 已签收
  WHEN 'TRADE_FINISHED' THEN 'completed'          -- 交易完成
  WHEN 'TRADE_CLOSED' THEN 'closed'               -- 交易关闭
  WHEN 'TRADE_CLOSED_BY_TAOBAO' THEN 'closed_tb'  -- 淘宝关闭
  ELSE 'unknown'
END AS status_enum
```

### 3.3 天猫 Schema 体系特殊处理

天猫品牌店商品发布使用 **XML Schema 模板**（`tmall.item.schema.*`），而非 field-level API：

- 每个类目有一套独立的 XML Schema 定义
- 商品数据需按 Schema 规则构建 XML
- **AOS 消费策略**：读操作（同步）不受影响；写回（商品发布）后置到 W4+

## Stage 4 · OKF 映射（Funnel）

### 4.1 OT 映射表

| TOP 对象 | 统一 OT | 主键 | 关键映射 |
|----------|---------|------|----------|
| `Trade`（交易） | **Order** | `tid` | payment→amount, status→status_enum |
| `Trade.Order`（子订单） | **OrderLine** | `oid` | num→quantity, price→unit_price |
| `Item` | **Product** | `num_iid` | title→name, price→price, nick→seller |
| `Item.Sku` | **ProductVariant** | `sku_id` | properties→spec, quantity→stock |
| `CrmUser` | **Customer** | `buyer_id` | buyer_nick→nick, grade→level |
| `Refund` | **AfterSales** | `refund_id` | status→refund_status, refund_fee→amount |
| `Logistics` | **Shipment** | `out_sid` | company_name→carrier, out_sid→tracking_no |
| `Shop` | **Shop** | `sid` | nick→name, title→title |

### 4.2 Funnel 状态机

```
TRADE_NO_CREATE_PAY → WAIT_SELLER_SEND_GOODS → SELLER_CONSIGNED_PART → WAIT_BUYER_CONFIRM → TRADE_BUYER_SIGNED → TRADE_FINISHED
                                          ↘ refund → TRADE_CLOSED
```
