## 一、平台定位与特色

### 1.1 定位：公域会员运营主战场

淘宝是中国最大的公域电商平台，核心定位是**公域流量运营 + 会员资产沉淀**。与私域（微商城）的核心差异在于：

| 维度 | 私域（微商城） | 公域（淘宝） |
|------|-------------|------------|
| **流量来源** | 企微好友、社群、朋友圈（免费自有） | 搜索、推荐、直通车、聚划算（付费购买） |
| **客户资产** | 企微好友（可反复触达） | 平台会员（受平台规则约束） |
| **触达方式** | 主动 1V1 企微消息 | 被动等客户上门 + 平台站内信/短信 |
| **运营重点** | 客情维护 + 复购唤醒 | 拉新引流 + 转化提升 + 会员沉淀 |
| **数字同事** | 私域管家 + 导购顾问 | 导购顾问 + 活动策划师 + 数据参谋 |

### 1.2 淘宝平台 6 大特色

淘宝平台相对于其他 8 个平台的独有特色：

```
┌─ 淘宝平台 6 大特色 ──────────────────────────────────────┐
│                                                          │
│  ① 直通车 ───── 搜索关键词竞价推广，公域流量入口              │
│  ② 万象台 ───── 全场景智能投放（搜索/推荐/首页/购后）         │
│  ③ 生意参谋 ─── 官方数据分析 BI，核心指标权威来源             │
│  ④ 微淘 ─────── 店铺私域内容阵地，粉丝运营主渠道              │
│  ⑤ 逛逛 ─────── 平台级内容社区，种草转化新引擎                │
│  ⑥ 聚划算 ───── 平台级活动IP，百亿补贴/天天特卖/品牌团        │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 1.3 淘宝 vs 天猫的核心差异（同属阿里系）

| 维度 | 淘宝 | 天猫 |
|------|------|------|
| **店铺类型** | C 店 + 企业店 | 品牌旗舰店/专卖店/专营店 |
| **活动IP** | 聚划算天天特卖 | 聚划算品牌团 + 天猫超级品牌日 |
| **推广工具** | 直通车标准版 | 直通车专业版 + 品牌专区 |
| **会员体系** | 淘宝会员（淘气值） | 天猫会员（88VIP） |
| **数据产品** | 生意参谋标准版 | 生意参谋专业版 + 品牌数据银行 |

#### 3.1.3 数据结构：淘宝会员对象

```typescript
interface TaobaoMember {
  open_id: string;           // 淘宝开放ID
  taobao_user_id: string;    // 淘宝用户ID
  nick: string;              // 淘宝昵称
  taobao_level: number;      // 淘气值（0-4000）
  member_level: "T1" | "T2" | "T3" | "T4";  // 店铺会员等级
  platform_tags: string[];   // 平台官方标签：["高购买力", "母婴人群", "美妆爱好者"]
  custom_tags: string[];     // 自定义标签：["夏季防晒意向", "618召回"]
  rfm_score: {               // RFM 评分
    r_score: number;         // 最近购买（1-5）
    f_score: number;         // 购买频次（1-5）
    m_score: number;         // 购买金额（1-5）
  };
  channels: {                // 触达渠道权限
    inner_message: boolean;  // 站内信（平台限制：每月≤20次/人）
    sms: boolean;            // 短信（会员授权）
    wangwang: boolean;       // 旺旺消息（客户主动联系后7天内）
  };
}
```

#### 3.1.4 触达渠道限制（淘宝规则）

| 渠道 | 限制 | 成本 | 适用场景 |
|------|------|------|---------|
| 站内信 | 每月≤20次/会员 | 免费 | 大促通知、活动提醒 |
| 短信 | 需会员授权 | ¥0.045/条 | 紧急通知、订单物流 |
| 旺旺消息 | 客户主动联系后7天内 | 免费 | 售后、咨询跟进 |
| 直通车投放 | 无限制，按点击付费 | ¥1-10/点击 | 拉新、召回、种草 |
| 万象台投放 | 无限制，按OCPC付费 | 按转化出价 | 全场景智能触达 |

| 差异维度 | 通用版（定义） | 淘宝平台（实例化） |

    │

    ▼

    ▼
淘宝开放平台（返回 XML/JSON）
