# 视觉稿与系统差异清单

> 对比 `docs/palantier/foundry/html/` 视觉稿与 `aos-platform/apps/web/` React 前端
> 日期：2026-07-24

## 一、视觉稿有但系统没有的内容

### 1. 全局深色导航栏（p-nav-global）
- **视觉稿**：左侧 48px 宽深色窄条 `#1A1D29`，含菜单/首页/搜索/通知/历史/项目/应用/数据 8 个图标按钮，底部有帮助/用户图标
- **当前系统**：无此组件
- **状态**：✅ 本次新增

### 2. 菜单分组结构差异
视觉稿的分组比系统更细，以下是视觉稿有但系统未单独分组的：

| 视觉稿分组 | 包含页面 | 系统当前位置 |
|---|---|---|
| **应用程序构建工具** | 画布编辑、模块接口、事件配置、发布入口 | 在"工作台"下 |
| **模型管理** | 模型供应商、模型路由、成熟度楼梯 | 在"AIP 决策引擎"下 |
| **数据源与同步** | 数据连接、边缘代理、同步配置、同步路由、媒体集 | 在"数据集成"下（无同步配置/路由） |
| **管道与数据治理** | 管道构建、管道提案、计划编辑器、搭建、数据集预览、代码库、数据沿袭、数据健康 | 在"数据集成"下 |

### 3. 视觉稿有但系统没有的页面

| 视觉稿页面 | HTML 文件 | 说明 |
|---|---|---|
| 订单管理 | workshop-app-order.html | 业务应用示例（订单管理系统） |
| 同步配置 | sync.html | 同步参数配置页 |
| 同步路由 | sync-routing.html | 同步路由规则配置页 |
| OKF 概览 | okf-funnel.html | OKF 行业漏斗概览页 |

### 4. 顶部栏差异
- **视觉稿**：顶部栏有居中搜索框 + Discard/Save to branch 按钮
- **当前系统**：搜索框在右侧，无 Discard/Save 按钮
- **状态**：✅ 本次对齐（居中搜索框，保留系统原有的右侧操作区）

### 5. 侧边栏折叠按钮
- **视觉稿**：侧边栏右边缘有圆形折叠按钮，折叠后仅显示图标（48px 宽）
- **当前系统**：无此功能
- **状态**：✅ 本次新增

### 6. 分组抽屉式折叠
- **视觉稿**：所有分组标题均可点击折叠/展开，带箭头图标，状态存 localStorage
- **当前系统**：仅"运维交付"分组可折叠
- **状态**：✅ 本次新增（所有分组均可折叠）

## 二、系统有但视觉稿没有的内容（不可丢弃）

以下功能在视觉稿中未体现，但系统已有，**必须保留**：

| 功能 | 路由 | 说明 |
|---|---|---|
| 工作区成员 | /workspace/members | 工作区成员管理 |
| 我的资料 | /settings/profile | 用户个人资料 |
| 组织与加入 | /org/membership | 组织成员管理 |
| 分析建模 | /analytics | Jupyter 分析建模 |
| SaaS 开通 | /apollo/provisioning | SaaS 平台开通 |
| 本地平台 | /settings/local-platform | 本地平台管理 |
| 启停说明 | /settings/ops-start-guide | 运维启停指南 |
| 邀请接受 | /org/invite/:token | 邀请链接接受页 |

**处理方式**：这些功能放入"运维交付"或顶部栏用户菜单中，不在侧边栏主导航中单独显示，但路由保留可访问。

## 三、样式差异总结

| 维度 | 视觉稿（浅色） | 当前系统（深色） | 改造方向 |
|---|---|---|---|
| 默认主题 | 浅色 `#F0F2F5` | 深色 `#020617` | 改为浅色默认 |
| 品牌色 | `#2B6CB0` 深蓝 | `#22d3ee` 青色 | 改为深蓝 |
| 侧边栏宽度 | 260px | 224px | 改为 260px |
| 侧边栏背景 | 白色 `#FFFFFF` | 深色半透明 | 改为白色 |
| 圆角 | 2-4px | 0.5-0.75rem | 改为 2-4px |
| 激活项 | 左侧 3px 蓝竖条 + 浅蓝背景 | 边框 + 背景色 | 改为视觉稿样式 |
| 字体大小 | 13px 为主 | 14px 为主 | 改为 13px |
| 按钮高度 | 32px / 28px(sm) | 约 36px | 改为视觉稿尺寸 |
| 卡片 | 白底 + 1px 边框 + 2px 圆角 | 深色半透明 + 大圆角 | 改为白底小圆角 |
| 表格头 | `#F7FAFC` 背景 + 大写 | 透明 | 改为视觉稿样式 |
| 滚动条 | 6px 细条 | 默认 | 改为视觉稿样式 |
