# AIP-1B 权威 TAOR 执行闭环对账

> 日期：2026-08-11
> 状态：`IMPLEMENTED_GREEN`
> 分支：仅 `aos-platform/m1`
> 正向租户：`org-org / dev-project`

## 1. 本波结果

AIP-1B 已把批准后的 TaskRun 接入 PostgreSQL 权威 TAOR 主链。运行步骤必须依次形成 Think、Act、Verify、Observe 四段不可变证据；Observe 产生的 Artifact 和每步 Checkpoint 均可在刷新或进程重启后从 timeline 回读。

运行控制 start/pause/resume/cancel/rollback 使用 Task/Run 双版本 CAS，且每个写命令以 `Idempotency-Key` 在同 Run 的 Evidence 中保存事务级收据。同键同请求可安全重放，同键不同请求返回冲突。

## 2. 安全和恢复边界

- 双 worker 竞争同一步骤时只有一个有效 lease。
- Act 前崩溃允许安全重领；Act 后租约过期不重放动作，StepRun/TaskRun 进入 `unknown`，Task 进入 `paused`，等待后续 reconcile。
- capabilityRef 未绑定精确 revision 时，Run 在启动前失败关闭。
- 真实组织 `org-org/dev-project` 无法再进入旧 Mock 或创建内存 Automation。
- 旧 demo 仅允许 `dev-org + AIP_DEMO_MOCK_ENABLED=1`，并明确返回 `source=demo`、`nonAuthoritative=true`。
- C1 ResearchJob 已冻结 provider adapter、不可变 manifest、事件 cursor/hash/去重/终态单调及 callback HMAC/nonce/replay-window 契约；没有默认 provider 或隐式 fallback。
