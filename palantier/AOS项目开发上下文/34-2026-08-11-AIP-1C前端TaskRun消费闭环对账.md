## 1. 本波目标

完成 AIP-1 的最后一个子波：让 Logic Canvas 使用唯一前端 SDK 消费 PostgreSQL 权威 Task/Plan/Run/timeline，覆盖七态控制、刷新恢复、浏览器验收和跨租户证据。

## 2. 已实现

- 后端增加 `GET /v1/aip/task-runs?logic_graph_id=...`；按租户 scope 和更新时间倒序发现 Run。
- 新增 `apps/web/src/api/aipTasks/`，严格解析 Task、PlanRevision、TaskRun 和 timeline。
- 新增 `CanonicalTaskRunPanel`，可创建 Task→Plan→精确 hash 批准→queued Run，并控制 start/pause/resume/cancel/rollback。
- 每个控制请求成功后立即回读 timeline；HTTP accepted 不直接冒充最终状态。
- `unknown` 明确显示“结果待对账”，禁用重复动作；失败/取消后的再次执行创建新 Task 链。
- 页面刷新按 Logic Graph ID 从服务端恢复，不把 localStorage 当运行真源。
- Dry-Run 与权威 TaskRun 分栏存在，旧安全试跑不冒充生产执行。
