# ADR-003：权限与职责分离失败关闭

- 状态：Accepted
- 日期：2026-08-03

## 决策

tenant、role、publisher scope、marking 和 maker-checker 全部由服务端权威执行。写场景权限不足明确拒绝；读场景 marking 不足隐藏为 not found；管理员不绕过 marking；提交人与审批人不得相同。

## 影响

- UI 可按已知角色优化按钮，但不能把按钮隐藏视为授权控制。
- 403/404 必须按服务端语义呈现，不能泄漏被 marking 隐藏的资源。
- 审批 UI 展示 hash 供确认，实际一致性仍由服务端校验。
