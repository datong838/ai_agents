# Foundry 数据连接与集成文档镜像方案

> 目标：将 Palantir 官方文档「数据连接与集成」章节（以 overview 页侧栏为范围）完整镜像到本地，保留页面正文、图片与链接关系。

## 1. 范围

| 项 | 说明 |
|---|---|
| 入口 URL | `https://www.palantir.com/docs/zh/foundry/data-integration/overview/` |
| 语言 | 中文（`/zh/`） |
| 页面集合 | 侧栏 `sidebarNavProps` 递归提取，共 **993** 个唯一 URL |
| 覆盖子域 | data-integration、data-connection、hyperauto、available-connectors、pipeline-builder、transforms-* 等（均属「数据连接与集成」TOC） |

## 2. 技术路线

Palantir 文档站为 **Next.js**，正文不在静态 HTML 中，而在 `__NEXT_DATA__` → `props.pageProps`：

| 字段 | 用途 |
|---|---|
| `markdown` | 页面正文（MDX 风格） |
| `docAssetMetadata` | 页面图片资源清单 |
| `pageNeighbours` | 上一页 / 下一页 |
| `sidebarNavProps` | 完整侧栏树（种子 URL） |
| `metadata` | 标题等元数据 |

**不采用** Playwright/浏览器渲染：数据已在 SSR JSON 中，requests 即可。

**依赖**：`requests`、`beautifulsoup4`（仅解析 `__NEXT_DATA__` script 标签）。

## 3. 目录结构

```
docs/palantier/foundry/
├── 00-镜像方案.md          # 本文件
├── scrape_foundry_docs.py  # 爬虫脚本（可重复执行）
├── meta/
│   ├── sidebar-nav.json    # 侧栏树
│   ├── url-index.json      # URL → 本地路径映射
│   ├── link-graph.json     # 链接关系图
│   └── scrape-report.json  # 爬取统计 / 失败列表
├── pages/                  # 按 URL 路径存 .md
│   └── zh/foundry/...
└── images/                 # 图片本地化
    └── foundry/...
```

## 4. 单页处理流程

1. GET `https://www.palantir.com/docs{url_path}`
2. 解析 `__NEXT_DATA__`，提取 markdown / metadata / neighbours / assets
3. 下载 `docAssetMetadata` 及 markdown 内引用的 `/docs/resources/...` 图片
4. 将 markdown 中图片路径改写为相对本地路径 `../../images/...`
5. 写入 frontmatter（source_url、title、prev、next、scraped_at）
6. 从 markdown 提取 `[text](url)` 边，汇入 link-graph

## 5. 链接关系

`link-graph.json` 边类型：

| type | 来源 |
|---|---|
| `sidebar` | 侧栏父子 / 顺序 |
| `prev` / `next` | pageNeighbours |
| `content` | 正文 markdown 链接 |

## 6. 风险与约束

- **速率**：并发 4、间隔 0.25s，避免触发反爬
- **编码**：全程 UTF-8 写文件，规避 Windows GBK 控制台问题
- **幂等**：已存在且 HTTP 200 的页面可 `--skip-existing` 跳过
- **版权**：仅供内部分析学习，保留原始 URL 与 © 声明
