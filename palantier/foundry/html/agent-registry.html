三种来源说明
平台内创建

在对话机器人 Studio 中配置提示词+工具+上下文+安全等级后创建。编辑入口 → 对话机器人

插件引入

通过 Capability Manifest 声明接入的外部能力（C0/C1/C2）。管理入口 → 智能体插件

外部接入

从 awesome-llm-apps 等开源社区导入的 Agent 框架，通过 Adapter（Process Wrapper / MCP Bridge / Docker Container / Session Gateway）桥接。管理入口 → 智能体插件
