接入插件能力（Capability Manifest）

声明外部能力端点和契约，注册为 C0/C1/C2 Capability 供智能体调用。

C0 / C1 / C2 能力分层
C0 sync — 同步函数，<15s，可直接挂 Function
C1 Job — 异步任务，GPU/长耗时，产物写 MediaSet
C2 Session — 实时会话，WebSocket 长连接，AV 流外置

选择能力类型

不同能力类型对应不同的运行时和资源配额

C0 sync
同步函数
超时 < 15s
直接挂 Function Tool
内存限制 512Mi
例：直播稿引擎、文本摘要
C1 Job
异步任务
GPU / 长耗时
submit → status → artifact
产物写 MediaSet
例：短视频生成、图片渲染
C2 Session
实时会话
WebSocket 长连接
open / push / close
AV 流外置
例：数字人交互、语音对话
提示：选择后将在 Step 2 自动预填对应 Manifest 模板。可在 Step 2 修改。

配置 Capability Manifest

填写能力端点、输入输出 Schema、回调地址。右侧实时预览生成的 YAML。

存储于 KMS，运行时注入，不落地

# Capability Manifest — auto-generated apiVersion: v1 kind: Capability metadata: name: short-video-generation displayName: 短视频生成 version: 1.0.0 spec: capabilityLevel: C1 # async Job runtime: endpoint: https://cap.internal/video/v1 secretRef: vault://aip/cap#token healthCheck: /health timeout: 300 interface: input: prompt: string duration: int? output: artifact: MediaSet writeBack: false callback: webhook: https://aos-api/cb/video verify: hmac-sha256 references: - path: references/video-api-spec.pdf - path: references/prompt-guide.md # 运行时按需检索注入上下文
