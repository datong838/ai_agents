任务类型 · 出境 · 预热 · 熔断降级。供应商安装与类型化配置见 大模型接入(插件)。

三层栈式架构定位： L3 已注册模型 L2 模型路由（当前页） L1 模型供应商 本页管理同一逻辑模型的多后端流量分配、熔断和回退。向上为已注册模型提供路由 RID。
本页只选已接入模型做策略；新增 DeepSeek / Azure / 本地机 → 先到供应商页完成接入。
