calculate_tax

输入: Order.amount: Double · 输出: Double

场景 C：派生税额 · 壳核模式被 Action「审核订单」调用 · 无 UI 表单

@Function()
public calculate_tax(order: Order): Double {
  // Schema 编译为 TS 接口 · order.amount 类型安全
  return order.amount * 0.13;
}
