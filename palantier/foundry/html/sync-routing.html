prod-mysql-orders

MySQL 8.0 · agent-prod-1 · 10.0.12.45:3306

可用功能

此源连接支持以下功能。选择"创建"以开始配置新的同步或导出。

批量同步

将表格数据从外部系统同步到 Foundry 数据集。支持 SNAPSHOT 和 APPEND 事务类型，可配置增量同步和计划调度。

SQL 查询 增量 SNAPSHOT/APPEND
创建

流式同步

使用 Kafka 等流式数据源实时同步变更数据到 Foundry 流数据集。

此源类型不支持

虚拟表

通过 Foundry 直接查询源系统的 REST API 端点，无需创建同步任务。适用于 REST API 源类型。

仅 REST API 源

媒体集同步

同步非结构化媒体文件（PDF、图像、音视频）到 Foundry 媒体集进行 AIP 文档智能处理。

此源类型不支持

导出

将 Foundry 数据集的数据导出到外部目标系统。支持全量和增量导出模式。

可用

Webhooks

配置传入 Webhook 端点以接收外部系统的推送通知，实时触发 Foundry 工作流。

仅 REST API 源
