数据绑定

选择本体中的对象类型作为数据源。Module 的 Widget 将通过 Object Set 引用这些数据。

本体对象类型
业务对象
Order（订单）
Product（商品）
Inventory（库存）
RiskAlert（风险告警）
用户对象
Customer（客户）
Supplier（供应商）
Order 属性列表
勾选要展示的属性（自动绑定到 Widget）：
order_id customer_name total_amount status created_at shipping_address payment_method discount_code tax_amount remark
初始过滤条件（选填）
status != "cancelled"
当前用户对 Order 对象有读取权限。写入操作需在创建后通过 Action 配置单独授权。

模板选择

选择起始布局模板，系统将预填充 Widget 和变量。后续可自由增删修改。

空白画布
空白模板
零预填 Widget，完全从零搭建。适合高度自定义场景。
表格列表模板
筛选栏 + 数据表格 + 详情面板。适合 CRUD 管理场景，如订单管理。
仪表盘模板
统计卡片 x4 + 趋势图 + 饼图。适合数据监控和概览场景。
对象探索模板
对象列表 + 属性筛选 + 图表探索 + Actions。适合 Ontology 数据探索。
选中模板将预填充：
1 个 Layout（首页） · 3 个 Widget（FilterBar + DataTable + DetailPanel）
2 个 Variables（all_orders: ObjectSet, selected_order: Object）
1 个 Event（onRowClick → selected_order.setValue）
