# 概述

:::callout{theme="neutral"}
代码仓库的管理需要适当的权限。大多数设置可以由仓库**所有者**（默认）调整。其他选项，如代码编辑器首选项，所有作者都可以使用。
:::

要更改代码仓库的设置，请访问仓库并点击顶部导航栏中的“设置”选项卡。设置选项卡允许您设置个人编辑器首选项以及配置仓库的行为。有关以下设置的更多信息，请参阅：
