# 导航

在使用Artifacts之前，我们建议您熟悉Artifact Repository界面。

Artifact Repositories界面顶部有三个选项卡：

* 搜索
* 发布
* 概览

## 搜索

![AR界面搜索选项卡](../../../images/foundry/code-repositories/ar-ui-search.png)

使用下拉菜单和搜索栏在您的Artifact Repository中搜索Artifacts。点击搜索结果以查看元数据，例如版本历史、大小和创建日期。

## 发布

![AR界面发布选项卡](../../../images/foundry/code-repositories/ar-ui-publish.png)

通过生成词元并按照页面**说明**部分的分步说明，将Artifacts发布到您的Artifact Repository中。

## 概览

![AR界面概览选项卡](../../../images/foundry/code-repositories/ar-ui-overview.png)

查看您的Artifact Repository中所有Artifacts的摘要，包括其资源ID（RID）、创建日期和文件系统中的父文件夹等元数据。
