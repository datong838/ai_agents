# 创建 Artifact 存储库

在您开始发布和管理 Artifact 之前，您需要创建一个用于存储它们的 Artifact 存储库。

要创建一个 Artifact 存储库，首先导航到您希望保存 Artifact 存储库的项目。

然后，选择 **新建** 并选择 **Artifact 存储库**。

<img src="../../foundry-docs/code-repositories/media/ar-create.png" alt ="创建" width="300">

创建 Artifact 存储库后，开始[发布 Artifacts](/zh/foundry/code-repositories/publish-artifact/)。
