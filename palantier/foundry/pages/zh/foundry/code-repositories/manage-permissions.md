# 管理权限

使用Artifact代码库时，请考虑以下权限要求：

* 使用Artifact时，用户必须在Artifact代码库上具有**查看**权限。
* 将Artifact发布到Artifact代码库时，用户必须在Artifact代码库上具有**编辑**权限。
* 撤回Artifact时，用户必须在Artifact代码库上具有**编辑**权限。

:::callout{theme="neutral"}
无法[删除Artifact](/zh/foundry/code-repositories/recall-artifact/#delete)。
:::
