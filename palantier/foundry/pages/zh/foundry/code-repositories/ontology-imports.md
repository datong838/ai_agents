# Ontology 导入

代码库中的 **Ontology** 选项卡用于导入[Object 和链接类型](/zh/foundry/ontology/core-concepts/)，以便在[函数中的 Objects](/zh/foundry/functions/functions-on-objects/)中使用。请参阅函数文档中的[Ontology 导入](/zh/foundry/functions/ontology-imports/)以了解更多信息。
