# 发布制品

要将制品添加到制品库，请按照以下步骤生成词元并查看发布说明：

1. 导航到界面中的**发布**选项卡。

2. 从下拉菜单中选择要发布的制品类型。

   <img src="../../foundry-docs/code-repositories/media/ar-publish-select.png" alt ="选择制品类型" width="300">

3. 点击**生成词元**。

   ![生成词元](../../../images/foundry/code-repositories/ar-publish-generate-token.png)

4. 在词元字段中查看生成的词元。词元字段下的文本将显示词元的有效期。

   ![生成的词元](../../../images/foundry/code-repositories/ar-publish-generated-token.png)

5. （非必填）对于某些制品类型，可以使用参数命令更新发布说明。在**参数**部分的字段中添加命令。

   ![添加参数](../../../images/foundry/code-repositories/ar-publish-param.png)

6. 运行**说明**部分列出的命令以发布制品。

   ![说明](../../../images/foundry/code-repositories/ar-publish-instructions.png)

7. 出现提示时，提供**详情**部分列出的其他信息。

   ![详情](../../../images/foundry/code-repositories/ar-publish-details.png)

现在您已经了解如何发布制品，学习如何[撤回制品](/zh/foundry/code-repositories/recall-artifact/)。
