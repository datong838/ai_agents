# 将同步添加到Marketplace产品 \[测试版]

使用[Foundry DevOps](/zh/foundry/devops/overview/)将您的数据连接同步包含在[Marketplace产品](/zh/foundry/devops/core-concepts/#product)中，以便其他用户安装和重复使用。[了解如何创建您的第一个产品。](/zh/foundry/foundry-devops/create-products/)

## 支持的功能

标准[同步](/zh/foundry/data-connection/set-up-sync/)和[流式同步](/zh/foundry/data-connection/set-up-streaming-sync/)都可以包含在Marketplace产品中。

## 将数据连接同步添加到产品

要将数据连接同步添加到产品中，首先[创建一个产品](/zh/foundry/foundry-devops/create-products/)，然后选择如下的**数据连接**内容类型。

![add data connection](/resources/foundry/data-connection/marketplace-add-data-connection.png)

一旦选择了数据连接源，您可以选择希望在产品中包含的同步。

![add syncs](../../../images/foundry/data-connection/marketplace-add-syncs.png)
