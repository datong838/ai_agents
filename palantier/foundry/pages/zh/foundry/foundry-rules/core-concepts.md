# 概述

有几个基本概念对于Foundry Rules至关重要：

* **[Object模型](/zh/foundry/foundry-rules/object-model/)：** Foundry规则是具有**属性**的**Objects**，可以通过**规则提案**进行管理。
* **[Workshop应用程序](/zh/foundry/foundry-rules/workshop-application/)：** Foundry规则由**Workshop应用程序**管理，通常包括**规则编辑器**和**提案审阅器**功能。
* **[规则逻辑](/zh/foundry/foundry-rules/rule-logic/)：** Foundry规则编码旨在执行[特定工作流程](/zh/foundry/foundry-rules/overview/#example-use-cases)的业务逻辑。此逻辑遵循特定结构，并定义了一组数据变换。
* **[Foundry Rules工作流程配置](/zh/foundry/foundry-rules/foundry-rules-workflow-configuration/)：** 使用工作流程配置编辑器配置Foundry规则。编辑器是工作流程所有者用来将Foundry Rules定制到他们的应用案例的界面。

在2022年7月之前，Foundry Rules包含了额外的概念并需要更多配置。如果您在此日期之前部署了Foundry Rules，请了解这些[额外概念和配置](/zh/foundry/foundry-rules/legacy-foundry-rules-setup-taurus/)。
