# 对Object发表评论

多个用户经常处理特定的Object。为了促进这种合作，Object Explorer允许用户对Object发表评论，提及其他用户，并附加文件和图像。

您可以使用任何Object视图标题中的**查看评论**按钮打开任何Object的评论助手。

![评论](../../../images/foundry/object-views/comments_in_helper.png)

Object Explorer对Object的评论*不*与[Workshop中的评论微件](/zh/foundry/workshop/widgets-comments/)相关。
