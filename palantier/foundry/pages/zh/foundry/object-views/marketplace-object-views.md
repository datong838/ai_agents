# 添加Object视图到Marketplace产品 \[Beta]

使用[Foundry DevOps](/zh/foundry/devops/overview/)将您的Object视图包含在[Marketplace产品](/zh/foundry/devops/core-concepts/#product)中，以便其他用户安装和重复使用。[了解如何创建您的第一个产品。](/zh/foundry/foundry-devops/create-products/)

## 支持的功能

Marketplace产品仅支持使用[Workshop标签](/zh/foundry/object-views/config-workshop-tabs/)搭建器的[Object视图标签](/zh/foundry/object-views/config-tabs/)。不支持旧版Object视图搭建器。如果您想打包利用旧版搭建器的Object视图标签，您应首先使用Workshop标签搭建器重新搭建该标签。

## 将Object视图添加到产品中

要将Object视图添加到产品中，首先[创建一个产品](/zh/foundry/foundry-devops/create-products/)，然后选择如下所示的**Object视图**内容类型。

![add object view](/resources/foundry/object-views/marketplace-add-object-view.png)

选择Object视图后，您可以选择要包含在产品中的标签。

![add tabs](../../../images/foundry/object-views/marketplace-add-tabs.png)
