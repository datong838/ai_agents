# 创建分支

要创建分支，导航到顶部工具栏并点击分支下拉菜单；在创建新的管道工作流后，您将默认处于**主**分支。在下拉菜单中，点击**创建新分支**。

![分支选择下拉菜单的截图](../../../images/foundry/pipeline-builder/branches-new@2x.png)

在**创建分支**窗口中，为您的分支命名，并选择使用自动生成的Foundry分支名称或重命名它。数据集输入将使用此Foundry分支或主分支进行读取（如果不存在）。

![分支选择下拉菜单的截图](../../../images/foundry/pipeline-builder/create-branch-prompt@2x.png)

点击**创建**以复制**主**分支的当前状态，并从新分支开始工作。您可以通过分支下拉菜单导航到其他分支。
