# 源探索

一旦[源已创建](/zh/foundry/sap/sap-source-setup/)，可以使用SDDI SAP源探查器进行交互式源探索。请注意，以下截图中的所有数据都是假设性的。

1. 导航到源并选择**探索和创建同步**按钮。

![Explore SAP Source](../../../images/foundry/sap/sap-source-explore.png)

2. 对于远程和SLT连接，选择适当的上下文。

![SAP Explorer Landing](../../../images/foundry/sap/sap-explorer-landing.png)

3. 选择感兴趣的表或模块并将它们添加到图中。

![SAP Explorer Graph](../../../images/foundry/sap/sap-explorer-graph.png)

4. 继续[配置同步](/zh/foundry/sap/sap-sync-setup/)。
