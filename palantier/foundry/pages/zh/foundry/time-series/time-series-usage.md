# 在 Foundry 中使用时间序列

一旦您的[时间序列设置](/zh/foundry/time-series/time-series-setup/)完成后，使用时间序列 Object 类型在以下列出的 Foundry 应用程序中创建可视化和分析。

[Quiver](/zh/foundry/quiver/timeseries-overview/)：创建互动的时间序列仪表盘和分析。下面的示例展示了机器温度读数随时间变化的分析。

![quiver 示例](../../../images/foundry/time-series/time-series-usage-quiver.png)

[Workshop](/zh/foundry/workshop/time-series-properties/)：以时间序列地图、图表和指标卡片搭建高质量的互动应用程序。

![workshop 示例](../../../images/foundry/time-series/time-series-usage-workshop.png)

[Vertex](/zh/foundry/vertex/explore-time-series/)：与时间序列互动，以可视化系统中的变化，并进行深入分析，以查看过去决策的影响、探索当前状态及识别未来潜力。

![vertex 示例](../../../images/foundry/time-series/time-series-usage-vertex.png)

[Foundry Rules](/zh/foundry/foundry-rules/timeseries-concepts/)：编写规则以识别数据中感兴趣的时间段。

![foundry rules 示例](../../../images/foundry/time-series/add_timeseries.png)

[Map](/zh/foundry/map/time-series/)：查看和分析与地理空间 Object 相关联的时间序列数据。下面的示例中，飞机传感器读数与地图一起显示，展示了读数发生的位置。

![选择面板的系列选项卡](../../../images/foundry/time-series/time-series-tab.png)
