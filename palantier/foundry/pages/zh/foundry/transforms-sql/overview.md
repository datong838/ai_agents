# 概述

**SQL** 是在 Foundry 中进行数据变换时最容易使用的语言，同时由于 Spark SQL 的表达能力，可以实现多种高级数据操作模式，包括筛选、聚合、推导和窗口函数。

通过[简单批处理管道教程](/zh/foundry/building-pipelines/create-batch-pipeline-cr/)以代码库中的 SQL 变换入门，或探索 [Spark SQL 参考](/zh/foundry/transforms-sql/spark-reference/)。请注意，Foundry 不支持 SQL 中的增量变换。
