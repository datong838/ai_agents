## 三、湃肽专属实体映射（知识网本体）

### 3.1 节点类型（Objects → 神经元）

| 节点类型 | 湃肽业务示例 |
|----------|--------------|
| `document` | 工艺卡片、实验记录、专利全文、法规标准 |
| `section` | 纯化步骤段、合成路线段、失败案例段 |
| `concept` | 氨基酸序列、树脂类型、保护基、脱除条件、梯度、收率、杂质谱 |
| `media` | HPLC 色谱图、质谱图、电镜图 |
| `experiment` | 批次实验（序列+参数+结果三元组） |
| `molecule` | 目标多肽 / 环肽 / 修饰肽 |

### 3.2 边类型（Links → 突触）

| 边类型 | 生物别名 | 湃肽语义 |
|--------|----------|----------|
| `contains` | 胞体-胞突 | 文档→段落→谱图 |
| `references` | 短程突触 | 段落引用色谱图 |
| `mentions` | 语义树突簇 | 段落提及「聚集物控制」 |
| `similar_to` | 长程髓鞘 | 相似序列/相似工艺 |
| `leads_to` | 因果轴突 | 参数→收率/纯度 |
| `failed_with` | 抑制突触 | 失败路径（弱化传播） |

### 3.3 技能（Actions → 可触发操作）

| 技能 | 触发场景 |
|------|----------|
| 纯化参数推荐 | 输入序列 → 推荐柱型/梯度/流速 |
| 合成路线选型 | 长肽/环肽 → 分段 vs 全长 |
| 失效诊断 | 收率低/新杂质 → 排查清单 |
| 文献/工艺检索 | 对话式 RAG + meta-path 扩散 |
| 实验方案生成 | 基于相似成功案例生成草案 |

## 四、核心 meta-path（PPR 扩散模板）

| 模板 | 路径 | 业务语义 |
|------|------|----------|
| MP-P1 | concept → section ← experiment | 问「环肽纯化失败」命中多批次 |
| MP-P2 | section → media → experiment | 谱图反查工艺 |
| MP-P3 | molecule → similar_to → experiment | 相似结构工艺迁移 |
| MP-P4 | experiment → leads_to → concept | 参数-结果因果链 |
| MP-P5 | experiment → failed_with → concept | 失败模式警示 |

## 五、分期实施（最小风险）

| 阶段 | 周期 | 范围 | 验收 |
|------|------|------|------|
| **POC** | 8–10 周 | 1 个品种（如环肽化妆品原料）+ 历史工艺卡片 500 份 | 图谱可浏览；对话检索 Top-3 命中 |
| **试点** | 3–6 月 | 纯化选型智能体 + 3 条 meta-path | 新人培训场景可用；专家采纳率 >60% |
| **推广** | 6–12 月 | 全管线 + 实验数据自动回流 | 干湿闭环；边权可塑更新 |

## 六、风险与边界

| 风险 | 缓解 |
|------|------|
| 数据敏感（cGMP/FDA） | 私有化部署；湃肽数据不出域 |
| 专家不信任 AI | Human-in-the-Loop；每条建议附来源 |
| 幻觉 | 知识网约束 + 仅沿 meta-path 扩散 |
| 过度工程 | POC 单品种验证；RAG 优先，不盲目微调 |
