## 1. 一句话定位

谛听知识网今天已经实现了 **BGE（感官编码）+ ANN（快速感知定位）+ PPR（神经扩散 / 记忆激活）**——工程上相当于一个**仿生中枢神经系统的原型**。

但它还缺两样东西，所以仍是「聪明的数据库」，不是「会学习的小动物」：


| 缺失     | 生物学对应           | 工程对应                            |
| ------ | --------------- | ------------------------------- |
| **基因** | 基因组决定脑结构先验、本能行为 | Schema + 初始化边权 + meta-path 禁止规则 |
| **身体** | 行动改变环境、反馈改变大脑   | Action → Feedback → 突触可塑性闭环     |


**BDNS（ Bio-Digital Nervous System）** 就是把这两块补上，把现有系统升级成 **生物数字自主进化智能体（BDAEA）**——有基因、有感官、有反射、有本能、会思考、会犯错、会从错误中学习。

```text
BDAEA = BDNS（神经系统架构） × OKF/Wiki（知识基因组表达） × WorkBuddy（行动器官）
```

## 2. 现状诊断：已有「皮层 + 丘脑」，缺「基因 + 身体」

### 2.1 工程组合（图 1 · 当前已实现）


| 缩写      | 工程含义                                  | 系统角色        | 现状                    |
| ------- | ------------------------------------- | ----------- | --------------------- |
| **BGE** | BAAI General Embedding（通用语义编码）        | 感官编码层       | ✅ BGE-M3 嵌入 Chroma    |
| **ANN** | Approximate Nearest Neighbor（近似最近邻检索） | 快速感知定位      | ✅ ANN 种子节点            |
| **PPR** | Personalized PageRank（个性化 PageRank）   | 神经扩散 / 记忆激活 | ✅ `ann_then_ppr` 生产默认 |


**关键洞察（图 1）：**

> 你的系统本质上已经是「仿生中枢神经系统的工程实现」，但还没有给它「基因」和「身体」。

### 2.2 仿生组合（图 2 · 目标解释框架）

在仿生 / 计算神经科学视角，更合理的三元组是 **EGB + ANN + PPR**：


| 缩写      | 仿生含义                                                                                   | 对应生物结构             |
| ------- | -------------------------------------------------------------------------------------- | ------------------ |
| **EGB** | Evolutionary Genetic Brain（进化基因脑）/ Embodied Genetic Brain（具身基因脑）                       | 基因组 + 发育规则 → 脑结构先验 |
| **ANN** | Artificial Neural Network（人工神经网络）                                                      | 大脑皮层 / 神经元集群       |
| **PPR** | Parallel Pattern Recognition（并行模式识别）/ Physiologically Plausible Representation（生理合理表征） | 丘脑-皮层环路 / 并行感知通路   |


**EGB + ANN + PPR** 描述的是：

> 一个由**基因预设结构**、由**神经网络并行处理信息**、按**生理合理方式表征世界**的生物大脑。

### 2.3 两套组合如何叠合

```text
工程视角          仿生视角           我们已有        我们缺失
────────          ────────           ────────        ────────
BGE（编码）   →   感官输入           ✅              多模态扩展
ANN（检索）   →   皮层并行计算       ✅              感知门控
PPR（扩散）   →   模式激活/记忆召回  ✅              三层回路
（无）        →   EGB（基因脑）      ❌              Schema + 先天边权
（无）        →   身体/环境闭环      ❌              Action → Feedback
```

### 3.2 第一层：基因层（EGB）

**定义「数字生命」的先天结构。**


| 组件              | 工程映射                         | 说明                          |
| --------------- | ---------------------------- | --------------------------- |
| **Schema 基因模板** | `OKF_ECOM.md` · 节点/边 type 枚举 | 定义合法实体关系约束、领域本体知识结构         |
| **边权先天偏好**      | Compile 初始化 `weight`         | 强化重要连接权重；禁止某些硬编码路径          |
| **结构可塑性基因**     | `props_json` 可塑性参数           | 突触生长/修剪阈值、学习率、记忆衰减          |
| **基因表达引擎**      | Ingest + Graph Compile       | 实例化知识模式、引导 meta-path、生成本能响应 |


**与 OKF 关系：** Layer 2 OKF Bundle 是基因的表达产物；`schema/OKF_ECOM.md` 是基因组序列。

### 3.3 第二层：感知层（ANN）

**多模态并行编码与检索。**


| 通道           | 编码器                   | 功能                 |
| ------------ | --------------------- | ------------------ |
| **文本编码通道**   | BGE-M3                | 向量化、分句、分词          |
| **图像编码通道**   | CLIP / SigLIP         | 向量空间对齐、视觉特征提取      |
| **化学结构通道**   | ChemBERTa / MolFormer | SMILES 编码、分子指纹     |
| **ANN 检索引擎** | HNSW · Chroma         | Top-K 种子召回、向量语义门控  |
| **丘脑中继门控**   | Thalamus Router（待建）   | 任务类型判断、模态权重分配、资源调度 |


**数据流：** 多通道并行编码 → ANN 检索召回种子节点 → 丘脑门控决定哪些模态参与下游扩散。

**右侧虚线（感知层 → 思考层）：** 「感知信号 → 皮层输入」——感官数据馈入深度推理层。

---

### 3.4 第三层：反射层（PPR）

**毫秒级响应与神经扩散。**


| 回路           | 延迟     | 机制                                       | LLM   |
| ------------ | ------ | ---------------------------------------- | ----- |
| **反射回路**     | ms 级   | 固定 meta-path；无 LLM；缓存直接返回                | ❌     |
| **本能回路**     | ~100ms | 高权重边扩散；轻量 Skill（如查常见杂质）                  | 模板/轻量 |
| **PPR 有向扩散** | —      | 随机游走权重传播；阻尼因子；种子节点激活                     | —     |
| **突触可塑性引擎**  | —      | Hebbian Learning：成功路径 ↑、失败路径 ↓；动态修剪/生长调度 | —     |


**右侧虚线（基因层 → 反射层）：** 「结构先验 → 扩散约束」——Schema 与先天边权约束 PPR 可走的路径。

**与现有实现对齐：** 当前生产 `ann_then_ppr` 覆盖本能层 + 部分思考层入口；反射缓存与 Hebbian 批处理为 Stage 3–4 待建项。

---

### 3.5 第四层：思考层（Cortex）

**多跳推理与规划决策。**


| 模块                | 功能                                                                         | 谛听对应                                    |
| ----------------- | -------------------------------------------------------------------------- | --------------------------------------- |
| **LLM Planner**   | CoT 推理链、行动计划、因果推断                                                          | `llm` 阶段 · 可切换模型                        |
| **Skill 编排器**     | 并行 Skill 调度、工具链调用、外部 API                                                   | WorkBuddy Orchestrator · `agent_skills` |
| **Meta-Path 约束器** | 语义路径模板（MP1 任务分析 / MP2 逻辑推理 / MP3 同益推理）                                     | meta-path 白名单 · 入库方案 §十四                |
| **知识网记忆中枢**       | document / section / concept / media 节点；mentions / contains / references 边 | Layer 3 知识网 Graph · Chroma + SQLite     |


**数据流：** 反射/本能层未命中 → 思考层接管 → LLM Planner 生成推理链 → Skill 编排器并行执行 → Meta-Path 约束保证路径合法 → 知识网提供记忆上下文。

### 3.6 第五层：身体反馈层（Body Loop）

| 组件             | 功能                           | 场景示例                      |

| **记忆回写引擎**     | 更新边权（可塑性）、动态插入新节点、知识库持续进化    | 突触可塑性批处理；OKF Synthesis 回写 |

### 3.7 LIFE LOOP — 生命闭环

 **LIFE LOOP** 箭头从第五层反馈回第一层基因，形成完整生命循环：

```text
感知（L2）→ 反射（L3）→ 思考（L4）→ 行动（L5）
                                              │
                                              ▼
                                        环境 / 湿实验
                                              │
                                              ▼
                                        反馈采集器
                                              │
                                              ▼
                                        记忆回写引擎
                                              │
                    ┌─────────────────────────┘
                    │  LIFE LOOP（红色闭环 ↑）
                    ▼
              基因层更新（L1）
              · 边权先天偏好微调
              · 结构可塑性参数演化
              · 新 Concept 写入 OKF Bundle
```

**生物学对应：** 行为改变环境 → 环境反馈改变大脑（神经可塑性）→ 基因表达（表观遗传）随之调整。

**工程对应（M7-3 §7 + M7-3a §7）：**

```text
skill_output / Action
   → 环境反馈（成交/实验结果）
   → knowledge_edges.props_json.weight ±Δ
   → 可选：Layer 2 Synthesis Concept 回写
   → Graph Compile（增量）
   → 下一轮 Query 自动变准
```

> 对应图 3 · 把工程组合与仿生组合叠合，明确升级方向。


| 仿生组合            | 工程组合      | 本质功能          | 当前状态 | 升级方向                      |

**结论：**

```text
你现在有「皮层 + 丘脑」的原型；
缺的是「基因组（EGB）」和「身体/环境闭环」。
```

### 🟢 Stage 1：补全 EGB —— 给智能体植入「基因」

#### 生物学原型

- 基因组决定神经连接的大致框架（如视觉皮层一定在枕叶）
- 本能行为（呼吸、眨眼、恐惧）由基因硬编码

#### 工程实现


| 工程动作                           | 生物学对应      | 落地位置                                                              |
| ------------------------------ | ---------- | ----------------------------------------------------------------- |
| **Schema = 基因**                | 基因组序列      | `knowledge/schema/OKF_ECOM.md` + 入库方案 §十四                         |
| 定义节点/边合法组合                     | 发育规则       | `concept → mentions → section` ✅；`section → contains → concept` ❌ |
| **初始化边权 = 先天偏好**               | 本能连接强度     | Compile 时写入 `knowledge_edges.weight`                              |
| `mentions` 初始权重 > `references` | 功效联想强于文献引用 | 美妆：功效→商品；多肽：序列→修饰位点 > 序列→作者                                       |
| **禁止规则 = 本能抑制**                | 脊髓抑制通路     | meta-path 白名单；某些路径永不参与扩散                                          |
| 例：实验结果 → 无关法规                  | 跨域跳跃抑制     | `evaluate → regulatory` 禁止                                        |


#### 与 OKF 的衔接

```yaml
# OKF_ECOM.md 扩展（Stage 1 建议新增）
diting.gene:
  edge_prior:
    mentions: 1.0
    appears_in: 0.8
    references: 0.5
    contains: 0.9
  forbidden_meta_paths:
    - [evaluate, regulatory]
    - [media, compliance]
```

#### ✅ 效果

智能体一「出生」，就有一个符合领域常识的脑结构，**不是白纸**。

#### 验收标准

- `OKF_ECOM.md` 含边权先验表 + 禁止 meta-path 表
- Compile Job 按先验初始化 `weight`
- PPR 扩散日志可显示「被禁止路径」拦截记录

### 🟢 Stage 2：升级 ANN —— 从「单通道感知」到「多感官并行」

#### 生物学原型

- 视觉、听觉、触觉、嗅觉并行输入
- 丘脑负责「路由」，决定哪些信号送到皮层

#### 工程实现


| 工程动作                     | 模态   | 编码器                   | 场景                 |
| ------------------------ | ---- | --------------------- | ------------------ |
| **多模态 BGE**              | 文本   | BGE-M3（已有）            | Listing / 客服 / 概念  |
|                          | 图像   | CLIP / SigLIP         | 商品主图、色谱图、结构式       |
|                          | 化学结构 | ChemBERTa / MolFormer | 多肽序列、修饰位点、杂质       |
| **统一向量空间**               | 跨模态  | 同维度映射 + 对齐训练或投影层      | 「这张图」↔「这个 concept」 |
| **感知门控（Thalamus Layer）** | 任务路由 | 根据 Buddy / 问题类型选通道    | 结构问题 → 化学通道优先      |


#### 与现有架构的衔接

```text
用户 Query
   ↓
Thalamus Router（新增 · Stage 2）
   ├── 文本通道 → BGE-M3 → ANN
   ├── 图像通道 → SigLIP → ANN
   └── 化学通道 → MolFormer → ANN
   ↓

```

#### 跨境电商 vs 湃肽场景

### 🟢 Stage 3：升级 PPR —— 从「单层扩散」到「三层神经回路」

#### 生物学原型


| 层级    | 生物结构   | 特征         |
| ----- | ------ | ---------- |
| 脊髓反射  | 脊髓     | 快，无意识      |
| 皮层下中枢 | 丘脑、基底节 | 习惯性行为      |
| 新皮层   | 大脑皮层   | 慢，有意识思考、规划 |


#### 工程实现


| 层级      | 工程名称          | 延迟目标 | 机制                                         | LLM      |
| ------- | ------------- | ---- | ------------------------------------------ | -------- |
| **反射层** | Reflex PPR    | 毫秒级  | 固定 meta-path（`concept → concept`）；缓存命中直接返回 | ❌ 无      |
| **本能层** | Instinct PPR  | 百毫秒级 | 沿高权重边扩散；调用轻量 Skill（如「查常见杂质」「查平台禁售词」）       | 轻量 / 模板  |
| **思考层** | Cognition PPR | 秒级   | 多跳、跨 meta-path；LLM Planner 生成推理链           | ✅ 完整 LLM |


#### 路由逻辑（Thalamus + PPR 协同）

```text
Query 进入
   ↓
反射层：缓存 / 高频固定路径？
   ├── 命中 → 直接返回（如「SPF50 定义」）
   └── 未命中 ↓
本能层：高权重边 + 轻量 Skill？
   ├── 命中 → 秒级响应（如「这款禁售吗」→ 查 references/平台政策）
   └── 未命中 ↓
思考层：多跳 PPR + LLM Planner
   └── 复杂推理（如「搭配三款防晒 + 写 FAQ + 合规检查」）
```

#### 与 WorkBuddy 的映射


| PPR 层 | WorkBuddy 行为          | 示例                         |
| ----- | --------------------- | -------------------------- |
| 反射层   | FAQ 缓存、概念定义           | 「什么是烟酰胺」                   |
| 本能层   | 导购四步 PDS、禁售词检查        | 「这款能发泰国吗」                  |
| 思考层   | 多 Buddy 编排、Listing+合规 | 「做成 Shopee Listing 并配 FAQ」 |


#### ✅ 效果

智能体有了「反应速度分层」——像动物一样：烫手立刻缩（反射），熟悉问题秒答（本能），陌生问题深思（思考）。

#### 验收标准

- 三层 PPR 路由可观测（日志区分 reflex / instinct / cognition）
- 反射层 P95 < 50ms（缓存命中）
- 本能层覆盖 ≥ 60% 高频 Query（无需 LLM）

| **Feedback**    | 成功/失败/部分成功事件             | 感觉反馈              | `{path_id, outcome: success |
| **突触可塑性**       | 边权 ↑↓                    | 长时程增强/抑制（LTP/LTD） | M7-3 §7 `props_json.weight` |

```text
5. Environment：30 天后 A/B 成交，C 无点击
6. Feedback：
   - path(A)、path(B) 边权 ↑
   - path(C) 边权 ↓
   - 可选：回写 Layer 2 Synthesis Concept「2026-Q3 防晒选品结论」
7. Graph Compile（增量）→ 下一轮推荐自动变准
```

| 环科院机房 | 监测系统       | 运行日志、告警、资源状态             |


#### ✅ 效果

智能体开始「活着」——知识网随真实世界反馈演化，**不再是静态数据库**。
