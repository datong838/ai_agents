# 环境准备 — 腾讯混元 API 与元宝网页版（测试）

> **角色**：DeepSeek **备选 LLM** / **仅测试**网页对比  
> **阶段**：**POC 非必须**  
> **配置**：`server.json#llm.providers.hunyuan`、`test_only_providers.yuanbao_web`  
> **技术方案**：[服务端 §7](../技术方案-SalesAgent服务端.md)、PRD Provider 策略

---

## 1. 三者关系

| 名称 | 类型 | 生产可用 | 用途 |
|------|------|----------|------|
| **DeepSeek API** | 云端 OpenAI-compatible | **是**（默认） | `POST /api/analyze` |
| **混元 TokenHub API** | 云端 OpenAI-compatible | **是**（备选） | DeepSeek 故障时 fallback |
| **腾讯元宝网页版** | 浏览器 `yuanbao.tencent.com` | **否** | 开发对比、Prompt 调试 |

```json
"provider_fallback_order": ["deepseek", "hunyuan"]
```

元宝 **禁止**接入生产 `POST /api/analyze`（`yuanbao_web.enabled: false`）。

## 2. 混元 TokenHub API（备选）

### 2.1 获取 Key

1. 登录 [腾讯混元 / TokenHub](https://tokenhub.tencentmaas.com/)（以官方最新入口为准）。
2. 创建 API Key。
3. 写入 `salesagent/.env`：

```bash
HUNYUAN_API_KEY=your-key
```

### 2.2 配置

`server.json`：

```json
"hunyuan": {
  "api_key_env": "HUNYUAN_API_KEY",
  "base_url": "https://tokenhub.tencentmaas.com/v1",
  "model": "hunyuan-lite"
}
```

> 模型 id 以控制台为准，编码时写入 `server.json`。

### 2.3 调用示例

```python
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["HUNYUAN_API_KEY"],
    base_url="https://tokenhub.tencentmaas.com/v1",
)
resp = client.chat.completions.create(
    model="hunyuan-lite",
    messages=[{"role": "user", "content": "输出 JSON: {\"ok\":true}"}],
)
```

### 2.4 接入 SalesAgent

`llm_client.py` 在 DeepSeek 连续失败 2 次后切换 `provider_fallback_order` 下一项。

### 2.5 验收

- 临时将 `default_provider` 改为 `hunyuan`（**仅 dev**）→ analyze 返回 `llm_meta.provider == "hunyuan"`。
- 恢复 `deepseek` 为默认。

## 3. 腾讯元宝网页版（仅测试）

### 3.1 定位

- **不是 API**：无稳定官方接口供生产调用。
- 配置项 `test_only_providers.yuanbao_web`：`method: playwright`，`enabled: false`。

### 3.2 适用场景

- 产品/运营对比「元宝网页回答 vs DeepSeek JSON 输出」。
- Prompt 草稿人工验证。

### 3.3 若启用本地实验（禁止上生产）

```bash
pip install playwright
playwright install chromium
```

伪流程：

1. 无头浏览器打开 `https://yuanbao.tencent.com`。
2. 模拟输入测试问题。
3. 读 DOM 或截获 SSE 得纯文本。
4. **手工**对比，不写入 analyze 管线。

```python
# 仅 scripts/dev/yuanbao_web_smoke.py — 不得 import 到 main.py
```

### 3.4 风险

| 风险 | 说明 |
|------|------|
| 页面改版 | DOM 选择器失效 |
| ToS | 自动化可能违反服务条款；**仅本地人工辅助** |
| 延迟 | 秒级～十秒级，不适合实时 analyze |
